# engine

The locale text engine both machines read: digit-system normalization,
locale formatting and parsing, bound assertion, constraint checks, and
the caret-aware segment stepping both fields share. The dirty buffer is
locale text, and only complete in-constraints candidates become the ISO
the parent ever sees. Pure and proven in colocated unit tests; the
Gregorian arithmetic underneath comes from Calendar's date kernel.
