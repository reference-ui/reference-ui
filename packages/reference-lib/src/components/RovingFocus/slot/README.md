# slot

Transparency: how Root and Item disappear into their authored children. The
merge layers part props first with the child winning, combines className
from compiled css plus both sides, shallow-merges style child-wins, chains
handlers through the shared gating, concatenates aria-describedby, and
applies kernel overrides last so tabIndex stays authoritative. The anatomy
gate throws the descriptive single-element error before any of that runs,
so an invalid child shape never partially registers.
