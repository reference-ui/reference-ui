# Tabs recipes

The prepackaged system styles: the tablist strip recipe and the per-tab
recipe across the variant, orientation, selection, and disabled axes.
Axes hold axis-pure styles only and compounds carry every cross-term,
so unknown author variant names resolve to base plus axis classes with
no built-in paint — the recipe calls ARE the extension API. The 22 CT
snapshots pin the verbatim values pixel-identical.
