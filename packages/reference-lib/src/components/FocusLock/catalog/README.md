# catalog

"What Tab lands on" — the lock's reading of native tabbability. Eligibility
decides per element, traversal walks composed trees through shadow and slots,
radio collapsing folds named groups, and assembly merges the container with
its shards into one deterministic order. Restore leans on the same reading
when it hunts a live replacement, so the two never disagree about what can
take focus.
