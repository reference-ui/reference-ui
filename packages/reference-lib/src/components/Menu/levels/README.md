# Menu levels

The level tree the whole menu coordinates through. The entry cell
records the opening key's first/last strategy where the trigger (which
lives outside the mounted Menu) can plant it and the root can consume
it once per open. Intent state holds one submenu's timers, travel
samples, and keyboard-open flag. The registry answers stable root
identity, root-trigger and direction reads, descendant checks, and
deepest-first open ordering for Escape, outside press, and selection.
Pure over the registry and the cell; unit-tested in isolation.
