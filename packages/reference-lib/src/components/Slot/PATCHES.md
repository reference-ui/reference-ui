# Slot patches (mechanical follow-ups)

No open mechanical items. The single deferred Slot item needs API design,
so it lives in [FEATURES.md](./FEATURES.md); everything else in
[DECISIONS.md](./DECISIONS.md) is Landed, Declined, or a non-decision.

New entries go here only when fully specified — a test could pin the
behavior today. Format per entry: `### <n>. <Title> (from DECISIONS
<candidate|gap> #<k>)` + one-line What + Acceptance (the test/proof) +
Source pointer.
