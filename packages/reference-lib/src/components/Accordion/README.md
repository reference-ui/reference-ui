# Accordion

Policy over disclosures: the root owns single/multiple expansion and APG
header traversal while every item stays a Collapsible. The value store —
controlled or self-managed from the natural zero — answers each item's
openness and computes the next value on toggle; keyboard moves across the
root's own enabled headers with wrap-around arrows; and authored children
are re-scoped so a nested standalone never joins the collection.

Contract: the Accordion contract. Cases: the Accordion test catalog.

The root is composition only: identities collect, the expansion store and
the traversal handler compose, and the provider renders over one div.
Beneath the hooks, each problem owns a folder. Expansion holds the value
math and its shape guards. Items owns detection, identity collection with
dev diagnostics, and nesting isolation. Keyboard owns traversal math and
header scope. Parts holds the item alias; the trigger and content aliases
re-export Collapsible's parts unchanged. Shared holds the ref fanout. Pure
decisions carry colocated unit tests; mounted behavior proves out in the
existing suites and CT.

Collapsible consumes the context through a deep import of the Accordion context — the one
cross-component edge this collection owns. There is no `store`: the value
store is a hook, not a substrate.

Find-in-page: item panels inherit `hiddenUntilFound` from their item
Collapsible, and a `beforematch` reveal expands through existing policy —
single mode swaps the open item, multiple adds — with enter motion skipped
once. Setting `hiddenUntilFound` is the opt-in; there is no separate
`findExpansion` switch. A match on the already-open item is a no-op.
