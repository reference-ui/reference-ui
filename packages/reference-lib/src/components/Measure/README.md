# Measure

Contracts for the `useMeasure` hook: this folder owns no implementation
— the hook lives in core and publishes the authored host border box
with no wrapper node. Settle, pause, idle reads, and the scale, loop,
document, hidden, and StrictMode edges prove out in the browser spec
against the single story fixture.

Cases: [case.json](./case.json). Fixture: [Measure.story](./Measure.story.tsx).
