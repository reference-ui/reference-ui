# Button

Contracts and states for the primitive Button: this folder owns no
implementation — the styled `Button` comes from `@reference-ui/react`.
Native-form ownership, submitter values, validation, keyboard activation,
and consumer cancellation prove out in the contracts spec; variants,
icon configurations, and interaction states prove out in the states
spec with visual snaps.

Cases: [case.json](./case.json). Form fixtures:
[Button.contracts.story](./Button.contracts.story.tsx). States fixtures:
[Button.story](./Button.story.tsx).

Up: [components](../components.md).
