# selection

Committed selection as pure decisions: the six matchers answer
selected, inclusive-selected, interior and inclusive in-range, and the
range endpoints from (mode, value, date); the completion machine folds
one activation into the controlled range, rejecting blocked spans and
suppressing identical values; and the collection paints mark month and
year cells from the committed value. The root wraps matchers and
activators in stable context callbacks; preview never touches these.
