# hooks

React bindings over the domain folders: one hook per behavior, data and
handlers out, no JSX. The pane owns the shown month, the private view,
and the nav-target model; availability wraps bounds and predicate into
stable callbacks; the out-of-range warning names off-bound controlled
values in dev; selection wraps the matchers and the three activators;
the today marker and locale data resolve their render inputs; grid focus
owns the roving tab target and its repair effect. The root calls its six
in their original order and renders the slotted parts; the Grid part
owns grid focus.
