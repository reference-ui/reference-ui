# Primitives

Executable smoke contracts for the library's theme primitives — forms,
buttons, selection, tables, typography, code, inline semantics, lists,
and disclosure — rendered from the shared Book gallery
(`Primitives.book`) and proven in a real browser. There is no source
component here: the story re-exports the gallery sections and the CT
suite boots the harness, renders the fixture root, and drives the
controls. Case metadata lives in the case catalog; execution decides the
verdict.
