# collapse

"Tween or jump" — the panel's height-motion gate. Plain opens and closes
tween; the initial enter, one armed `beforematch` reveal, and every
hidden-until-found shut jump straight to rest; force-mount-alone content
never tweens at all, keeping author styles in both states. Measurement
and the tween itself live in the motion hook; this module only decides.
