# hooks

React bindings over the splitter's sessions: one hook per behavior, data
and handlers out, no JSX. The registry owns DOM-order part identity, the
measured table resolves string bounds off render, the separator model
derives ARIA and blocked flags, collapse memory keys restore sizes by
panel id, keyboard owns arrows and Enter collapse, pointer owns the
one-capture drag with its synchronous geometry writes, and structure
validation records the fail-fast error the root throws. The root only
composes them, shares the session refs across the measurement and
separator seams, and publishes the result as context.
