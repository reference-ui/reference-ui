# hooks

One hook per behavior, returning data, handlers, and refs — never JSX.
The store hook binds the host to its document's records; auto-dismiss
owns countdowns and pause arbitration; swipe owns the drag machine;
focus restore and outside tracking return focus where it came from;
item height feeds measured geometry upward; stack expand hovers piles
open; the hotkey focuses the front toast; action dismiss shares the
chrome click contract; and two media hooks track motion and viewport.
Pure decisions live in the queue kernel and stack — these hooks schedule.
