# shared

The nameless plumbing every Toast layer asks: ID minting for caller-omitted
identities, development diagnostics for silent no-ops, class-name layering
between host and item, pointer-release detection for dropped drags, and
direction resolution for RTL mirroring. (Hotkey chords stay in the root
queue kernel with the rest of its coupled cluster.)
Nothing here knows about toasts as records — pure helpers with colocated
unit tests, imported by state, stack, hooks, and the API alike.
