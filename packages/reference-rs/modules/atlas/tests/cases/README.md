# Atlas cases

Committed usage-analysis stations, `ATL-<FAMILY>-<NN>`. Barrel, re-export, and export stations pin component discovery through module shapes; name and type stations pin identity and prop typing; observation and pair stations pin element observation and co-usage; package, surface, value, walk, and wrapper stations pin scanning scope, public surfaces, prop values, traversal reach, and wrapped components. Bound stations (ATL-BOUND) pin that hostile shapes, such as cycles and a twelve-module clique, finish inside a time budget in a child process.
