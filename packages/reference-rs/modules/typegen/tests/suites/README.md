# Typegen suites

Vitest coverage over the live emitter. The seam suite pins sync/async emit, strict output, recipe gating, and error boundaries through the native boundary; the diagnostics suite pins one row per `TGN-W` code plus the coded spec refusal; the vocabulary suite pins the reported `PropDefs` names against the style golden; the remaining suites run `tsc` consumers over live or golden declarations for tokens, strict narrowing, nested conditions, tones, full-surface acceptance, and animation.
