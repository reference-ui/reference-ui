# Tests

Unit tests for the nesting gate. `tests.rs` pins the limit and its line, the skipped literal regions, TypeScript generics against
plain JavaScript, and the Oxc failure shape of a refusal, and it holds the two measurements that run only when `SHARED_MEASURE_OUT`
is set. `jsx.rs` pins the JSX rules: element levels up to the limit, and one group for each miscount risk, comparisons, TypeScript
generics, arrow generics, and text or strings that mention `<`.
