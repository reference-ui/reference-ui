# Resolve proofs

Pipeline contracts for want lowering. Covers the authored lookup keys and alias guards, font lowering against built scales, plain-shape lowering (rhythm, shorthands, tokens, container and size macros, border bools, nullish skips), and refusals (unknown props, invalid bools, suggestions) plus the guard that every unrealizable extension is claimed by a lowering — asserted as codes and facts, not atoms.
