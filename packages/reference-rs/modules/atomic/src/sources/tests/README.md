# Source discovery tests

Pins for the walk and the retention contract over a shared tricky-tree fixture. The disk scan keeps the live set, provided-everything plus a root equals the bare scan, symlinks keep their stat verdicts on both walks; a complete scan skips the union backfill while incomplete, mismatch, and scope arms keep the walk — with skip and walk agreeing byte for byte. An include pattern past the brace limits is refused on the gather, the checked collect on both paths (leaving a retention token live) and the whole compile, and patterns at the limits still gather.
