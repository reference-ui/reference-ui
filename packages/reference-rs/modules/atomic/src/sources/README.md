# Source discovery

Request inputs into sorted path-content pairs for extraction. Takes the virtual file list or a root directory; the disk scan skips build and metadata directories plus non-source extensions; the include scope then filters both arms to matching files. Backfill, gather, request, and walk split the union, traversal, and retention-token paths.

The walk is one traversal shared by the collecting scan and the union backfill. Its engine lives in `shared::walk`; `walk.rs` supplies atomic's ignore set, extension gate and file read through a `WalkSink`, and keeps the `scan_dir` and `WalkScope::new` paths. The engine enters a directory only when the include patterns can still reach it by its path from the root. Every directory it enters is keyed by its canonical path and the include state of the path that reached it, and a symlinked directory is walked only when that key is new: a link that closes a loop is walked once in each state it reaches, so a file in scope only through such a link is listed under that link's path, and the walk stays bounded on cliques and lattices of links. A real directory is always walked. A file is listed once, under its first in-scope path in walk order, real paths before link aliases. The union backfill claims each provided file's canonical identity before it walks, so a listed file reached again through a link is never read twice. Styletrace's source discovery has no include scope and keeps its own walk; the JS listing follows this walk's rule, so the two sides enumerate one file set.
