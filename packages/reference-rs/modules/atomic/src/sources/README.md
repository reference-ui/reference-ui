# Source discovery

Request inputs into sorted path-content pairs for extraction. Takes the virtual file list or a root directory; the disk scan skips build and metadata directories plus non-source extensions; the include scope then filters both arms to matching files. Backfill, gather, request, and walk split the union, traversal, and retention-token paths.

The walk (`walk.rs`) is one traversal shared by the collecting scan and the union backfill. It enters a directory only when the include patterns can still reach it by its path from the root, and it enters a symlinked directory under every alias that passes that test, unless the link's target is already on the path being walked, which ends a loop at the link that closes it. A file is listed once, under its first in-scope path in walk order, real paths before link aliases. The union backfill claims each provided file's canonical identity before it walks, so a listed file reached again through a link is never read twice. Styletrace's source discovery has no include scope and keeps its own walk; the JS listing follows this walk's rule, so the two sides enumerate one file set.
