# Atomic test suites

Case-driven compiler coverage. `cases` holds the ATM case corpus executed through the shared runner with standing gauges (six-layer preamble, CSS grammar, ghost-class zero); `suites` holds the seam, ordering, quarantine, and meta tests; `harness` holds the case helpers, want matchers, and harvest model the specs build on; `rust` holds native integration tests; `goldens` pins the namer procedure outputs; `fixtures` holds the enterprise harvest tree.
