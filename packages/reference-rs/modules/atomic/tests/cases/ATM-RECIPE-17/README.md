# ATM-RECIPE-17 — Unreadable slotted recipe defaults and predicates are refused once

A slotted recipe refuses an unreadable default or compound predicate once, not once per slot. Each refusal names the field with `ATM-E-RECIPE-FIELD`, and the refused definition is dropped whole. Related: ATM-RECIPE-13, ATM-RECIPE-15, ATM-RECIPE-16.
