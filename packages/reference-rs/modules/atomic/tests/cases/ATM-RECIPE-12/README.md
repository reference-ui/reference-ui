# ATM-RECIPE-12 — Unreadable plain recipe fields are refused

A plain `recipe()` field the compiler cannot read refuses the whole definition. The refusal is `ATM-E-RECIPE-FIELD` and names the field, like `variants.size` or `compoundVariants[1]`. Related: ATM-RECIPE-06, ATM-RECIPE-13, ATM-RECIPE-14.
