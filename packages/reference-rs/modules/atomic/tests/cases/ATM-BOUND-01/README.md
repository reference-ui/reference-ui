# ATM-BOUND-01 — a lane-sized project with one 1,000-deep parenthesised value compiles

The input is 71 styling files, enough to shard across the parse lanes. `src/deep.ts` nests one `css()` colour value 1,000 parentheses deep, just inside the 1,024-level nesting gate, so Oxc parses it. The compile runs in a child process through `runIsolated` (see `ISOLATED_CASES` in `harness/helpers.ts`), so it must finish with no signal inside the 5 s budget and emit the red class. Before the native containment, a 2,000-deep value of this shape overflowed a thread stack and the process died with SIGILL; a value past the gate is refused, and ATM-BOUND-02 covers that.
