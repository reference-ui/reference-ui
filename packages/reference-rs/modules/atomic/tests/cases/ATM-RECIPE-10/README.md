# ATM-RECIPE-10 — Slotted recipe lowers to one closed recipe per slot

One `recipe({ slots })` call lowers to one closed recipe per slot under
`{className}__{slot}`. Each slot table ships only the cells that style that
slot plus every default, compounds land on the slots their `css` names, and
every slot shares its call's gate: observed triples print on each slot with
the cell, a dynamic call prints the full matrix, an uncalled recipe prints
nothing while its tables still build. Related: ATM-RECIPE-09, ATM-RECIPE-11.
