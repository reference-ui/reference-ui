# Atomic suites

Vitest coverage around the case corpus. The case executor compiles every ATM input tree and diffs committed outputs; the seam suite pins the native boundary; ordering suites pin cascade and recipe rule order plus container roots; the quarantine suites read committed goldens to prove stale entries leave the lists; census, portability, merge-eviction, alias, and token suites pin the harvest numbers, machine-independent goldens, slot eviction, locked aliases, and token backing.
