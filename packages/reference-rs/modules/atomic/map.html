Atomic Compiler Pipeline

The atomic module is Reference UI's native stylesheet compiler. It takes project sources and BaseSystem definitions, and compiles them into a deterministic six-layer stylesheet (styles.css) and a companion runtime class lookup map.

Transformation Story Example
// Author writes:
<Button variant="solid" mt="2r" bg={on ? "n300" : "n100"} />
The Atomic Mandate: Sources in, styles.css + class map out. Does not own React DOM primitives. Does not evaluate author JS at build time. Does not emit TypeScript types (owned by modules/typegen).
