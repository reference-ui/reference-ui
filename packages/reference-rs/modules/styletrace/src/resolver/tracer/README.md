# Recursive type tracer

Concrete style-prop names from declaration roots. Recurses through declarations with type arguments bound in child environments, expands builtins and literal-key passes over unions, keyof targets, mapped sources, and indexed access — emitting a flat name set or explicit failure diagnostics.

Every declaration expansion passes a session-wide expansion guard. A repeat of an expansion already in progress (same pass, declaration and caller-scoped arguments) is refused silently, since it adds no names, so a self-referential or mutually recursive type ends the walk instead of overflowing the stack. Depth, argument-size and per-session expansion limits stop recursive generics whose arguments grow. A refused expansion contributes no names, like any reference the tracer cannot resolve, so the session records each distinct cut with the names it could reach (`reach.rs`, a static walk that expands nothing). When the walk settles, a cut is lossy only if one of those reached names is missing from the trace's result; the lossy cuts are the ones the analysis reports as `STT-W-TYPE-EXPANSION-LIMIT`, and a surface whose entry has one is refused as `STT-E-UNRESOLVED-SURFACE`.
