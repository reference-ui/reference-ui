# Wrapper analysis

Directory-level tracing of public components to primitives. Parses modules, resolves imports, walks forwarding edges with memoized verdicts and cycle cuts, exposes names with their owned props through barrels, aliases, namespaces, and higher-order applications, and reports which exported bindings carry style props to a primitive.

Exposure lists every module of the outer loop. A declared same-name re-export (`export { n } from './t'`, not a default) adds nothing at the top level when `./t` is also in the outer loop and exports `n` directly, because that module's own exposure carries the same owned props under the same key; this keeps a chain of such re-exports at one hop per module instead of a walk to the end of the chain from each. The skip stops at a namespace expansion, where names change spelling, and at a default, whose spelling is the binding's. Alias chains (`export { a as b }`), default chains and atomic's per-import identity walk stay O(n) per query: a linear answer would need a stored result per node, which the no-caching rule forbids. A staged source (`TraceSources.staged`) arrives as a `ScreenedSource` and parses from its stored verdict; only a disk file is gated here.
