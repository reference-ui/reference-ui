The stack

TypeScript above the cut. Rust below.

The engine emits two things: styles.css and types. Above that dotted line is TypeScript land — a build-time layer (tokens(), font(), keyframes(), globalCss(), sitting on fragments) and a runtime layer (css(), recipe()). Primitives sit on the runtime. Fragments stay in JS: authors write real TypeScript. Rust consumes the dump; it does not run the files.

Hover a function to see which module it rests on. Written plan: docs/atomic.md. tasty, atlas, virtualrs, and modules/runtime (the .node loader) are other products — not this engine.
