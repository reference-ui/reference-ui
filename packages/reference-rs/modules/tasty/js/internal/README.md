# Tasty runtime internals

The machinery behind the public API. Node and browser runtimes load and validate the manifest; artifact loading resolves and imports modules with cache-busting queries; the chunk loader caches per-chunk imports; the symbol resolver serves symbols by id or name; interface flattening, generic instantiation, object projection with Pick/Omit keys, reference following, and type description, guards, and wrappers evaluate the graph; error and shared helpers round out the surface. Each public display call builds one projection context: its path of visited symbols ends cycles, and its step budget (10,000 steps) bounds the walk, so a runaway heritage ends with a notice rather than a crash.
