# TST-DOC-02 — jsdoc: members of an object type literal keep their JSDoc

Verifies JSDoc on members of a type literal: the literal in an intersection, a plain alias literal, and a nested literal.
Tests description, a preserved `@default` tag, and that a comment above the alias never attaches to the literal's first member.
Proves primary SPEC ID anchor TST-DOC-02.
