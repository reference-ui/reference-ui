# Workspace discovery

Include globs into the reachable file set. Discovery walks the include scope with the shared alias-aware walk (`shared::walk`) into sorted root-relative ids: a directory is entered only when an include can still reach it, `node_modules` is never entered at any depth, a symlink is followed once per directory and include state so loops and cliques stay bounded, each real file is listed once, a dangling link is skipped rather than failing the scan, and a missing scan root still fails it. It then crawls the import graph from user files inside the boundary, and applies the import policy that decides which imports bridge libraries into the index.
