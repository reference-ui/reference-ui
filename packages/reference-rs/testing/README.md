# Testing library

Shared test primitives for every compiler harness. Exports the declarative case-suite runner, golden diffing, virtual workspace helpers, CSS assertions, and normalizers through one entrypoint, so harnesses share runner semantics instead of each growing its own case loop.

`runner.ts` discovers cases by raw ID, rejects non-ID folders, validates each case's index entry and README heading, executes semantic specs, runs invariant gauges, and verifies committed output goldens. `caseIndex.ts` owns the folder convention itself (`case.json` id plus the matching `# <ID> — <claim>` heading) as pure, independently testable checks.

`isolated.ts` runs one export in a child Node process, so a hostile input that overflows a native stack or never returns cannot take the Vitest worker down with it. `runIsolated` spawns `node` on a small driver that imports a built `dist/<name>.mjs` entry (or an absolute `.mjs` path), awaits the export with its JSON arguments, and writes the JSON result to a temporary file; it returns that result with the signal, exit status, wall time, timeout flag and stderr tail, and the child gets SIGKILL when `timeoutMs` passes. `expectBounded` turns the record into the result or a failure that names the cause: a signal, a timeout, a non-zero exit with its stderr, or a call that ran past its budget. The child never inherits `RUST_MIN_STACK`, so a case sees the same stack size on every shell.
