# Package scripts

Build tooling for the published JS bundle. `build-bundle.mjs` runs esbuild over the twelve published entries (ESM-only, React external, no splitting) into a staging directory beside `dist/`, then publishes them one file at a time: each staged output is renamed over its `dist/` file, which replaces it in one step, so a reader never finds an output missing and a failed build leaves the old files in place. Only an output the previous bundle published and this one does not make is removed, after the replacements. The bundle stamp is written last, through the same rename: `dist/bundle.inputs.json`, a digest of every file esbuild read and every output it wrote. `bundle-stamp.mjs` holds that format and the check that re-hashes those files, which the test runner uses to refuse a stale dist without running esbuild. The `tsc` leg's declarations are outside this step and are not pruned by it.
