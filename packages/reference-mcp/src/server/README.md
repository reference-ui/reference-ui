# MCP server

Model Context Protocol serving over discovered projects.

The factory registers the nine documented tools plus guidance resources on either transport: stdio for editors, streamable HTTP on the loopback default. The project manager tracks the active project across workspace discovery and the cross-project registry, model state follows its build lifecycle, and tool handlers run against the active project or the primitive-only universal fallback. Shared formatters and the stderr log sink keep every tool answer shaped and stdout clean.
