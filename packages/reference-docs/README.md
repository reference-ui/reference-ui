# Reference docs app

The Reference UI documentation site: a thin Vite + React + TanStack Router shell around MDX content. There is no client-side code playground — examples render the real components and their source is shown as a static, build-time-highlighted block.

- Stack, content model, and look & feel: documented in DOCS
- Package layout and placement rules: documented in STRUCTURE
- Sections, page order, and status: documented in PLAN

Serve locally with `pnpm dev:docs` (port 5174). Agent workflow: the `agent-docs` skill. Part of Reference UI.
