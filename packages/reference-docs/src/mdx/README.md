# MDX kit

Rendering kit turning MDX output into docs pages.

The element map sets the docs visual system for headings, lists, and links; inline code is left as plain `code` for the system pill; headings add anchored sections and tutorial steps; code blocks add highlights, tall-source reveal, and tabbed groups over the shared panel look; install tabs and the agent prompt card cover setup; previews frame live examples; and the slug helper agrees with the compile-time heading-id pass so anchors never break.
