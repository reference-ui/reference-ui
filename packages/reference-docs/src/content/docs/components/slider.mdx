# Slider

Slider selects a single number or a numeric range by dragging a thumb along a
track or stepping with the keyboard.

<Preview>
  <SliderDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Slider } from '@reference-ui/lib'

export function Volume() {
  const [volume, setVolume] = useState(35)
  return (
    <Slider value={volume} onChange={setVolume}>
      <Slider.Track>
        <Slider.Range />
        <Slider.Thumb aria-label="Volume" />
      </Slider.Track>
    </Slider>
  )
}
```

## Import

```tsx
import { Slider } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Slider>
  <Slider.Track>
    <Slider.Range />
    <Slider.Thumb />
  </Slider.Track>
</Slider>
```

Without children, Slider renders this structure with one thumb per value.

## Examples

### Range

Pass a number array to `value` and render one `Slider.Thumb` per element. Each
thumb corresponds to the array item at its index. Use `minStepsBetweenThumbs`
to enforce a minimum step distance between adjacent thumbs.

<Preview>
  <SliderRangeDemo />
</Preview>

```tsx
const [price, setPrice] = useState([20, 80])

<Slider value={price} onChange={setPrice} minStepsBetweenThumbs={5}>
  <Slider.Track>
    <Slider.Range />
    <Slider.Thumb aria-label="Minimum price" />
    <Slider.Thumb aria-label="Maximum price" />
  </Slider.Track>
</Slider>
```

Adjacent thumbs stop at each other's bounds and cannot cross.

### Vertical

Set `orientation="vertical"` for a vertical track. A vertical slider stretches
to fill its parent's height, so give the container an explicit height.

<Preview>
  <SliderVerticalDemo />
</Preview>

```tsx
<Div height="40r">
  <Slider value={level} onChange={setLevel} orientation="vertical">
    <Slider.Track>
      <Slider.Range />
      <Slider.Thumb aria-label="Level" />
    </Slider.Track>
  </Slider>
</Div>
```

### Commit on release

`onChange` fires continuously as the thumb moves. Use `onChangeEnd` to run an
action only when the interaction finishes (on pointer release or key up).

```tsx
<Slider value={volume} onChange={setVolume} onChangeEnd={saveVolume} />
```

### Forms

Slider does not render a form input automatically. Include a hidden input to
submit the value with a form:

```tsx
<input type="hidden" name="volume" value={volume} />
```

## API reference

### Slider

The root container. Renders a `div` and accepts standard `div` props and style
props.

<Reference name="SliderProps" headingLevel={4} />

`onChange` and `onChangeEnd` receive a single number when `value` is a number,
or a number array when `value` is an array. Neither callback fires when
`value` is updated externally.

Slider throws on an invalid `min`, `max`, `step` or array `value`. A value
outside `min` and `max` is clamped to the nearest bound.

| Data attribute | Values |
| --- | --- |
| `[data-orientation]` | `horizontal`, `vertical` |
| `[data-disabled]` | Present when disabled. |
| `[data-dragging]` | Present while a thumb is being dragged. |

### Slider.Track

The track along which thumbs move. Clicking the track jumps the nearest thumb
to that position. Renders a `div`; each slider must contain exactly one track.

| Data attribute | Values |
| --- | --- |
| `[data-orientation]` | `horizontal`, `vertical` |

### Slider.Range

The filled portion of the track, spanning from `min` to the thumb in
single-value mode or between the first and last thumbs in range mode. Renders
a `div`; include at most one per slider.

| CSS variable | Value |
| --- | --- |
| `--reference-slider-range-start` | Start of the fill, as a percentage of the track. |
| `--reference-slider-range-end` | End of the fill, as a percentage of the track. |

### Slider.Thumb

The draggable handle for a single value. Renders a `div` with `role="slider"`.

<Reference name="SliderThumbProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `[data-orientation]` | `horizontal`, `vertical` |
| `[data-disabled]` | Present when disabled. |
| `[data-active]` | Present while the thumb is pressed or dragged. |
| `[data-dragging]` | Present while the thumb is dragged. |
| `[data-focus-visible]` | Present when the thumb has keyboard focus. |

| CSS variable | Value |
| --- | --- |
| `--reference-slider-thumb-position` | The thumb's position, as a percentage of the track. |

## Accessibility

Provide an accessible name for each thumb with `aria-label` or
`aria-labelledby`. A single thumb has no default label. In a multi-thumb
slider, unlabelled thumbs default to "Minimum" and "Maximum" for two thumbs,
or "Value 1 of N" for three or more.

To announce formatted units or custom text to screen readers, pass
`formatValue` (for example, `` formatValue={(v) => `${v}%`} ``).

Slider follows the inherited `dir`. In a right-to-left horizontal slider,
Arrow Left increases the value.

### Keyboard interactions

| Key | Action |
| --- | --- |
| `ArrowRight` / `ArrowUp` | Increases the value by `step`. |
| `ArrowLeft` / `ArrowDown` | Decreases the value by `step`. |
| `PageUp` | Increases the value by about a tenth of the range, rounded up to whole steps. |
| `PageDown` | Decreases the value by the same amount. |
| `Home` | Moves to the lowest value the thumb can reach. |
| `End` | Moves to the highest value the thumb can reach. |
