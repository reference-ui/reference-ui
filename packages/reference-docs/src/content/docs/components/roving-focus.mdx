# RovingFocus

RovingFocus makes a group of controls one Tab stop and moves focus between
them with the arrow keys. Use it for toolbars, toggle groups and grids you
build yourself.

<Preview>
  <RovingFocusDemo />
</Preview>

```tsx
import { Button, Div } from '@reference-ui/react'
import { RovingFocus } from '@reference-ui/lib'

<RovingFocus.Root orientation="horizontal" loop>
  <Div role="toolbar" aria-label="Formatting">
    <RovingFocus.Item>
      <Button>Bold</Button>
    </RovingFocus.Item>
    <RovingFocus.Item>
      <Button>Italic</Button>
    </RovingFocus.Item>
  </Div>
</RovingFocus.Root>
```

[Menu](/menu), [Menubar](/menubar) and [Tabs](/tabs) are built on it.

## Import

```tsx
import { RovingFocus } from '@reference-ui/lib'
```

## Anatomy

```tsx
<RovingFocus.Root>
  <Div>
    <RovingFocus.Item>
      <Button />
    </RovingFocus.Item>
  </Div>
</RovingFocus.Root>
```

Root and Item each take one element child and add their behaviour to it.
Neither renders a wrapper. Other props, such as event handlers, ARIA
attributes and style props, pass through to the child, and a `ref` reaches it.

## Props

### RovingFocus.Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `'horizontal' \| 'vertical' \| 'both'` | `'horizontal'` | Which arrow keys move focus. `both` moves through a grid by layout. |
| `loop` | `boolean` | `false` | Wrap from the last item to the first and back. |
| `typeahead` | `boolean` | `false` | Typing moves focus to the next item whose text starts with the typed characters. |

### RovingFocus.Item

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | `false` | Removes the item from arrow-key movement and the Tab stop. |
| `textValue` | `string` | text content | Text matched by typeahead. |
| `id` | `string` | generated | Stable identity for the item within the group. |
| `getNode` | `() => HTMLElement \| null` | — | Returns the item's element when its child can't take a ref. |

## Behaviour

- The first enabled item is the Tab stop until another item takes focus.
  Tab back into the group lands on the last focused item.
- Clicking an item makes it the Tab stop without moving focus.
- Items that are natively disabled, `aria-disabled`, hidden or
  `display: none` are skipped as well as those with `disabled`.
- Horizontal arrows reverse when the item's text direction is right to left.
- With `orientation="both"`, items group into rows by position on screen.
  Up and Down move to the nearest item in the next row.
- Typeahead ignores keys typed into inputs, text areas and editable
  content.

## Accessibility

RovingFocus manages `tabIndex` only. Give the container a role such as
`toolbar`, `grid` or `radiogroup` and an accessible name.

| Key | Description |
| --- | --- |
| `Tab` | Moves focus into the group, to the current item, and out again. |
| `ArrowRight` / `ArrowLeft` | Moves to the next or previous item when `orientation` is `horizontal` or `both`. |
| `ArrowDown` / `ArrowUp` | Moves to the next or previous item when `orientation` is `vertical`, or to the next or previous row with `both`. |
| `Home` / `PageUp` | Moves to the first item. |
| `End` / `PageDown` | Moves to the last item. |
