# RovingFocus

RovingFocus makes a group of controls a single Tab stop and moves focus between
items with the arrow keys. Use it when building custom composite widgets such
as toolbars, toggle groups, and grids.

<Preview>
  <RovingFocusDemo />
</Preview>

```tsx
import { Button, Div } from '@reference-ui/react'
import { RovingFocus } from '@reference-ui/lib'

<RovingFocus.Root orientation="horizontal" loop>
  <Div role="toolbar" aria-label="Formatting">
    <RovingFocus.Item>
      <Button>Bold</Button>
    </RovingFocus.Item>
    <RovingFocus.Item>
      <Button>Italic</Button>
    </RovingFocus.Item>
  </Div>
</RovingFocus.Root>
```

[Menu](/menu), [Menubar](/menubar), and [Tabs](/tabs) use `RovingFocus`
internally.

## Import

```tsx
import { RovingFocus } from '@reference-ui/lib'
```

## Anatomy

```tsx
<RovingFocus.Root>
  <Div>
    <RovingFocus.Item>
      <Button />
    </RovingFocus.Item>
  </Div>
</RovingFocus.Root>
```

`RovingFocus.Root` and `RovingFocus.Item` each require a single React element
child and merge their props and refs directly onto it without rendering an
extra wrapper DOM element.

## Props

## Behaviour

- The first enabled item holds the Tab stop until another item receives focus.
  Tabbing back into the group restores focus to the most recently focused item.
- Clicking an item makes it the Tab stop without moving focus.
- Items with `disabled`, `aria-disabled`, `hidden`, or `display: none` are
  skipped during keyboard navigation.
- Horizontal arrow keys reverse automatically in right-to-left layouts.
- With `orientation="both"`, items are grouped into rows by their screen
  coordinates, and Up and Down arrow keys move to the nearest item in the
  adjacent row.
- Typeahead ignores keys typed into inputs, text areas, and editable content.

## Accessibility

RovingFocus manages `tabIndex` only. Give the container a role such as
`toolbar`, `grid` or `radiogroup` and an accessible name.

| Key | Description |
| --- | --- |
| `Tab` | Moves focus into the group, to the current item, and out again. |
| `ArrowRight` / `ArrowLeft` | Moves to the next or previous item when `orientation` is `horizontal` or `both`. |
| `ArrowDown` / `ArrowUp` | Moves to the next or previous item when `orientation` is `vertical`, or to the next or previous row with `both`. |
| `Home` / `PageUp` | Moves to the first item. |
| `End` / `PageDown` | Moves to the last item. |
