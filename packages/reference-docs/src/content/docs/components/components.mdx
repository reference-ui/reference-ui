# Overview

`@reference-ui/lib` ships components for behaviour that is hard to build by
hand: focus, keyboard navigation, layering, dismissal, selection and value
editing. Markup and appearance stay in your code.
[Library components](/library-components) explains why the set is this
small.

Import components by name from the package root, and mount
[ReferenceLibrary](/reference-library) once near your app root:

```tsx
import { ReferenceLibrary, Tabs } from '@reference-ui/lib'
```

Each part renders a fixed native element and takes that element's props and
style props.
