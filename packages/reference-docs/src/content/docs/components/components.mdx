# Overview

`@reference-ui/lib` ships components for behaviour that is hard to build by
hand: focus, keyboard navigation, layering, dismissal, selection and value
editing. Markup and styling remain under your control. See
[Library components](/library-components) for how this set is scoped.

Import components by name from the package root, and mount
[ReferenceLibrary](/reference-library) once near your app root:

```tsx
import { ReferenceLibrary, Tabs } from '@reference-ui/lib'
```

Each component part renders a specific HTML element and accepts its standard
DOM props alongside Reference UI style props.

## Foundation

| Component | Use it for |
| --- | --- |
| [ReferenceLibrary](/reference-library) | Mounting the toast host, live region, and shared tooltip timing. |
| [Overlay](/overlay) | Dialogs, drawers, sheets and anchored panels. |
| [Popover](/popover) | Interactive content anchored to a trigger. |
