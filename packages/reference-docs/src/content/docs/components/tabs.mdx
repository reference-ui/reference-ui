# Tabs

Tabs organize content into separate views where only one panel is visible at a
time.

<Preview>
  <TabsDemo />
</Preview>

```tsx
import { Tabs } from '@reference-ui/lib'

<Tabs>
  <Tabs.List aria-label="Settings">
    <Tabs.Tab value="general">General</Tabs.Tab>
    <Tabs.Tab value="billing">Billing</Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="general">General settings.</Tabs.Panel>
  <Tabs.Panel value="billing">Billing settings.</Tabs.Panel>
</Tabs>
```

## Import

```tsx
import { Tabs } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Tabs>
  <Tabs.List>
    <Tabs.Tab />
  </Tabs.List>
  <Tabs.Panel />
</Tabs>
```

`Tabs` renders no DOM element of its own. Pair each `Tabs.Tab` inside
`Tabs.List` with a corresponding `Tabs.Panel` sharing the same `value`.

## Examples

### Controlled

For controlled state, pass `value` and `onChange`.

```tsx
const [tab, setTab] = React.useState('billing')

<Tabs value={tab} onChange={setTab}>…</Tabs>
```

In uncontrolled mode, the first enabled tab is selected by default.

### Pill variant

Set `variant="pill"` for rounded pill tabs instead of an underline:

<Preview>
  <TabsPillDemo />
</Preview>

```tsx
<Tabs variant="pill">…</Tabs>
```

### Vertical

Set `orientation="vertical"` to stack tabs vertically and navigate between them
with the Up and Down arrow keys. Wrap `Tabs` in a flex or grid container to
arrange the tab list and panels side by side.

<Preview>
  <TabsVerticalDemo />
</Preview>

```tsx
<Div display="flex" gap="6r">
  <Tabs orientation="vertical">
    <Tabs.List aria-label="Account">
      <Tabs.Tab value="profile">Profile</Tabs.Tab>
      <Tabs.Tab value="email">Email</Tabs.Tab>
      <Tabs.Tab value="password" disabled>Password</Tabs.Tab>
    </Tabs.List>
    <Tabs.Panel value="profile">…</Tabs.Panel>
    <Tabs.Panel value="email">…</Tabs.Panel>
    <Tabs.Panel value="password">…</Tabs.Panel>
  </Tabs>
</Div>
```

### Manual activation

By default, moving focus to a tab with the arrow keys selects it immediately.
Set `activation="manual"` so arrow keys only move focus and `Enter` or `Space`
selects the focused tab.

```tsx
<Tabs activation="manual">…</Tabs>
```

### Keeping panels mounted

By default, inactive panels unmount their children. Set `keepMounted` on `Tabs`
or on an individual `Tabs.Panel` to keep inactive panels mounted in the DOM
(with `hidden`), preserving their local state across tab switches.

```tsx
<Tabs.Panel value="billing" keepMounted>
  <BillingForm />
</Tabs.Panel>
```

### Custom variants

Pass a custom string to `variant` (any value other than `"line"` or `"pill"`)
to retain base structural and accessibility styles, such as focus rings and
disabled states, without applying built-in indicator styles. You can then style
the list and tabs via `className`. The built-in recipes are exported as
`tabsListRecipe` and `tabsTabRecipe`.

```tsx
<Tabs variant="underline">
  <Tabs.List className={myList}>
    <Tabs.Tab value="general" className={myTab}>General</Tabs.Tab>
  </Tabs.List>
  …
</Tabs>
```

## API reference

### Tabs

Manages the active tab selection and configuration. Renders no DOM element of
its own.

<Reference name="TabsProps" headingLevel={4} />

### Tabs.List

The tab list container (`role="tablist"`). Renders a `div` and accepts standard
`div` props and style props.

<Reference name="TabsListProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `data-orientation` | `horizontal`, `vertical` |
| `data-variant` | the variant name |

### Tabs.Tab

An individual tab trigger (`role="tab"`). Renders a `button` and accepts
standard `button` props and style props.

<Reference name="TabProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `data-state` | `active`, `inactive` |
| `data-disabled` | present when disabled |
| `data-value` | the tab's `value` |
| `data-variant` | the variant name |

### Tabs.Panel

The content panel associated with a tab (`role="tabpanel"`). Renders a `div`
and accepts standard `div` props and style props.

<Reference name="TabPanelProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `data-state` | `active`, `inactive` |
| `data-value` | the panel's `value` |

## Behaviour

- Clicking or activating the already active tab does not fire `onChange`.
- Duplicate `value` props across tabs or panels throw an error.

## Accessibility

- Give `Tabs.List` an `aria-label`. Each panel is labelled by its tab.
- Inactive panels have the `hidden` attribute.
- If focus is inside a panel when another tab becomes active, focus moves to
  the newly selected tab.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Tab` | Moves focus into the list, onto the selected tab, then out of the list. |
| `ArrowRight` | Horizontal: moves focus to the next tab, wrapping from last to first. |
| `ArrowLeft` | Horizontal: moves focus to the previous tab, wrapping from first to last. |
| `ArrowDown` | Vertical: moves focus to the next tab, wrapping from last to first. |
| `ArrowUp` | Vertical: moves focus to the previous tab, wrapping from first to last. |
| `Home` | Moves focus to the first tab. `PageUp` does the same. |
| `End` | Moves focus to the last tab. `PageDown` does the same. |
| `Enter` | Selects the focused tab in manual activation. |
| `Space` | Selects the focused tab in manual activation. |

Arrow keys skip disabled tabs. In automatic activation, moving focus also
selects the tab. In right-to-left layouts, `ArrowLeft` and `ArrowRight` are
reversed.
