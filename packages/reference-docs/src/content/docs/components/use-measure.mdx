# useMeasure

`useMeasure` tracks an element's bounding box and indicates when its dimensions
have settled after a resize or transition.

<Preview>
  <UseMeasureDemo />
</Preview>

```tsx
import { Div, Textarea } from '@reference-ui/react'
import { useMeasure } from '@reference-ui/lib'

export function Notes() {
  const { ref, rect, isSettled } = useMeasure<HTMLTextAreaElement>()
  return (
    <Div>
      <Textarea ref={ref} aria-label="Notes" />
      {rect && isSettled ? `${rect.width} × ${rect.height}` : null}
    </Div>
  )
}
```

## Import

```tsx
import { useMeasure } from '@reference-ui/lib'
```

## Usage

Attach the returned `ref` to the target DOM element.

`rect` contains the element's border-box dimensions and viewport coordinates
(via `getBoundingClientRect`). It is `null` during server rendering and until
the initial measurement completes, and updates whenever the element resizes.

`isSettled` becomes `true` once the element's dimensions have remained stable
for 20ms (configurable via `settleTimeout`). Check `isSettled` when you need
final dimensions after a CSS transition or continuous resize.

## Examples

### Using an existing ref

Pass an existing ref to `target` when you already hold a ref to the element:

```tsx
const panelRef = useRef<HTMLDivElement>(null)
const { rect } = useMeasure({ target: panelRef })

return <Div ref={panelRef}>…</Div>
```

### Pausing during a drag

Set `paused` to suspend observation during an active interaction such as a
[Splitter](/splitter) drag or CSS animation. While paused, `rect` retains its
last measured value and `isSettled` is `false`. Measurement resumes
automatically when `paused` becomes `false`.

```tsx
const [dragging, setDragging] = useState(false)
const { ref, rect } = useMeasure({ paused: dragging })
```

## API reference

```ts
function useMeasure<E extends HTMLElement = HTMLElement>(
  options?: UseMeasureOptions
): UseMeasureResult<E>
```

### Options

Optional configuration passed to `useMeasure(options)`.

### Return value

The measurement state and callback ref returned by `useMeasure`.

<Reference name="UseMeasureResult" headingLevel={4} />

The default quiet time is also exported as `MEASUREMENT_SETTLE_TIMEOUT_MS`.
The types `MeasureBox`, `UseMeasureOptions`, and `UseMeasureResult` are
exported from `@reference-ui/lib`.

`top` and `left` are relative to the viewport at the last measurement.
Scrolling does not update them.
