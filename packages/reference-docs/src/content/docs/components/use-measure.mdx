# useMeasure

`useMeasure` reports an element's size and position once its layout stops
changing.

<Preview>
  <UseMeasureDemo />
</Preview>

```tsx
import { Div, Textarea } from '@reference-ui/react'
import { useMeasure } from '@reference-ui/lib'

export function Notes() {
  const { ref, rect, isSettled } = useMeasure<HTMLTextAreaElement>()
  return (
    <Div>
      <Textarea ref={ref} aria-label="Notes" />
      {rect && isSettled ? `${rect.width} × ${rect.height}` : null}
    </Div>
  )
}
```

## Import

```tsx
import { useMeasure } from '@reference-ui/lib'
```

## Usage

Attach the returned `ref` to the element you want to measure. The hook
renders nothing of its own.

`rect` is the element's border box, read with `getBoundingClientRect`. It
is `null` until the first measurement, including during server rendering.
It updates when the element's size changes.

`isSettled` turns `true` once the size has stopped changing for 20
milliseconds. Sizes measured mid-transition are not final, so wait for
`isSettled` before acting on them.

## Examples

### Measuring an element you already have a ref to

Pass the ref as `target` when the element's ref is already taken.

```tsx
const panelRef = useRef<HTMLDivElement>(null)
const { rect } = useMeasure({ target: panelRef })

return <Div ref={panelRef}>…</Div>
```

### Pausing during a drag

Set `paused` while something else is resizing the element, such as a
[Splitter](/splitter) drag or a CSS animation. Observation stops, `rect`
keeps its last value and `isSettled` is `false`. Measurement starts again
when `paused` turns `false`.

```tsx
const [dragging, setDragging] = useState(false)
const { ref, rect } = useMeasure({ paused: dragging })
```

## API reference

```ts
function useMeasure<E extends HTMLElement = HTMLElement>(
  options?: UseMeasureOptions
): UseMeasureResult<E>
```

### Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `paused` | `boolean` | `false` | Stop observing. The last `rect` is kept. |
| `settleTimeoutMs` | `number` | `20` | Quiet time in milliseconds before `isSettled` turns `true`. |
| `target` | `RefObject<HTMLElement \| null>` | — | Measure the element this ref holds instead of attaching `ref`. |

### Return value

| Field | Type | Description |
| --- | --- | --- |
| `ref` | `RefCallback<E>` | Attach to the element to measure. |
| `rect` | `MeasureBox \| null` | `{ width, height, top, left }` in pixels, or `null` before the first measurement. |
| `isSettled` | `boolean` | `true` once `rect` has not changed for `settleTimeoutMs`. |

The default quiet time is also exported as `MEASUREMENT_SETTLE_TIMEOUT_MS`.
The types `MeasureBox`, `UseMeasureOptions` and `UseMeasureResult` are
exported from `@reference-ui/lib`.

`top` and `left` are relative to the viewport at the last measurement.
Scrolling does not update them.
