# Menu

A pop-up list of commands, toggles and submenus. It opens from a button or a
context press, and the arrow keys move through the items.

<Preview>
  <MenuDemo />
</Preview>

```tsx
import { Menu, Popover, useMenuTriggerKeys } from '@reference-ui/lib'

function ActionsTrigger() {
  const keys = useMenuTriggerKeys()
  return (
    <Popover.Trigger aria-haspopup="menu" onKeyDown={keys.onKeyDown} onClick={keys.onClick}>
      Actions
    </Popover.Trigger>
  )
}

export function ActionsMenu() {
  return (
    <Popover>
      <ActionsTrigger />
      <Popover.Content placement="bottom-start">
        <Menu aria-label="Actions">
          <Menu.Item onSelect={() => console.log('cut')}>Cut</Menu.Item>
          <Menu.Item onSelect={() => console.log('copy')}>Copy</Menu.Item>
          <Menu.Separator />
          <Menu.Item disabled>Delete</Menu.Item>
        </Menu>
      </Popover.Content>
    </Popover>
  )
}
```

Menu owns the items and the keyboard. The surrounding [Popover](/popover)
owns open state and position.

## Import

```tsx
import { Menu, useMenuTriggerKeys, useMenuContextKeys } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Popover>
  <Popover.Trigger />
  <Popover.Content>
    <Menu>
      <Menu.Item />
      <Menu.LinkItem />
      <Menu.CheckboxItem />
      <Menu.RadioGroup>
        <Menu.RadioItem />
      </Menu.RadioGroup>
      <Menu.Separator />
      <Menu>
        <Menu.Trigger />
        <Menu.Content />
      </Menu>
    </Menu>
  </Popover.Content>
</Popover>
```

A `Menu` inside another `Menu` is a submenu. It renders no element of its
own: `Menu.Trigger` is its row in the parent menu and `Menu.Content` is its
panel.

## Examples

### Submenus

Nest a `Menu` and give it `open`, `onOpen` and `onDismiss`. A submenu is
always controlled; without `open` it stays closed.

```tsx
const [shareOpen, setShareOpen] = useState(false)

<Menu aria-label="File">
  <Menu.Item>New</Menu.Item>
  <Menu open={shareOpen} onOpen={() => setShareOpen(true)} onDismiss={() => setShareOpen(false)}>
    <Menu.Trigger>Share</Menu.Trigger>
    <Menu.Content>
      <Menu.Item>Email</Menu.Item>
      <Menu.Item>Copy link</Menu.Item>
    </Menu.Content>
  </Menu>
</Menu>
```

### Checkbox items

`Menu.CheckboxItem` is controlled. Activating it calls `onChange` with the
opposite of `checked`; a `'mixed'` item becomes `true`.

```tsx
const [grid, setGrid] = useState(true)

<Menu.CheckboxItem checked={grid} onChange={setGrid}>
  Show grid
</Menu.CheckboxItem>
```

### Radio items

Put `Menu.RadioItem`s in a `Menu.RadioGroup`. The group holds the value.

```tsx
const [sort, setSort] = useState('name')

<Menu.RadioGroup aria-label="Sort by" value={sort} onChange={setSort}>
  <Menu.RadioItem value="name">Name</Menu.RadioItem>
  <Menu.RadioItem value="date">Date</Menu.RadioItem>
</Menu.RadioGroup>
```

Checkbox and radio items keep the menu open after selection. Pass
`closeOnSelect` to close it.

### Links

`Menu.LinkItem` renders an `a`. A plain click navigates and closes the menu.
Modified clicks and middle clicks keep their native behaviour.

```tsx
<Menu.LinkItem href="/settings">Settings</Menu.LinkItem>
```

### Keeping the menu open

Call `preventDefault()` on the event passed to `onSelect`. The menu stays
open and, for choice items, `onChange` is not called.

```tsx
<Menu.Item onSelect={event => event.preventDefault()}>Refresh</Menu.Item>
```

### Context menus

Open the menu from an [Overlay](/overlay) anchored at the pointer, and spread
`useMenuContextKeys()` on the target so a keyboard opening focuses the first
item.

```tsx
import { useState } from 'react'
import { Menu, Overlay, useMenuContextKeys } from '@reference-ui/lib'

export function Canvas() {
  const [open, setOpen] = useState(false)
  const [anchor, setAnchor] = useState<{ x: number; y: number }>()
  const keys = useMenuContextKeys()
  return (
    <>
      <div
        role="button"
        tabIndex={0}
        onKeyDown={keys.onKeyDown}
        onContextMenu={event => {
          if (!open) keys.onContextMenu(event)
          event.preventDefault()
          setAnchor({ x: event.clientX, y: event.clientY })
          setOpen(true)
        }}
      >
        Right-click here
      </div>
      <Overlay open={open} onDismiss={() => setOpen(false)} anchor={anchor}>
        <Overlay.Content placement="bottom-start">
          <Menu aria-label="Canvas">
            <Menu.Item>Edit</Menu.Item>
            <Menu.Item>Delete</Menu.Item>
          </Menu>
        </Overlay.Content>
      </Overlay>
    </>
  )
}
```

`useMenuContextKeys()` also returns an `onKeyDown` that marks the
ContextMenu key and Shift+F10. Your handler still opens the overlay for
those keys.

## API reference

Every part takes the props of the element it renders, plus style props.

### Menu

Renders a `div` with `role="menu"`. The root menu's open state lives on the
Popover or Overlay around it.

### Menu.Item

Renders a `div` with `role="menuitem"`.

<Reference name="MenuItemProps" headingLevel={4} />

### Menu.CheckboxItem

Renders a `div` with `role="menuitemcheckbox"` and `aria-checked`.

<Reference name="MenuCheckboxItemProps" headingLevel={4} />

### Menu.RadioGroup

Renders a `div` with `role="group"`.

<Reference name="MenuRadioGroupProps" headingLevel={4} />

### Menu.RadioItem

Renders a `div` with `role="menuitemradio"` and `aria-checked`. Use it only
inside `Menu.RadioGroup`.

<Reference name="MenuRadioItemProps" headingLevel={4} />

### Menu.LinkItem

Renders an `a` with `role="menuitem"`.

<Reference name="MenuLinkItemProps" headingLevel={4} />

### Menu.Separator

Renders a `div` with `role="separator"`. It is never focused.

### Menu.Trigger

The submenu's row in its parent menu. Renders a `div` with
`role="menuitem"` and `aria-haspopup="menu"`. Use it only inside a nested
`Menu`.

<Reference name="MenuTriggerProps" headingLevel={4} />

### Menu.Content

The submenu panel. Renders a `div` with `role="menu"`. Use it only inside a
nested `Menu`. It takes the geometry props of
[`Overlay.Content`](/overlay); `placement` defaults to `'right-start'`
(`'left-start'` right to left).

### useMenuTriggerKeys

Returns `{ onKeyDown, onClick }`. Spread both on the `Popover.Trigger` that
opens a root menu. A keyboard opening focuses the first or last item; a
pointer opening focuses the menu itself.

<Reference name="MenuTriggerKeys" headingLevel={4} />

### useMenuContextKeys

Returns `{ onContextMenu, onKeyDown }`. Spread both on a context-menu
target so the next opening focuses the first item.

<Reference name="MenuContextKeys" headingLevel={4} />

## Accessibility

Menu follows the WAI-ARIA Menu and Menu Button patterns. Focus moves between
items with a roving tab index.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` | On the trigger, opens the menu and focuses the first item. On an item, activates it. On a submenu trigger, opens the submenu. |
| `ArrowDown` | On the trigger, opens the menu and focuses the first item. In the menu, moves to the next item, wrapping at the end. |
| `ArrowUp` | On the trigger, opens the menu and focuses the last item. In the menu, moves to the previous item, wrapping at the start. |
| `Home` / `PageUp` | Moves to the first item. |
| `End` / `PageDown` | Moves to the last item. |
| `ArrowRight` | On a submenu trigger, opens the submenu and focuses its first item. Mirrored right to left. |
| `ArrowLeft` | In a submenu, closes it and returns focus to its trigger. Mirrored right to left. |
| `Escape` | Closes one level: the open submenu, or the menu itself, returning focus to its trigger. |
| `Tab` | Closes the menu and moves focus to the next control after the trigger. |
| Letters | Focus the next item whose text starts with the typed characters. |

Disabled items are skipped. Space typed during a typeahead search is part
of the search and does not activate the item.

### Pointer

Hovering a submenu trigger opens it after 100 ms. Moving the pointer
diagonally toward the open submenu keeps it open.

### Labelling

Give the root menu a name with `aria-label` or `aria-labelledby`, and give
each `Menu.RadioGroup` an `aria-label`.

For a row of always-visible menus, use [Menubar](/menubar).
