# Menu

Menu displays a list of actions, toggles, and submenus. It opens from a trigger
button or right-click, with full arrow-key navigation and typeahead support.

<Preview>
  <MenuDemo />
</Preview>

```tsx
import { Menu, Popover, useMenuTriggerKeys } from '@reference-ui/lib'

function ActionsTrigger() {
  const keys = useMenuTriggerKeys()
  return (
    <Popover.Trigger aria-haspopup="menu" onKeyDown={keys.onKeyDown} onClick={keys.onClick}>
      Actions
    </Popover.Trigger>
  )
}

export function ActionsMenu() {
  return (
    <Popover>
      <ActionsTrigger />
      <Popover.Content placement="bottom-start">
        <Menu aria-label="Actions">
          <Menu.Item onSelect={() => console.log('cut')}>Cut</Menu.Item>
          <Menu.Item onSelect={() => console.log('copy')}>Copy</Menu.Item>
          <Menu.Separator />
          <Menu.Item disabled>Delete</Menu.Item>
        </Menu>
      </Popover.Content>
    </Popover>
  )
}
```

Menu handles the items and keyboard navigation, while the surrounding
[Popover](/popover) manages open state and positioning.

## Import

```tsx
import { Menu, useMenuTriggerKeys, useMenuContextKeys } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Popover>
  <Popover.Trigger />
  <Popover.Content>
    <Menu>
      <Menu.Item />
      <Menu.LinkItem />
      <Menu.CheckboxItem />
      <Menu.RadioGroup>
        <Menu.RadioItem />
      </Menu.RadioGroup>
      <Menu.Separator />
      <Menu>
        <Menu.Trigger />
        <Menu.Content />
      </Menu>
    </Menu>
  </Popover.Content>
</Popover>
```

A `Menu` nested inside another `Menu` acts as a submenu. It renders no wrapper
element of its own: `Menu.Trigger` renders the item row in the parent menu, and
`Menu.Content` renders the submenu panel.

## Examples

### Submenus

Nest a `Menu` and pass `open`, `onOpen`, and `onDismiss`. Submenus are always
controlled and remain closed if `open` is omitted.

```tsx
const [shareOpen, setShareOpen] = useState(false)

<Menu aria-label="File">
  <Menu.Item>New</Menu.Item>
  <Menu open={shareOpen} onOpen={() => setShareOpen(true)} onDismiss={() => setShareOpen(false)}>
    <Menu.Trigger>Share</Menu.Trigger>
    <Menu.Content>
      <Menu.Item>Email</Menu.Item>
      <Menu.Item>Copy link</Menu.Item>
    </Menu.Content>
  </Menu>
</Menu>
```

### Checkbox items

`Menu.CheckboxItem` is controlled. Selecting it calls `onChange` with the
toggled boolean value (an indeterminate `'mixed'` item resolves to `true`).

```tsx
const [grid, setGrid] = useState(true)

<Menu.CheckboxItem checked={grid} onChange={setGrid}>
  Show grid
</Menu.CheckboxItem>
```

### Radio items

Group `Menu.RadioItem` components inside a `Menu.RadioGroup` to manage single
selection via `value` and `onChange`.

```tsx
const [sort, setSort] = useState('name')

<Menu.RadioGroup aria-label="Sort by" value={sort} onChange={setSort}>
  <Menu.RadioItem value="name">Name</Menu.RadioItem>
  <Menu.RadioItem value="date">Date</Menu.RadioItem>
</Menu.RadioGroup>
```

Checkbox and radio items keep the menu open when toggled. Pass `closeOnSelect`
to close the menu on selection.

### Links

`Menu.LinkItem` renders an `<a>` element. A standard left-click navigates and
closes the menu, while modifier and middle clicks preserve default browser
behavior.

```tsx
<Menu.LinkItem href="/settings">Settings</Menu.LinkItem>
```

### Keeping the menu open

Call `preventDefault()` on the event in `onSelect` to keep the menu open. On
checkbox and radio items, this also prevents `onChange` from firing.

```tsx
<Menu.Item onSelect={event => event.preventDefault()}>Refresh</Menu.Item>
```

### Context menus

Render the menu inside an [Overlay](/overlay) anchored to the pointer
coordinates, and attach `useMenuContextKeys()` to the target element so opening
via keyboard focuses the first item.

```tsx
import { useState } from 'react'
import { Menu, Overlay, useMenuContextKeys } from '@reference-ui/lib'

export function Canvas() {
  const [open, setOpen] = useState(false)
  const [anchor, setAnchor] = useState<{ x: number; y: number }>()
  const keys = useMenuContextKeys()
  return (
    <>
      <div
        role="button"
        tabIndex={0}
        onKeyDown={keys.onKeyDown}
        onContextMenu={event => {
          if (!open) keys.onContextMenu(event)
          event.preventDefault()
          setAnchor({ x: event.clientX, y: event.clientY })
          setOpen(true)
        }}
      >
        Right-click here
      </div>
      <Overlay open={open} onDismiss={() => setOpen(false)} anchor={anchor}>
        <Overlay.Content placement="bottom-start">
          <Menu aria-label="Canvas">
            <Menu.Item>Edit</Menu.Item>
            <Menu.Item>Delete</Menu.Item>
          </Menu>
        </Overlay.Content>
      </Overlay>
    </>
  )
}
```

`useMenuContextKeys()` also provides an `onKeyDown` handler that detects the
`ContextMenu` key and `Shift+F10` so focus moves into the menu when your
handler opens the overlay.

## API reference

Each part accepts the standard HTML props of its rendered element along with
style props.

### Menu

Renders a `div` with `role="menu"`. For a root menu, open state is managed by
the surrounding `Popover` or `Overlay`.

<Reference name="MenuProps" headingLevel={4} />

### Menu.Item

Renders a `div` with `role="menuitem"`.

<Reference name="MenuItemProps" headingLevel={4} />

`closeOnSelect` is a deprecated alias for `closeOnClick`.

### Menu.CheckboxItem

Renders a `div` with `role="menuitemcheckbox"` and `aria-checked`.

<Reference name="MenuCheckboxItemProps" headingLevel={4} />

### Menu.RadioGroup

Renders a `div` with `role="group"`.

<Reference name="MenuRadioGroupProps" headingLevel={4} />

### Menu.RadioItem

Renders a `div` with `role="menuitemradio"` and `aria-checked`. Must be used
inside `Menu.RadioGroup`.

<Reference name="MenuRadioItemProps" headingLevel={4} />

### Menu.LinkItem

Renders an `a` with `role="menuitem"`.

<Reference name="MenuLinkItemProps" headingLevel={4} />

### Menu.Separator

Renders a `div` with `role="separator"`. Skipped during keyboard navigation.

### Menu.Trigger

The trigger item in the parent menu that opens a submenu. Renders a `div` with
`role="menuitem"` and `aria-haspopup="menu"`. Must be used inside a nested
`Menu`.

<Reference name="MenuTriggerProps" headingLevel={4} />

### Menu.Content

The floating panel for a submenu. Renders a `div` with `role="menu"` and must
be used inside a nested `Menu`. Accepts the positioning props of
[`Overlay.Content`](/overlay), with `placement` defaulting to `'right-start'`
(`'left-start'` in right-to-left layouts).

### useMenuTriggerKeys

Returns `{ onKeyDown, onClick }` for the `Popover.Trigger` that opens a root
menu. Opening with the keyboard focuses the first or last item, while opening
with a pointer focuses the menu container.

<Reference name="MenuTriggerKeys" headingLevel={4} />

### useMenuContextKeys

Returns `{ onContextMenu, onKeyDown }` for a context-menu target so keyboard
activation focuses the first menu item.

<Reference name="MenuContextKeys" headingLevel={4} />

## Accessibility

Menu follows the WAI-ARIA Menu and Menu Button patterns. Focus moves between
items with a roving `tabIndex`.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` | On the trigger, opens the menu and focuses the first item. On an item, activates it. On a submenu trigger, opens the submenu. |
| `ArrowDown` | On the trigger, opens the menu and focuses the first item. In the menu, moves to the next item, wrapping at the end. |
| `ArrowUp` | On the trigger, opens the menu and focuses the last item. In the menu, moves to the previous item, wrapping at the start. |
| `Home` / `PageUp` | Moves to the first item. |
| `End` / `PageDown` | Moves to the last item. |
| `ArrowRight` | On a submenu trigger, opens the submenu and focuses its first item. Reversed in right-to-left layouts. |
| `ArrowLeft` | In a submenu, closes it and returns focus to its trigger. Reversed in right-to-left layouts. |
| `Escape` | Closes one level: the open submenu, or the menu itself, returning focus to its trigger. |
| `Tab` | Closes the menu and moves focus to the next control after the trigger. |
| Letters | Focus the next item whose text starts with the typed characters. |

Disabled items are skipped. Space typed during a typeahead search is part
of the search and does not activate the item.

### Pointer

Hovering a submenu trigger opens it after 100 ms. Moving the pointer
diagonally toward the open submenu keeps it open.

### Labelling

Provide an accessible name for the root menu using `aria-label` or
`aria-labelledby`, and label each `Menu.RadioGroup` with `aria-label`.

For a row of always-visible menus, use [Menubar](/menubar).
