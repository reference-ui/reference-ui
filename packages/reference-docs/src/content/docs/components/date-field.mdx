# DateField

DateField edits a date as locale-formatted text and holds it as an ISO
string (`YYYY-MM-DD`). Add a picker to choose the date from a calendar.

<Preview>
  <DateFieldDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Label } from '@reference-ui/react'
import { DateField, type ISODate } from '@reference-ui/lib'

export function StartDate() {
  const [date, setDate] = useState<ISODate | null>('2026-10-17')
  return (
    <>
      <Label htmlFor="start">Start date</Label>
      <DateField id="start" value={date} onChange={setDate} locale="en-GB">
        <DateField.Input />
        <DateField.Trigger aria-label="Open calendar" />
        <DateField.Picker />
      </DateField>
    </>
  )
}
```

## Import

```tsx
import { DateField } from '@reference-ui/lib'
```

## Anatomy

```tsx
<DateField>
  <DateField.Input />
  <DateField.Trigger />
  <DateField.Picker>
    <DateField.Calendar />
  </DateField.Picker>
</DateField>

<DateField.Range>
  <DateField.Start />
  <DateField.End />
  <DateField.Trigger />
  <DateField.Picker />
</DateField.Range>
```

Regardless of child order, DateField places the input first, the trigger after
it, and the picker below the field.

- Without children, DateField renders only the text input.
- A `DateField.Picker` without a `DateField.Trigger` gets a calendar-icon
  trigger.
- A `DateField.Picker` without children holds a calendar bound to the field.

## Examples

### Text only

Leave out the children for a plain input.

```tsx
<DateField id="due" value={date} onChange={setDate} locale="en-US" />
```

The text follows the locale: `17/10/2026` in `en-GB`, `10/17/2026` in
`en-US`. DateField also accepts `2026-10-17`. A year must have four digits.

### Range

`DateField.Range` holds a start and an end input and one range picker.

<Preview>
  <DateFieldRangeDemo />
</Preview>

```tsx
const [stay, setStay] = useState<DateRangeValue | null>(null)

<DateField.Range value={stay} onChange={setStay} locale="en-GB">
  <DateField.Start aria-label="Check-in" />
  <DateField.End aria-label="Check-out" />
  <DateField.Trigger aria-label="Open calendar" />
  <DateField.Picker />
</DateField.Range>
```

`onChange` receives a range only when both dates are complete, in order and
allowed, or `null` when both inputs are cleared.

### Limits

`min`, `max` and `isDateUnavailable` limit the dates the field accepts. A
typed date outside them is never passed to `onChange`.

In a single field, the default picker greys out dates outside `min` and
`max`, but not unavailable dates. Clicking one does nothing. To grey those
out too, pass the same function to `DateField.Calendar`:

```tsx
<DateField value={date} onChange={setDate} locale="en-GB" isDateUnavailable={isWeekend}>
  <DateField.Input />
  <DateField.Trigger aria-label="Open calendar" />
  <DateField.Picker>
    <DateField.Calendar isDateUnavailable={isWeekend} />
  </DateField.Picker>
</DateField>
```

### Forms

Pass `name` to submit the ISO value with a form. DateField adds a hidden
input; a disabled field submits nothing.

```tsx
<DateField name="start" value={date} onChange={setDate} locale="en-GB" />
```

For a range, a string `name` submits both dates under that name, and
`name={{ start: 'from', end: 'to' }}` submits them separately.

## API reference

### DateField

Without children, renders an `input` and takes its props. With children,
renders a `div` around the parts; `id`, `placeholder` and the input event
handlers still go to the input.

<Reference name="DateFieldProps" headingLevel={4} />

DateField throws if a required prop is missing or `min` and `max` are not
valid dates in order.

`onChange` fires as soon as the typed text is a complete, allowed date that
differs from `value`, and with `null` when the text is cleared. Incomplete
dates do not fire `onChange`. On blur or Enter, text that is not an allowed
date goes back to the current value and the input is marked invalid.

The input carries these data attributes:

| Data attribute | Present when |
| --- | --- |
| `[data-invalid]` | The last commit failed, or `value` is outside the limits. |
| `[data-editing]` | The text has been edited and not yet committed. |
| `[data-empty]` | The input is empty. |

### DateField.Range

The range host. Renders a `div` and takes its props. The `locale`, limit,
state and `form` props work as on DateField; `value`, `onChange` and `name`
differ.

<Reference name="DateFieldRangeProps" headingLevel={4} />

### Parts

| Part | Renders | Description |
| --- | --- | --- |
| `DateField.Input` | `input` | The text input of a single field. Takes input props. |
| `DateField.Start` | `input` | The start input of a range. Takes input props. |
| `DateField.End` | `input` | The end input of a range. Takes input props. |
| `DateField.Trigger` | `button` | Opens and closes the picker. Defaults to a calendar icon. |
| `DateField.Picker` | `div` | The pop-up. Takes [Overlay.Content](/overlay) props; `placement` defaults to `'bottom-start'`. |
| `DateField.Calendar` | [Calendar](/calendar) | A calendar bound to the field. Takes Calendar props, all optional. |

The managed props of each input, such as `value`, `role` and the ARIA
state, always win over the ones you pass. Your `onKeyDown`, `onBlur` and
`onClick` run first; call `preventDefault()` in them to skip the field's own
handling.

## Accessibility

Label the input with a `Label` and `htmlFor`, as above. Give
`DateField.Start` and `DateField.End` an `aria-label` each.

With a picker, the input is a combobox and clicking it opens the picker.

The trigger is out of the tab order, and its default icon has no name. Give
it an `aria-label`. Keyboard users open the picker with Alt+ArrowDown.

### Keyboard interactions

| Key | Action |
| --- | --- |
| `Alt` + `ArrowDown` | Opens the picker. |
| `Escape` | Closes the picker. In a range, also drops unsaved edits. |
| `Enter` | Commits the typed text. |
| `ArrowUp` / `ArrowDown` | Steps the day, month or year under the caret by one. |
| `Shift` + `ArrowUp` / `ArrowDown` | Steps it by ten. |

Stepping needs a complete date in the input. A step that lands outside the
limits does nothing.
