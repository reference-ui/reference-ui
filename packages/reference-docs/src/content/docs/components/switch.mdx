# Switch

A control that turns a setting on or off.

<Preview>
  <SwitchDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Label } from '@reference-ui/react'
import { Switch } from '@reference-ui/lib'

export function AirplaneMode() {
  const [enabled, setEnabled] = useState(false)
  return (
    <>
      <Label htmlFor="airplane">Airplane mode</Label>
      <Switch id="airplane" checked={enabled} onChange={setEnabled} />
    </>
  )
}
```

## Import

```tsx
import { Switch } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Switch>
  <Switch.Thumb />
</Switch>
```

`Switch` is the track, a `button`. `Switch.Thumb` is optional: when you
leave it out, Switch renders a default thumb.

### Uncontrolled

Pass `defaultChecked` and leave out `checked`. Switch keeps its own state
and still calls `onChange`.

```tsx
<Label>
  <Switch defaultChecked />
  Notifications
</Label>
```

### Disabled

Pass `disabled` to prevent toggling and dim the control:

```tsx
<Switch disabled aria-label="Sync" />
```

### Custom thumb

Author `Switch.Thumb` to style it. It replaces the default thumb, so there
is always exactly one.

```tsx
<Switch defaultChecked borderRadius="md" aria-label="Compact mode">
  <Switch.Thumb borderRadius="sm" />
</Switch>
```

The thumb moves `1.25rem` when checked, through an inline `transform`. If
you change the track width, set your own `transform` in the thumb's
`style`.

### Forms

Switch does not submit with a form. Add a hidden input for the value:

```tsx
<Switch checked={enabled} onChange={setEnabled} aria-label="Airplane mode" />
<Input type="hidden" name="airplane" value={enabled ? 'on' : 'off'} />
```

### Cancelling a change

Your `onClick` runs before Switch changes. Call `event.preventDefault()` in
it and Switch neither changes nor calls `onChange`.

## API reference

### Switch

Renders a `button` and takes `button` props and style props, except
`role`, `type`, `aria-checked` and `aria-pressed`, which Switch sets.

<Reference name="SwitchProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `[data-state]` | `'checked'` or `'unchecked'` |
| `[data-disabled]` | Present when disabled. |

### Switch.Thumb

Renders a `span` and takes `span` props and style props.

| Data attribute | Values |
| --- | --- |
| `[data-state]` | `'checked'` or `'unchecked'` |
| `[data-disabled]` | Present when disabled. |

## Accessibility

Switch is a `button` with `role="switch"` and `aria-checked`. Name it with
a `label` (`htmlFor` or wrapping), `aria-label` or `aria-labelledby`.
There is no default name.

Text inside the track becomes part of its accessible name, even where the
track hides it. Mark any extra children `aria-hidden`.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Space` | Toggles the switch. |
| `Enter` | Toggles the switch. |
