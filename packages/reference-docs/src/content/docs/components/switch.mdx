# Switch

Switch is a toggle control that turns a setting on or off.

<Preview>
  <SwitchDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Label } from '@reference-ui/react'
import { Switch } from '@reference-ui/lib'

export function AirplaneMode() {
  const [enabled, setEnabled] = useState(false)
  return (
    <>
      <Label htmlFor="airplane">Airplane mode</Label>
      <Switch id="airplane" checked={enabled} onChange={setEnabled} />
    </>
  )
}
```

## Import

```tsx
import { Switch } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Switch>
  <Switch.Thumb />
</Switch>
```

`Switch` renders the outer track as a `button`. `Switch.Thumb` is optional; if
omitted, Switch renders a default thumb automatically.

### Uncontrolled

For uncontrolled state, pass `defaultChecked` and omit `checked`. Switch
manages its own state internally and still calls `onChange` when toggled.

```tsx
<Label>
  <Switch defaultChecked />
  Notifications
</Label>
```

### Disabled

Pass `disabled` to prevent toggling and dim the control:

```tsx
<Switch disabled aria-label="Sync" />
```

### Custom thumb

Pass `Switch.Thumb` as a child to customize its styling. It replaces the
default thumb rather than rendering a second one.

```tsx
<Switch defaultChecked borderRadius="md" aria-label="Compact mode">
  <Switch.Thumb borderRadius="sm" />
</Switch>
```

When checked, the thumb translates by `1.25rem` via an inline `transform`. If
you customize the track width, override `transform` on `Switch.Thumb`'s
`style` prop to match.

### Forms

Switch does not submit a value with a form automatically. Render a hidden
input when you need form submission:

```tsx
<Switch checked={enabled} onChange={setEnabled} aria-label="Airplane mode" />
<Input type="hidden" name="airplane" value={enabled ? 'on' : 'off'} />
```

### Cancelling a change

A custom `onClick` handler runs before Switch toggles. Call
`event.preventDefault()` inside `onClick` to cancel the toggle and skip
`onChange`.

## API reference

### Switch

Renders a `button` and takes `button` props and style props, except
`role`, `type`, `aria-checked` and `aria-pressed`, which Switch sets.

<Reference name="SwitchProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `[data-state]` | `'checked'` or `'unchecked'` |
| `[data-disabled]` | Present when disabled. |

### Switch.Thumb

Renders a `span` and takes `span` props and style props.

| Data attribute | Values |
| --- | --- |
| `[data-state]` | `'checked'` or `'unchecked'` |
| `[data-disabled]` | Present when disabled. |

## Accessibility

Switch renders a `button` with `role="switch"` and `aria-checked`. Provide an
accessible name using a `Label` (via `htmlFor` or wrapping), `aria-label`, or
`aria-labelledby`.

Any text rendered inside the button becomes part of its accessible name, even
if visually clipped by the track. Add `aria-hidden="true"` to decorative
children inside Switch.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Space` | Toggles the switch. |
| `Enter` | Toggles the switch. |
