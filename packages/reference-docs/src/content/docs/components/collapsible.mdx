# Collapsible

Collapsible toggles the visibility of a content section from a trigger button.

<Preview>
  <CollapsibleDemo />
</Preview>

```tsx
import { Collapsible } from '@reference-ui/lib'

<Collapsible>
  <Collapsible.Trigger>Order details</Collapsible.Trigger>
  <Collapsible.Content>Shipped on 12 October.</Collapsible.Content>
</Collapsible>
```

## Import

```tsx
import { Collapsible } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Collapsible>
  <Collapsible.Trigger />
  <Collapsible.Content />
</Collapsible>
```

`Collapsible` renders no DOM element of its own. `Collapsible.Trigger` renders a
`button`, and `Collapsible.Content` renders a `div`.

## Examples

### Controlled

For controlled state, pass `open` and `onOpenChange`.

```tsx
const [open, setOpen] = React.useState(false)

<Collapsible open={open} onOpenChange={setOpen}>
  <Collapsible.Trigger>Order details</Collapsible.Trigger>
  <Collapsible.Content>Shipped on 12 October.</Collapsible.Content>
</Collapsible>
```

### Open by default

Pass `defaultOpen` to render the content expanded initially in uncontrolled mode.

```tsx
<Collapsible defaultOpen>…</Collapsible>
```

### Custom icon

By default, the trigger renders a trailing chevron that rotates when expanded.
Pass `icon` to render a custom icon, or `hideIcon` to omit it.

```tsx
<Collapsible.Trigger icon={<AddIcon />}>Order details</Collapsible.Trigger>
<Collapsible.Trigger hideIcon>Order details</Collapsible.Trigger>
```

### Findable content

Pass `hiddenUntilFound` to keep closed content in the DOM with
`hidden="until-found"`. When the browser's find-in-page matches text inside the
panel, the Collapsible opens automatically. Call `preventDefault()` on the
`beforematch` event to prevent it from opening.

```tsx
<Collapsible hiddenUntilFound>
  <Collapsible.Trigger>Order details</Collapsible.Trigger>
  <Collapsible.Content>Tracking number 1Z 999 AA1 01.</Collapsible.Content>
</Collapsible>
```

## API reference

### Collapsible

Manages the open state for the trigger and content. Renders no DOM element of
its own.

<Reference name="CollapsibleProps" headingLevel={4} />

### Collapsible.Trigger

Toggles the collapsible content. Renders a `button` and accepts standard
`button` props and style props.

<Reference name="CollapsibleTriggerProps" headingLevel={4} />

Only primary clicks toggle the state. Calling `preventDefault()` in `onClick`
cancels the toggle.

| Data attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |
| `data-disabled` | present when disabled |

### Collapsible.Content

The collapsible content container. Renders a `div` and accepts standard `div`
props and style props. Renders nothing if used outside `Collapsible`.

<Reference name="CollapsibleContentProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |
| `data-disabled` | present when disabled |

| CSS variable | Description |
| --- | --- |
| `--reference-collapsible-content-height` | Height of the open content. |
| `--reference-collapsible-content-width` | Width of the open content. |

Content animates its height over 320ms when opening and closing, and disables
the transition when `prefers-reduced-motion` is enabled. It stays mounted until
the exit animation completes, then unmounts unless `forceMount` or
`hiddenUntilFound` is set.

## Accessibility

If focus is inside `Collapsible.Content` when it closes, focus returns to
`Collapsible.Trigger`.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Space` | Opens or closes the content. |
| `Enter` | Opens or closes the content. |
