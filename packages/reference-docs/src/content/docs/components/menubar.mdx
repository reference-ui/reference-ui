# Menubar

Each trigger opens a [Menu](/menu) in a popover, and the arrow keys move along the row.

<Preview>
  <MenubarDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Menu, Menubar } from '@reference-ui/lib'

export function EditorMenubar() {
  const [open, setOpen] = useState<string | null>(null)
  return (
    <Menubar aria-label="Editor" value={open} onChange={setOpen}>
      <Menubar.Menu value="file">
        <Menubar.Trigger>File</Menubar.Trigger>
        <Menubar.Content>
          <Menu.Item>New</Menu.Item>
          <Menu.Item>Open</Menu.Item>
        </Menubar.Content>
      </Menubar.Menu>
      <Menubar.Menu value="edit">
        <Menubar.Trigger>Edit</Menubar.Trigger>
        <Menubar.Content>
          <Menu.Item>Undo</Menu.Item>
          <Menu.Item>Redo</Menu.Item>
        </Menubar.Content>
      </Menubar.Menu>
    </Menubar>
  )
}
```

Menubar is controlled. `value` names the open menu, so opening one closes
the others.

## Import

```tsx
import { Menu, Menubar } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Menubar>
  <Menubar.Menu>
    <Menubar.Trigger />
    <Menubar.Content>
      <Menu.Item />
    </Menubar.Content>
  </Menubar.Menu>
</Menubar>
```

`Menubar.Content` renders a [Menu](/menu) around its children. Put any menu
part inside it: `Menu.Item`, `Menu.CheckboxItem`, `Menu.RadioGroup`,
`Menu.LinkItem`, `Menu.Separator`, or a nested `Menu` for a submenu.

## Examples

### Submenus

Nest a `Menu` inside `Menubar.Content`, as on the [Menu](/menu#submenus)
page.

```tsx
const [recentOpen, setRecentOpen] = useState(false)

<Menubar.Content>
  <Menu.Item>New</Menu.Item>
  <Menu open={recentOpen} onOpen={() => setRecentOpen(true)} onDismiss={() => setRecentOpen(false)}>
    <Menu.Trigger>Open recent</Menu.Trigger>
    <Menu.Content>
      <Menu.Item>notes.md</Menu.Item>
    </Menu.Content>
  </Menu>
</Menubar.Content>
```

### Wrapping at the ends

By default the arrow keys stop at the first and last trigger. Pass `loop`
to wrap around.

```tsx
<Menubar aria-label="Editor" value={open} onChange={setOpen} loop>
```

## API reference

### Menubar

Renders a `div` with `role="menubar"`. Takes `div` props and style props.

<Reference name="MenubarProps" />

### Menubar.Menu

Binds one trigger to one content panel. Renders no element.

<Reference name="MenubarMenuProps" />

### Menubar.Trigger

Renders a `Popover.Trigger` button with `role="menuitem"`. Takes the props
of [`Popover.Trigger`](/popover).

<Reference name="MenubarTriggerProps" />

It sets `data-state` to `open` or `closed`.

### Menubar.Content

Renders a `Popover.Content` with a `Menu` inside. Takes the props of
[`Popover.Content`](/popover), including `placement`.

## Accessibility

Menubar follows the WAI-ARIA Menubar pattern. The bar is one Tab stop, and
focus moves between triggers with a roving tab index. Inside an open menu
the keys are the same as [Menu](/menu#keyboard-interactions).

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` / `ArrowDown` | On a trigger, opens its menu and focuses the first item. |
| `ArrowUp` | On a trigger, opens its menu and focuses the last item. |
| `ArrowRight` / `ArrowLeft` | On a trigger, moves to the next or previous trigger. If a menu is open, that trigger's menu opens in its place. Mirrored right to left. |
| `ArrowRight` / `ArrowLeft` | In an open menu, switches to the next or previous menu. On a submenu trigger, `ArrowRight` opens the submenu instead. |
| `Escape` | Closes the open menu and returns focus to its trigger. |

Disabled triggers are skipped. Give the bar a name with `aria-label`.
