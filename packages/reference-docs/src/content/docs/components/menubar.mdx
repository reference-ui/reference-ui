# Menubar

Menubar displays a horizontal row of menus, such as an application's File,
Edit, and View bar. Each trigger opens a [Menu](/menu) in a popover, with
arrow-key navigation across triggers and items.

<Preview>
  <MenubarDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Menu, Menubar } from '@reference-ui/lib'

export function EditorMenubar() {
  const [open, setOpen] = useState<string | null>(null)
  return (
    <Menubar aria-label="Editor" value={open} onChange={setOpen}>
      <Menubar.Menu value="file">
        <Menubar.Trigger>File</Menubar.Trigger>
        <Menubar.Content>
          <Menu.Item>New</Menu.Item>
          <Menu.Item>Open</Menu.Item>
        </Menubar.Content>
      </Menubar.Menu>
      <Menubar.Menu value="edit">
        <Menubar.Trigger>Edit</Menubar.Trigger>
        <Menubar.Content>
          <Menu.Item>Undo</Menu.Item>
          <Menu.Item>Redo</Menu.Item>
        </Menubar.Content>
      </Menubar.Menu>
    </Menubar>
  )
}
```

Menubar is controlled. `value` holds the active menu's identifier (or `null`
when closed), ensuring only one menu is open at a time.

## Import

```tsx
import { Menu, Menubar } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Menubar>
  <Menubar.Menu>
    <Menubar.Trigger />
    <Menubar.Content>
      <Menu.Item />
    </Menubar.Content>
  </Menubar.Menu>
</Menubar>
```

`Menubar.Content` renders a [Menu](/menu) around its children and accepts any
menu subcomponent: `Menu.Item`, `Menu.CheckboxItem`, `Menu.RadioGroup`,
`Menu.LinkItem`, `Menu.Separator`, or a nested `Menu` for a submenu.

## Examples

### Submenus

Nest a controlled `Menu` inside `Menubar.Content` to create a submenu, just
like in [Menu](/menu#submenus).

```tsx
const [recentOpen, setRecentOpen] = useState(false)

<Menubar.Content>
  <Menu.Item>New</Menu.Item>
  <Menu open={recentOpen} onOpen={() => setRecentOpen(true)} onDismiss={() => setRecentOpen(false)}>
    <Menu.Trigger>Open recent</Menu.Trigger>
    <Menu.Content>
      <Menu.Item>notes.md</Menu.Item>
    </Menu.Content>
  </Menu>
</Menubar.Content>
```

### Looping focus

By default, Left and Right arrow keys stop at the first and last triggers.
Pass `loop` to cycle focus from the last trigger back to the first.

```tsx
<Menubar aria-label="Editor" value={open} onChange={setOpen} loop>
```

## API reference

### Menubar

Renders a `div` with `role="menubar"`. Accepts standard `div` props and style
props.

<Reference name="MenubarProps" headingLevel={4} />

### Menubar.Menu

Associates a trigger with its menu panel. Renders no DOM element of its own.

<Reference name="MenubarMenuProps" headingLevel={4} />

### Menubar.Trigger

Renders a `Popover.Trigger` button with `role="menuitem"`. Accepts the props of
[`Popover.Trigger`](/popover).

<Reference name="MenubarTriggerProps" headingLevel={4} />

Exposes `data-state="open"` or `data-state="closed"`.

### Menubar.Content

Renders a `Popover.Content` with a `Menu` inside. Accepts the props of
[`Popover.Content`](/popover), including `placement`.

## Accessibility

Menubar follows the WAI-ARIA Menubar pattern. The bar acts as a single Tab stop
using a roving `tabIndex` across triggers, and open menus support the same
keyboard shortcuts as [Menu](/menu#keyboard-interactions).

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` / `ArrowDown` | On a trigger, opens its menu and focuses the first item. |
| `ArrowUp` | On a trigger, opens its menu and focuses the last item. |
| `ArrowRight` / `ArrowLeft` | On a trigger, moves focus to the next or previous trigger. If a menu is already open, the newly focused trigger's menu opens automatically. Reversed in right-to-left layouts. |
| `ArrowRight` / `ArrowLeft` | In an open menu, switches to the next or previous menu. On a submenu trigger, `ArrowRight` opens the submenu instead. |
| `Escape` | Closes the open menu and returns focus to its trigger. |

Disabled triggers are skipped during keyboard navigation. Provide an accessible
label for the menubar using `aria-label` or `aria-labelledby`.
