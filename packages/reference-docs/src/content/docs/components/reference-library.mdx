# ReferenceLibrary

ReferenceLibrary mounts the document-level runtimes: the [Toast](/toast)
host, the live region behind [`announce()`](/announce), and the
[Tooltip](/tooltip) skip-delay group. Mount it once near your app root.

```tsx
import '@reference-ui/lib/styles.css'
import { ReferenceLibrary } from '@reference-ui/lib'

<ReferenceLibrary toaster={{ defaultPosition: 'bottom-end', limit: 4 }}>
  <App />
</ReferenceLibrary>
```

It is not a context provider. Children render as they are, and Overlay,
Popover, and Menu work with or without it.

## Behaviour

- Mounting more than one is safe: the earliest live mount hosts the
  runtimes, and another takes over if it unmounts.
- Mount it inside your `colorMode` root so toasts follow light and dark
  mode. That root must not set `transform`, `filter`, `contain`, or
  `container-type`, because the toast stack is `position: fixed`.
- On the server it renders only its children.
