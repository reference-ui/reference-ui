# Combobox

Combobox pairs a text input or trigger button with a popup list of options for
autocomplete, searchable selects, and standard select menus. DOM focus remains
on the input or button while arrow keys move the active highlight through the
list.

<Preview>
  <ComboboxDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Combobox, Field, Listbox } from '@reference-ui/lib'

const frameworks = [
  { value: 'react', label: 'React' },
  { value: 'vue', label: 'Vue' },
  { value: 'svelte', label: 'Svelte' },
]

export function FrameworkPicker() {
  const [value, setValue] = useState<string | null>(null)
  const [query, setQuery] = useState('')
  const visible = frameworks.filter(f =>
    f.label.toLowerCase().includes(query.toLowerCase())
  )
  return (
    <Combobox
      value={value}
      onChange={next => {
        setValue(next)
        setQuery(frameworks.find(f => f.value === next)?.label ?? '')
      }}
      inputValue={query}
      onInputValueChange={setQuery}
    >
      <Field>
        <Combobox.Input aria-label="Framework" />
      </Field>
      <Combobox.Popover>
        <Listbox>
          {visible.map(f => (
            <Listbox.Option key={f.value} value={f.value}>
              {f.label}
            </Listbox.Option>
          ))}
        </Listbox>
      </Combobox.Popover>
    </Combobox>
  )
}
```

Combobox does not filter options automatically. You filter the rendered
options based on `inputValue`, while Combobox manages keyboard navigation,
selection, and popup dismissal.

## Import

```tsx
import { Combobox } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Combobox>
  <Field>
    <Combobox.Input />
  </Field>
  <Combobox.Popover>
    <Listbox>
      <Combobox.Section>
        <Combobox.Option />
      </Combobox.Section>
      <Combobox.Empty />
    </Listbox>
  </Combobox.Popover>
</Combobox>
```

`Combobox` renders no wrapper element. Pair `Combobox.Popover` with either
`Combobox.Input` for a text input or `Combobox.Trigger` for a select button
(not both). Inside the popover, render a [Listbox](/listbox) or a
[Tree](/tree).

`Combobox.Option`, `Combobox.Section`, and `Combobox.Empty` are aliases for
`Listbox.Option`, `Listbox.Section`, and `Listbox.Empty`.

## Examples

### Select

For a select menu without text filtering, render `Combobox.Trigger` instead of
`Combobox.Input`. Pass the current selection label as its children.

<Preview>
  <ComboboxSelectDemo />
</Preview>

```tsx
<Combobox value={value} onChange={setValue}>
  <Combobox.Trigger aria-label="Framework">
    {labelOf(value) || 'Select a framework'}
  </Combobox.Trigger>
  <Combobox.Popover>
    <Listbox>
      <Listbox.Option value="react">React</Listbox.Option>
      <Listbox.Option value="vue">Vue</Listbox.Option>
    </Listbox>
  </Combobox.Popover>
</Combobox>
```

### Groups and empty state

Group related options under a heading with `Combobox.Section`, and render
`Combobox.Empty` when no options match the query.

```tsx
<Combobox.Popover>
  <Listbox>
    {visible.length > 0 ? (
      <Combobox.Section title="Frontend">
        <Combobox.Option value="react">React</Combobox.Option>
        <Combobox.Option value="vue">Vue</Combobox.Option>
      </Combobox.Section>
    ) : (
      <Combobox.Empty>No frameworks found</Combobox.Empty>
    )}
  </Listbox>
</Combobox.Popover>
```

### Inline completion

Set `autocomplete="inline"` or `"both"` to complete the active option's label
inline after the typed text, with the suggested suffix selected.

```tsx
<Combobox autocomplete="both" value={value} onChange={setValue}>…</Combobox>
```

### Custom values

By default, unrecognised text reverts to the selected option's label on blur.
Set `allowCustomValue` to commit arbitrary typed text as the value on Enter,
Tab, or blur. Clearing the input commits `null`.

```tsx
<Combobox allowCustomValue value={value} onChange={setValue}>…</Combobox>
```

### Loading

Set `loading` while options are being fetched asynchronously. This marks the
listbox with `aria-busy="true"` and suppresses empty-state announcements.

```tsx
<Combobox loading={isFetching} value={value} onChange={setValue}>…</Combobox>
```

## API reference

### Combobox

Manages selection, input text, and open state without rendering a DOM element.
Combobox is always controlled: `value` and `onChange` are required.

<Reference name="ComboboxProps" headingLevel={4} />

When controlling `inputValue`, update the input text inside `onChange` when an
option is selected, as shown in the first example. When `inputValue` is
uncontrolled, Combobox automatically sets it to the selected option's label.

### Combobox.Input

Renders the text input. Accepts standard `input` props and style props, except
`value`, `defaultValue`, and `onChange` (use `inputValue` and
`onInputValueChange` on Combobox instead). To intercept edits before they
apply, use `onBeforeInput`.

Focusing the input alone does not open the popover; typing, clicking, or
pressing an arrow key opens it. When `Combobox.Input` is wrapped in a
[Field](/field), the popover anchors to the outer Field border.

### Combobox.Trigger

Renders the trigger button for a select-only combobox. Accepts standard
`button` props and style props, defaulting to `type="button"`. Clicking
toggles the popover.

### Combobox.Popover

Renders the popup container. Accepts `div` props, style props, and the
positioning props of [`Overlay.Content`](/overlay). By default, it positions
below the control aligned to its start edge, matches at least the control's
width, and applies default panel styling that can be overridden with style
props.

<Reference name="ComboboxPopoverProps" headingLevel={4} />

### Combobox.Option

Alias for `Listbox.Option`. Accepts `value`, `textValue`, `disabled`, and
standard `div` props. See [Listbox](/listbox).

### Combobox.Section

Alias for `Listbox.Section`. Groups options under an optional `title` heading.

### Combobox.Empty

Alias for `Listbox.Empty`. Renders a `role="status"` message when no options
are present, defaulting to `"No results found"`. Rendering `Combobox.Empty`
suppresses the live-region announcements from `emptyMessage` and
`noResultsMessage`.

## Accessibility

Provide an accessible name for the input or trigger using a `Label` or
`aria-label`. DOM focus stays on the control while the highlighted option is
communicated to assistive technologies via `aria-activedescendant`.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `ArrowDown` | Opens the list, or moves to the next option. Wraps at the end. |
| `ArrowUp` | Opens the list, or moves to the previous option. Wraps at the start. |
| `Enter` | Selects the active option and closes. With no active option, resolves the text and closes. When the list is closed, the trigger opens it and the input leaves `Enter` to the form. |
| `Space` | On the trigger, opens the list or selects the active option. |
| `Tab` | If an option was highlighted via the keyboard or typing, selects it and closes the list before moving focus to the next element. Options highlighted only by pointer hover are not selected on `Tab`. |
| `Escape` | Closes the list. In the input, restores the text of the selected option. |
| `Home` / `End` | On the trigger, moves to the first or last option. |
| `ArrowRight` / `ArrowLeft` | With a [Tree](/tree) list, expands or collapses the active branch. |
| Letter keys | On the trigger, opens the list, then moves to the next option that starts with the typed text. |

Opening with an arrow key makes the selected option active, or else the
first option (`ArrowDown`) or the last (`ArrowUp`). Typing in the input makes
the first rendered option active.
