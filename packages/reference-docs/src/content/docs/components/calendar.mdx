# Calendar

Calendar renders a month grid for selecting a single date, date range, month,
or year. Values use ISO strings rather than `Date` objects.

<Preview>
  <CalendarDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Calendar, type ISODate } from '@reference-ui/lib'

export function DueDate() {
  const [date, setDate] = useState<ISODate | null>(null)
  return <Calendar value={date} onChange={setDate} locale="en-GB" />
}
```

Calendar does not parse typed dates. For a text input, use
[DateField](/date-field).

## Import

```tsx
import {
  Calendar,
  type DateRangeValue,
  type ISODate,
  type ISOMonth,
  type ISOYear,
} from '@reference-ui/lib'
```

## Anatomy

```tsx
<Calendar>
  <Calendar.Header>
    <Calendar.PrevButton />
    <Calendar.Heading>
      <Calendar.Month />
      <Calendar.Year />
    </Calendar.Heading>
    <Calendar.NextButton />
  </Calendar.Header>
  <Calendar.Grid>
    <Calendar.Weekdays />
    <Calendar.Days>
      {(day) => <Calendar.Day date={day.date}>{day.formattedDay}</Calendar.Day>}
    </Calendar.Days>
  </Calendar.Grid>
  <Calendar.Months />
  <Calendar.Years />
</Calendar>
```

Without children, Calendar renders this default layout. Pass any part as a
child to customize it; omitted parts use their defaults.

The day grid, month picker, and year picker are three views within a single
calendar, with one visible at a time. Clicking `Calendar.Month` or
`Calendar.Year` in the header switches to that view; selecting a month or year
updates the visible month and returns to the day grid.

## Examples

### Range

Set `mode="range"` to select a date range. The first click sets the start
date and the second sets the end date. Selecting a date earlier than the
start date swaps the two.

<Preview>
  <CalendarRangeDemo />
</Preview>

```tsx
const [stay, setStay] = useState<DateRangeValue | null>(null)

<Calendar mode="range" value={stay} onChange={setStay} locale="en-GB" />
```

After the first click, the value is `{ start, end: null }`. Before the end
date is selected, hovering or focusing a day previews the range. Selecting a
range across an unavailable date is ignored, keeping the current start date.

### Month or year

Set `mode="month"` to select a `'YYYY-MM'` month or `mode="year"` to select a
`'YYYY'` year. Calendar opens directly in the corresponding view.

```tsx
const [month, setMonth] = useState<ISOMonth | null>(null)

<Calendar mode="month" value={month} onChange={setMonth} locale="en-GB" />
```

### Limits

Use `min` and `max` to disable dates outside a range, and `isDateUnavailable`
to mark specific dates as unavailable.

```tsx
const isWeekend = (date: ISODate) => [0, 6].includes(new Date(date).getUTCDay())

<Calendar
  value={date}
  onChange={setDate}
  locale="en-GB"
  min="2026-01-01"
  max="2026-12-31"
  isDateUnavailable={isWeekend}
/>
```

Dates outside `min` and `max` are disabled and skipped during arrow-key
navigation. Unavailable dates remain focusable so keyboard users can navigate
past them, but cannot be selected.

### Custom days

Pass a render function to `Calendar.Days` to customize each cell based on its
state. The function must return a `Calendar.Day` with the matching `date`
prop; Calendar continues to manage selection, focus, and ARIA attributes.

```tsx
<Calendar value={date} onChange={setDate} locale="en-GB">
  <Calendar.Grid>
    <Calendar.Days>
      {(day) => (
        <Calendar.Day date={day.date}>
          {day.formattedDay}
          {holidays.has(day.date) ? ' •' : null}
        </Calendar.Day>
      )}
    </Calendar.Days>
  </Calendar.Grid>
</Calendar>
```

To customize only the inner content of each day button, pass the `Day` prop
on Calendar instead: `Day={(date, state) => node}`. Return `null` to fall
back to the default day number.

### Server rendering

By default, Calendar determines today's date in the browser after mounting, so
no today marker is rendered on the server. Pass `today` to render a consistent
initial month and today marker across server and client:

```tsx
<Calendar value={date} onChange={setDate} locale="en-GB" today="2026-10-17" />
```

## API reference

### Calendar

The root container. Renders a `div` and accepts standard `div` props and style
props.

<Reference name="CalendarProps" headingLevel={4} />

The types of `value` and `onChange` depend on `mode`:

| Mode | `value` type | Format |
| --- | --- | --- |
| `day` | `ISODate \| null` | `'2026-10-17'` |
| `range` | `DateRangeValue \| null` | `{ start: '2026-10-17', end: '2026-10-20' }`; `end` is `null` until picked. |
| `month` | `ISOMonth \| null` | `'2026-10'` |
| `year` | `ISOYear \| null` | `'2026'` |

`onChange` is never called with `null`, and re-selecting the current value
does not trigger it. When `month` is uncontrolled, the initial visible month
defaults to `value`, then `today`, then the current system month. When `month`
is controlled, Calendar calls `onMonthChange` instead of updating the visible
month internally.

If props are invalid (such as a malformed date string, a missing `locale`, or
`min` after `max`), Calendar renders nothing and logs a warning in
development.

| Data attribute | Values |
| --- | --- |
| `[data-mode]` | `day`, `range`, `month`, `year` |
| `[data-view]` | `day`, `month`, `year` |

### Header parts

| Part | Renders | Description |
| --- | --- | --- |
| `Calendar.Header` | `div` | Header container above the grid. |
| `Calendar.PrevButton` | `button` | Navigates to the previous month, with an accessible label naming that month. Defaults to `‹`. |
| `Calendar.NextButton` | `button` | Navigates to the next month, with an accessible label naming that month. Defaults to `›`. |
| `Calendar.Heading` | `div` | Displays the visible month and year. Passing children replaces the default text. |
| `Calendar.Month` | `button` | Toggles the months view. Sets `aria-pressed` while that view is active. |
| `Calendar.Year` | `button` | Toggles the years view. Sets `aria-pressed` while that view is active. |

The previous and next buttons are disabled outside the days view, or when the
adjacent month contains no selectable dates.

### Calendar.Grid

Renders the day grid as a `table` with `role="grid"`, labelled by the
heading unless you provide `aria-label` or `aria-labelledby`. Only
`Calendar.Weekdays` and `Calendar.Days` are valid children.

### Calendar.Weekdays

Renders a `thead` containing the locale-ordered weekday headers. Does not
accept children.

### Calendar.Day

Renders an individual day cell as a `button`.

<Reference name="CalendarDayProps" headingLevel={4} />

Custom styles, event handlers, and refs are merged onto the button, while
Calendar controls `id`, `tabIndex`, `disabled`, and ARIA attributes.

| Data attribute | Present when |
| --- | --- |
| `[data-date]` | Always. Holds the ISO date. |
| `[data-selected]` | The date is selected. |
| `[data-in-range]` | Inside a selected range. |
| `[data-range-start]` | First date of a range. |
| `[data-range-end]` | Last date of a range. |
| `[data-outside-month]` | The date belongs to the previous or next month. |
| `[data-today]` | The date is today. |
| `[data-disabled]` | Outside `min` and `max`. |
| `[data-unavailable]` | Marked unavailable by `isDateUnavailable`. |
| `[data-focused]` | The day that receives focus when tabbing into the grid. |

### Calendar.Months

Renders a three-column `div` of twelve month buttons. Selecting a month
navigates the day grid in `day` and `range` modes, or commits the value in
`month` mode.

### Calendar.Years

Renders a three-column `div` of year buttons. Displays a 21-year window
centered on the visible year, or the full range between `min` and `max` when
both are set.

## Accessibility

The grid is labelled by the heading, and screen readers announce the new
month after navigation. Each day button is labelled with its full date.

Only one day is in the tab order at a time. Arrow-key navigation moves focus
and switches months when crossing a month boundary, without changing the
selected value.

### Keyboard interactions

In the days view:

| Key | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Moves to the previous or next day. Reversed in a right-to-left `dir`. |
| `ArrowUp` / `ArrowDown` | Moves to the same weekday in the previous or next week. |
| `Home` / `End` | Moves to the first or last day of the week. |
| `PageUp` / `PageDown` | Moves to the same day in the previous or next month. |
| `Enter` / `Space` | Selects the focused day. |
| `Tab` | In `range` mode with a start picked, completes the previewed range, then leaves the grid. |

The arrow keys skip dates outside `min` and `max`.

In the months and years views, `ArrowLeft` and `ArrowRight` move one cell,
`ArrowUp` and `ArrowDown` move one row, and `Enter` or `Space` presses the
focused cell.
