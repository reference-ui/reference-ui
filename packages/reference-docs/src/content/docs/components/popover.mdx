# Popover

Popover opens a panel from a button. Focus can move freely in and out of
it, and the rest of the page stays usable.

<Preview>
  <PopoverDemo />
</Preview>

```tsx
import { Popover } from '@reference-ui/lib'

<Popover>
  <Popover.Trigger>Open filters</Popover.Trigger>
  <Popover.Content>
    Interactive content anchored to the trigger.
    <Popover.Close>Close</Popover.Close>
  </Popover.Content>
</Popover>
```

Popover is an [Overlay](/overlay) with isolation off. For a panel that
traps focus and blocks the page, use Overlay.

## Import

```tsx
import { Popover } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Popover>
  <Popover.Trigger />
  <Popover.Portal>
    <Popover.Content>
      <Popover.Close />
      <Popover.Arrow />
    </Popover.Content>
  </Popover.Portal>
</Popover>
```

`Popover` renders no element of its own. `Popover.Trigger` and
`Popover.Close` render a `button`, and `Popover.Content` a `div`.

Content has no panel style of its own. Give it a background, border and
padding with style props or a class.

## Examples

### Hover card

With `openOnHover`, the popover also opens when the pointer rests on the
trigger, and when the trigger gets keyboard focus.

<Preview>
  <PopoverHoverDemo />
</Preview>

```tsx
<Popover openOnHover>
  <Popover.Trigger>@reference-ui</Popover.Trigger>
  <Popover.Content>Components and a design system compiled at build time.</Popover.Content>
</Popover>
```

It closes when both the pointer and focus have left the trigger and the
content. The pointer can cross the gap between them without closing it.

### Controlled

Pass `open` and `onOpenChange` to own the state.

```tsx
const [open, setOpen] = React.useState(false)

<Popover open={open} onOpenChange={setOpen}>
  <Popover.Trigger>Open filters</Popover.Trigger>
  <Popover.Content>…</Popover.Content>
</Popover>
```

### Placement

Content sits below the trigger, aligned to its start edge. Pass `placement`
and `offset` to move it. It flips and shifts to stay in the viewport.

```tsx
<Popover.Content placement="top" offset={12}>…</Popover.Content>
```

### Custom anchor

Pass `anchor` to position against another element, a ref, or a point
instead of the trigger.

```tsx
const rowRef = React.useRef<HTMLDivElement>(null)

<Div ref={rowRef}>
  <Popover anchor={rowRef}>
    <Popover.Trigger>Details</Popover.Trigger>
    <Popover.Content>…</Popover.Content>
  </Popover>
</Div>
```

### Keep open on outside press

Call `preventDefault()` in `onOutsidePress` or `onEscape` to keep the
popover open.

```tsx
<Popover onOutsidePress={event => event.preventDefault()}>…</Popover>
```

## API reference

### Popover

Holds the open state. Renders only its children.

<Reference name="PopoverProps" headingLevel={4} />

### Popover.Trigger

The button that opens and closes the popover. Takes `button` props and style
props. A click toggles; calling `preventDefault()` in your `onClick` stops
it.

### Popover.Content

The panel. Takes `div` props and style props, plus the positioning props of
[`Overlay.Content`](/overlay). Outside a `Popover` it renders nothing.

<Reference name="PopoverContentProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |
| `data-side` | `top`, `right`, `bottom`, `left` |
| `data-align` | `start`, `center`, `end` |

| CSS variable | Description |
| --- | --- |
| `--reference-overlay-anchor-width` | Width of the anchor. |
| `--reference-overlay-anchor-height` | Height of the anchor. |
| `--reference-overlay-available-width` | Width of the viewport, less `collisionPadding` on each side. |
| `--reference-overlay-available-height` | Height of the viewport, less `collisionPadding` on each side. |
| `--reference-overlay-transform-origin` | Origin for an open or close animation. |

### Popover.Close

A button that closes the popover. Takes `button` props and style props.
Calling `preventDefault()` in your `onClick` keeps it open.

### Popover.Portal

Optional. Sets where Content is portalled.

<Reference name="PopoverPortalProps" headingLevel={4} />

### Popover.Arrow

An optional box positioned against the anchor. Takes `div` props and style
props. Give it a shape with your own styles.

<Reference name="PopoverArrowProps" headingLevel={4} />

## Accessibility

- Content has `role="dialog"`. Give it a label with `aria-label` or
  `aria-labelledby`.
- The trigger has `aria-haspopup="dialog"`. Pass `aria-haspopup` to change
  it, for example to `"menu"`.
- A hover card does not open on touch.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Space` | On the trigger, opens or closes the popover. |
| `Enter` | On the trigger, opens or closes the popover. |
| `Tab` | From the open trigger, moves focus into Content. From the last control in Content, closes the popover and moves on to the next control after the trigger. |
| `Shift + Tab` | From the first control in Content, moves focus back to the trigger. |
| `Escape` | Closes the popover. If focus was inside, it returns to the trigger. |
