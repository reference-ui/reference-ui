# Popover

Popover displays a non-modal panel anchored to a trigger button. Focus moves
freely in and out of the panel while the rest of the page remains interactive.

<Preview>
  <PopoverDemo />
</Preview>

```tsx
import { Popover } from '@reference-ui/lib'

<Popover>
  <Popover.Trigger>Open filters</Popover.Trigger>
  <Popover.Content>
    Interactive content anchored to the trigger.
    <Popover.Close>Close</Popover.Close>
  </Popover.Content>
</Popover>
```

Popover is built on [Overlay](/overlay) with isolation disabled. For a modal
surface that traps focus and blocks background interaction, use `Overlay`
directly.

## Import

```tsx
import { Popover } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Popover>
  <Popover.Trigger />
  <Popover.Portal>
    <Popover.Content>
      <Popover.Close />
      <Popover.Arrow />
    </Popover.Content>
  </Popover.Portal>
</Popover>
```

`Popover` renders no DOM element of its own. `Popover.Trigger` and
`Popover.Close` render a `button`, and `Popover.Content` renders a `div`.

`Popover.Content` is unstyled by default; apply a background, border, and
padding using style props or `className`.

## Examples

### Hover card

Pass `openOnHover` to open the popover when hovering or focusing the trigger.

<Preview>
  <PopoverHoverDemo />
</Preview>

```tsx
<Popover openOnHover>
  <Popover.Trigger>@reference-ui</Popover.Trigger>
  <Popover.Content>Components and a design system compiled at build time.</Popover.Content>
</Popover>
```

The popover closes once both the pointer and keyboard focus leave the trigger
and content, allowing the pointer to move across the gap between them without
dismissing the panel.

### Controlled

For controlled state, pass `open` and `onOpenChange`.

```tsx
const [open, setOpen] = React.useState(false)

<Popover open={open} onOpenChange={setOpen}>
  <Popover.Trigger>Open filters</Popover.Trigger>
  <Popover.Content>…</Popover.Content>
</Popover>
```

### Placement

By default, `Popover.Content` is positioned below the trigger and aligned to its
start edge (`bottom-start`). Pass `placement` and `offset` to adjust its
position; the panel automatically flips and shifts to stay within the viewport.

```tsx
<Popover.Content placement="top" offset={12}>…</Popover.Content>
```

### Custom anchor

Pass `anchor` to position the popover against a different element, ref, or
coordinate point instead of `Popover.Trigger`.

```tsx
const rowRef = React.useRef<HTMLDivElement>(null)

<Div ref={rowRef}>
  <Popover anchor={rowRef}>
    <Popover.Trigger>Details</Popover.Trigger>
    <Popover.Content>…</Popover.Content>
  </Popover>
</Div>
```

### Keep open on outside press

Call `preventDefault()` in `onOutsidePress` or `onEscape` to keep the
popover open.

```tsx
<Popover onOutsidePress={event => event.preventDefault()}>…</Popover>
```

## API reference

### Popover

Manages open state and positioning for the popover. Renders no DOM element of
its own.

<Reference name="PopoverProps" headingLevel={4} />

### Popover.Trigger

The button that toggles the popover. Accepts standard `button` props and style
props. Calling `preventDefault()` in `onClick` cancels the toggle.

### Popover.Content

The floating popover panel. Accepts standard `div` props, style props, and the
positioning props of [`Overlay.Content`](/overlay). Renders nothing if used
outside `Popover`.

<Reference name="PopoverContentProps" headingLevel={4} />

| Data attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |
| `data-side` | `top`, `right`, `bottom`, `left` |
| `data-align` | `start`, `center`, `end` |

| CSS variable | Description |
| --- | --- |
| `--reference-overlay-anchor-width` | Width of the anchor. |
| `--reference-overlay-anchor-height` | Height of the anchor. |
| `--reference-overlay-available-width` | Width of the viewport, minus `collisionPadding` on each side. |
| `--reference-overlay-available-height` | Height of the viewport, minus `collisionPadding` on each side. |
| `--reference-overlay-transform-origin` | Origin for an open or close animation. |

### Popover.Close

A button that dismisses the popover. Accepts standard `button` props and style
props. Calling `preventDefault()` in `onClick` prevents the popover from
closing.

### Popover.Portal

Optional portal wrapper that configures the DOM container where
`Popover.Content` is rendered.

<Reference name="PopoverPortalProps" headingLevel={4} />

### Popover.Arrow

An optional arrow element positioned along the panel edge facing the anchor.
Accepts standard `div` props and style props; style its shape with custom CSS.

<Reference name="PopoverArrowProps" headingLevel={4} />

## Accessibility

- Content has `role="dialog"`. Give it a label with `aria-label` or
  `aria-labelledby`.
- The trigger has `aria-haspopup="dialog"`. Pass `aria-haspopup` to change
  it, for example to `"menu"`.
- Hover-triggered popovers (`openOnHover`) do not open on touch devices.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Space` | On the trigger, opens or closes the popover. |
| `Enter` | On the trigger, opens or closes the popover. |
| `Tab` | From the open trigger, moves focus into Content. From the last control in Content, closes the popover and moves on to the next control after the trigger. |
| `Shift + Tab` | From the first control in Content, moves focus back to the trigger. |
| `Escape` | Closes the popover. If focus was inside, it returns to the trigger. |
