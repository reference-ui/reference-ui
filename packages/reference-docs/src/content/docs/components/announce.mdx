# announce

`announce()` sends a message to screen readers through a visually hidden live
region without rendering anything visible on screen. Use it to communicate
dynamic status changes, such as filter result counts or background updates.

```tsx
import { announce } from '@reference-ui/lib'

announce('3 results')
announce('Connection lost', { politeness: 'assertive' })
```

The live region is rendered by [ReferenceLibrary](/reference-library). Mount
it once near your app root.

## Import

```tsx
import { announce, type AnnounceOptions } from '@reference-ui/lib'
```

## API

Call `announce` with the message string and optional politeness or document
settings:

```ts
announce(message: string, options?: AnnounceOptions): void
```

## Behaviour

- Repeating the same message consecutively still triggers a new announcement.
- Empty or whitespace-only messages are ignored.
- Messages queued before ReferenceLibrary mounts are buffered and announced
  once it mounts.
- When multiple documents have a ReferenceLibrary mounted (such as the main
  window and a same-origin iframe), pass the target `document` option;
  otherwise the call is ignored.
- [Toast](/toast) uses this same live region when configured with its
  `announce` option.

## Accessibility

Polite messages are written to a `role="status"` region, and assertive
messages to a `role="alert"` region. Both regions remain outside inert
containers so announcements stay audible while a modal [Overlay](/overlay) is
open.
