# Tree

Tree displays hierarchical data such as a file browser or outline, with
expandable branches and single-item selection.

<Preview>
  <TreeDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Tree } from '@reference-ui/lib'

export function Files() {
  const [selected, setSelected] = useState<string | null>(null)
  const [expanded, setExpanded] = useState<string[]>(['src'])
  return (
    <Tree
      aria-label="Files"
      value={selected}
      onChange={setSelected}
      expanded={expanded}
      onExpandedChange={setExpanded}
    >
      <Tree.Item value="src">
        <Tree.Expander />
        src
        <Tree.Group>
          <Tree.Item value="src/index">index.ts</Tree.Item>
        </Tree.Group>
      </Tree.Item>
      <Tree.Item value="readme">README.md</Tree.Item>
    </Tree>
  )
}
```

## Import

```tsx
import { Tree } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Tree>
  <Tree.Item>
    <Tree.Expander />
    <Tree.Group>
      <Tree.Item />
    </Tree.Group>
  </Tree.Item>
</Tree>
```

A `Tree.Item` that contains a `Tree.Group` acts as a branch. `Tree.Group` holds
the branch's nested items and renders only while the branch is expanded,
removing collapsed descendants from the keyboard navigation order.

Selection is controlled: pass the selected item's value (or `null` when nothing
is selected) to `value` and handle updates with `onChange`. Omitting either
prop throws an error (unless used inside a `Combobox`).

## Examples

### Uncontrolled expansion

Omit `expanded` to let `Tree` manage branch expansion internally. Pass
`defaultExpanded` to specify which branches start open, and `onExpandedChange`
to listen for expansion changes.

```tsx
<Tree aria-label="Files" value={selected} onChange={setSelected} defaultExpanded={['src']}>
  …
</Tree>
```

### Disabled items

Set `disabled` on a `Tree.Item` to prevent it from being focused, selected, or
expanded, or set `disabled` on `Tree` to disable all items.

```tsx
<Tree.Item value="dist" disabled>dist</Tree.Item>
```

### Typeahead text

Typing characters moves focus to the next visible item whose label starts with
that prefix. Pass `textValue` when an item contains icons or non-text elements
so typeahead matches the expected label.

```tsx
<Tree.Item value="readme" textValue="readme">
  <FileIcon /> README.md
</Tree.Item>
```

### Branches without children yet

Set `isBranch` on a `Tree.Item` whose children are loaded asynchronously so it
renders as an expandable branch with `aria-expanded` before its `Tree.Group` is
populated.

### Inside a Combobox

When rendered inside a [Combobox](/combobox) popup, `Tree` delegates selection
state to the `Combobox`. Omit `value` and `onChange`: the `Combobox` selection
is reflected automatically, and DOM focus stays in the text input while arrow
keys navigate the tree.

## API reference

### Tree

The root tree container. Renders a `div` with `role="tree"`.

<Reference name="TreeProps" headingLevel={4} />

| Attribute | Values |
| --- | --- |
| `[data-disabled]` | Present when `disabled`. |

### Tree.Item

An individual tree node. Renders a `div` with `role="treeitem"`. When the item
is a branch, its label content is wrapped in a `[data-slot="row"]` element
followed by its `Tree.Group`.

<Reference name="TreeItemProps" headingLevel={4} />

| Attribute | Values |
| --- | --- |
| `[data-state]` | `selected`, `unselected` |
| `[data-selected]` | Present when selected. |
| `[data-expanded]` | Present when an expanded branch. |
| `[data-disabled]` | Present when disabled. |
| `[data-active]` | Present on the item that holds the tab stop. |
| `[data-level]` | Nesting depth, starting at `1`. |

### Tree.Group

The nested container for a branch's child items. Renders an indented `div` with
`role="group"` only while its parent branch is expanded.

### Tree.Expander

A button that toggles its parent branch open or closed without changing
selection. Excluded from the Tab order because branches are expanded and
collapsed with the arrow keys.

## Accessibility

Tree follows the [WAI-ARIA Tree View pattern](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/).

Give the Tree an accessible name with `aria-label` or `aria-labelledby`.

Only one item is in the Tab order at a time: the selected item if visible, or
the first visible item otherwise. If a branch is collapsed while focus is on
one of its descendants, focus moves to that branch item.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `ArrowDown` | Moves focus to the next visible item. |
| `ArrowUp` | Moves focus to the previous visible item. |
| `ArrowRight` | Opens a closed branch. On an open branch, moves focus to its first child. |
| `ArrowLeft` | Closes an open branch. Otherwise, moves focus to the parent. |
| `Home` | Moves focus to the first visible item. |
| `End` | Moves focus to the last visible item. |
| `Enter` / `Space` | Selects the focused item. |
| `*` | On a closed branch, opens it. On an open branch, opens every closed sibling branch. On a leaf, opens the first closed sibling branch. |
| Characters | Moves focus to the next visible item whose text starts with the typed characters. Typing the same letter again cycles through matches. |

In right-to-left layouts, `ArrowRight` and `ArrowLeft` are reversed. Disabled
items are skipped.
