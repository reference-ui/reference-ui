# Reference

Reference renders an API reference table for a TypeScript type, including its
properties, types, JSDoc descriptions, and inherited types.

<Preview>
  <ReferenceDemo />
</Preview>

```tsx
import { Reference } from '@reference-ui/lib'

<Reference name="ToastActionOption" />
```

## Import

Import `Reference` from `@reference-ui/lib` for library types, or from
`@reference-ui/types` for your project's own types:

```tsx
// The library's own types, such as ToastOptions or SwitchProps
import { Reference } from '@reference-ui/lib'

// Your project's types
import { Reference } from '@reference-ui/types'
```

`ref sync` generates `@reference-ui/types` from the files matched by your
config's `include` patterns, making any exported interface or type alias
available by name.

## Behaviour

- Type metadata loads lazily in the browser, so Reference renders a loading
  state initially.
- During server rendering, it outputs the loading state without fetching.
- If a type cannot be loaded, Reference renders an error message in place of
  the table.
