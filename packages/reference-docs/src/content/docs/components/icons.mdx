# Icons

The Material Symbols icon set, one React component per icon, in an outline
and a filled variant.

<Preview>
  <IconsDemo />
</Preview>

```tsx
import { HomeIcon, SearchIcon } from '@reference-ui/lib'

<SearchIcon />
<HomeIcon variant="filled" size="lg" />
```

## Import

Icons are named after their Material Symbols name in PascalCase, followed by
`Icon`: `search` is `SearchIcon` and `account_circle` is
`AccountCircleIcon`. Names that start with a digit take an `Icon` prefix, so
`10k` is `Icon10kIcon`.

```tsx
import { AccountCircleIcon, SearchIcon } from '@reference-ui/lib'
```

The same components ship on their own in `@reference-ui/icons`, for projects
that don't use the library:

```tsx
import { SearchIcon } from '@reference-ui/icons'
```

## Examples

### Size

`size` sets width and height. It takes `sm` (16px), `md` (20px) or `lg`
(24px), a number of pixels, an `r` value, or any CSS length.

```tsx
<SearchIcon size="sm" />
<SearchIcon size={32} />
<SearchIcon size="8r" />
<SearchIcon size="1.5rem" />
```

### Variant

```tsx
<HomeIcon />
<HomeIcon variant="filled" />
```

### Colour

Icons follow the text colour. Set `color` to change it.

```tsx
<Span color="red.600">
  <WarningIcon /> Payment failed
</Span>
<CheckIcon color="green.600" />
```

### Style props

Icons take style props like any other component, and resolve them against
your tokens:

```tsx
<CheckIcon marginLeft="3r" _hover={{ opacity: 0.7 }} />
```

This needs the icons' system in `extends` or `layers` in `ui.config.ts`.
The library's `baseSystem` carries it, and `ref init` puts that in `extends`.
Without `@reference-ui/lib`, add the icons' own system to `layers`:

```ts
// ui.config.ts
import { defineConfig } from '@reference-ui/core'
import { baseSystem as iconsSystem } from '@reference-ui/icons/baseSystem'

export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  layers: [iconsSystem],
})
```

With neither, `ref sync` warns at the icon and names its package, and its
style props do not paint. `size`, `variant`, `style` and `className` work
either way.

## API reference

<Reference name="MaterialSymbolIconProps" headingLevel={3} />

An icon renders an inline-flex `div` around an `svg`, and takes the `div`'s
props, style props and a `ref`.

## Accessibility

The `svg` is hidden from screen readers. An icon beside text, or inside a
button with a text label, needs nothing more.

An icon that carries meaning on its own needs a role and a label:

```tsx
<WarningIcon role="img" aria-label="Warning" />
```

In an icon-only button, label the button:

```tsx
<Button aria-label="Search">
  <SearchIcon />
</Button>
```
