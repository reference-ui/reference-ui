# Icons

`@reference-ui/lib` exports the Material Symbols icon set as individual React
components, each supporting outlined and filled variants.

<Preview>
  <IconsDemo />
</Preview>

```tsx
import { HomeIcon, SearchIcon } from '@reference-ui/lib'

<SearchIcon />
<HomeIcon variant="filled" size="lg" />
```

## Import

Icons are named after their Material Symbols name in PascalCase, followed by
`Icon`: `search` is `SearchIcon` and `account_circle` is
`AccountCircleIcon`. Names that start with a digit take an `Icon` prefix, so
`10k` is `Icon10kIcon`.

```tsx
import { AccountCircleIcon, SearchIcon } from '@reference-ui/lib'
```

The same components are also published separately in `@reference-ui/icons` for
projects that do not install `@reference-ui/lib`:

```tsx
import { SearchIcon } from '@reference-ui/icons'
```

## Examples

### Size

`size` sets both width and height. It accepts preset tokens (`sm` for 16px,
`md` for 20px, or `lg` for 24px), a pixel number, a rhythm unit (such as
`"8r"`), or any CSS length string.

```tsx
<SearchIcon size="sm" />
<SearchIcon size={32} />
<SearchIcon size="8r" />
<SearchIcon size="1.5rem" />
```

### Variant

Icons render outlined by default. Pass `variant="filled"` for the solid
version:

```tsx
<HomeIcon />
<HomeIcon variant="filled" />
```

### Colour

Icons inherit `currentColor` from the surrounding text by default. Pass
`color` to set a specific token or CSS color:

```tsx
<Span color="red.600">
  <WarningIcon /> Payment failed
</Span>
<CheckIcon color="green.600" />
```

### Style props

Icons accept Reference UI style props and resolve them against your design
tokens:

```tsx
<CheckIcon marginLeft="3r" _hover={{ opacity: 0.7 }} />
```

Using style props on icons requires the icon system in your `ui.config.ts`
`extends` or `layers`. `@reference-ui/lib` includes it in its `baseSystem`
(which `ref init` adds to `extends` by default). If you use
`@reference-ui/icons` without `@reference-ui/lib`, add the icon system to
`layers`:

```ts
// ui.config.ts
import { defineConfig } from '@reference-ui/core'
import { baseSystem as iconsSystem } from '@reference-ui/icons/baseSystem'

export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  layers: [iconsSystem],
})
```

If neither system is configured, `ref sync` logs a warning naming the package
and skips style-prop extraction for the icon. The `size`, `variant`, `style`,
and `className` props work without system configuration.

## API reference

<Reference name="MaterialSymbolIconProps" headingLevel={3} />

Each icon renders an inline-flex `div` wrapping an `svg`, and accepts standard
`div` props, style props, and a `ref`.

## Accessibility

The inner `svg` has `aria-hidden="true"` by default, so decorative icons next
to visible text require no extra attributes.

An icon that carries meaning on its own needs a role and a label:

```tsx
<WarningIcon role="img" aria-label="Warning" />
```

In an icon-only button, label the button:

```tsx
<Button aria-label="Search">
  <SearchIcon />
</Button>
```
