# Icons

`@reference-ui/lib` exports the Material Symbols icon set as one React
component per icon, named `<Name>Icon`.

<Preview>
  <IconsDemo />
</Preview>

```tsx
import { HomeIcon, SearchIcon, SettingsIcon } from '@reference-ui/lib'

<SearchIcon aria-label="Search" />
<SettingsIcon size="lg" aria-label="Settings" />
<HomeIcon variant="filled" size="lg" aria-label="Home" />
```

## Import

```tsx
import { SearchIcon } from '@reference-ui/lib'
```

Unused icons are removed by tree-shaking in production builds.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'`, a number of pixels, an `r` value, or a CSS length | `'md'` (20px) | Width and height. `sm` is 16px and `lg` 24px. |
| `variant` | `'outline' \| 'filled'` | `'outline'` | Glyph style. |
| `color` | CSS colour | `'inherit'` | Glyph colour; follows the text colour by default. |

Icons render a `div` and accept its DOM props, such as `aria-label`.

## Styling

Icons take style props like any other component, and resolve them against
your tokens:

```tsx
<CheckIcon marginLeft="3r" />
```

Style props on an icon compile when lib's `baseSystem` is in `extends` or
`layers` in `ui.config.ts`, as `ref init` sets up; it carries the icons' own
system. When neither holds lib's or the icons' `baseSystem`, `ref sync` warns
`ATM-W-EXTERNAL-UNBACKED` at the icon and the props do not paint.

`size`, `variant`, `style` and `className` work either way, and so does
wrapping the icon in your own element:

```tsx
<Span marginLeft="3r">
  <CheckIcon />
</Span>
```
