# Typography

One grayscale system, three shipped families, and a full weight ramp for each.
Every text primitive is token-aware, so the same markup reads correctly in light
and dark.

## Weight ramp

Grouped by weight, each family stacked so the same weight can be compared
across all three. The number is what that weight resolves to in the family.

<WeightRamp />

`bold` is the heaviest shipped weight. The `font()` API can still define a
`black` stop for a custom family.
