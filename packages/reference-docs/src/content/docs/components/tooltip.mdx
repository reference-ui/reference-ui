# Tooltip

Tooltip displays a short label when a user hovers or focuses a trigger control,
and associates the label with the trigger via `aria-describedby`.

<Preview>
  <TooltipDemo />
</Preview>

```tsx
import { Button } from '@reference-ui/react'
import { Tooltip } from '@reference-ui/lib'

<Tooltip>
  <Tooltip.Trigger>
    <Button>Save</Button>
  </Tooltip.Trigger>
  <Tooltip.Content>Save the document</Tooltip.Content>
</Tooltip>
```

## Import

```tsx
import { Tooltip } from '@reference-ui/lib'
```

## Anatomy

```tsx
<Tooltip>
  <Tooltip.Trigger />
  <Tooltip.Portal>
    <Tooltip.Content>
      <Tooltip.Arrow />
    </Tooltip.Content>
  </Tooltip.Portal>
</Tooltip>
```

`Tooltip` and `Tooltip.Trigger` render no wrapper DOM elements:
`Tooltip.Trigger` clones its single child element to attach event handlers and
ARIA attributes, while `Tooltip.Content` renders a `div`.

## Examples

### Neighbouring tooltips

Once a tooltip is open, moving the pointer to an adjacent trigger opens its
tooltip immediately without waiting for `openDelay`.

<Preview>
  <TooltipGroupDemo />
</Preview>

This instant-open window lasts for 300ms after a tooltip closes and can be
customized via `tooltip.skipDelay` on [ReferenceLibrary](/reference-library).

### Placement

`Tooltip.Content` is positioned above the trigger by default
(`placement="top"`). Pass `placement` and `offset` to adjust its position.

```tsx
<Tooltip.Content placement="right" offset={4}>
  Save the document
</Tooltip.Content>
```

### Delays

Use `openDelay` and `closeDelay` (in milliseconds) to configure how long
pointer hover waits before showing or hiding the tooltip:

```tsx
<Tooltip openDelay={300} closeDelay={0}>…</Tooltip>
```

### Controlled

For controlled state, pass `open` and `onOpenChange`.

```tsx
const [open, setOpen] = React.useState(false)

<Tooltip open={open} onOpenChange={setOpen}>
  <Tooltip.Trigger>
    <Button>Save</Button>
  </Tooltip.Trigger>
  <Tooltip.Content>Save the document</Tooltip.Content>
</Tooltip>
```

## API reference

### Tooltip

Manages open state and hover delay timers. Renders no DOM element of its own.

<Reference name="TooltipProps" headingLevel={4} />

### Tooltip.Trigger

Requires a single React element as its child. Merges pointer and focus
handlers, preserves the child's existing handlers and `ref`, and appends the
tooltip's ID to the child's `aria-describedby` while open. Passing multiple
children or a non-element child throws an error.

### Tooltip.Content

The floating tooltip label. Accepts standard `div` props, style props, and the
positioning props of [`Overlay.Content`](/overlay). Renders nothing if used
outside `Tooltip`.

<Reference name="TooltipContentProps" headingLevel={4} />

`Tooltip.Content` comes with a compact dark surface style by default, which can
be overridden with style props.

| Data attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |
| `data-side` | `top`, `right`, `bottom`, `left` |
| `data-align` | `start`, `center`, `end` |

### Tooltip.Portal

Optional portal wrapper that configures the DOM container where
`Tooltip.Content` is rendered.

<Reference name="TooltipPortalProps" headingLevel={4} />

### Tooltip.Arrow

An optional arrow element positioned along the tooltip edge facing the trigger.
Accepts standard `div` props and style props; style its shape with custom CSS.

## Behaviour

- Only one tooltip is open at a time.
- `Tooltip.Content` unmounts immediately when closed, with no exit animation.
- Pressing the trigger closes the tooltip, and it stays closed until the
  pointer leaves.
- Scrolling an ancestor of the trigger closes the tooltip.
- Tooltips do not open on touch devices; do not rely on a tooltip as the only
  way to convey essential information.
- `Tooltip.Content` is not meant for interactive controls. For floating panels
  containing links or buttons, use [Popover](/popover) (with `openOnHover` for
  hover cards).

## Accessibility

- Content has `role="tooltip"`.
- The pointer can move onto Content without closing it.
- Escape closes the tooltip without moving focus. Inside a dialog, the first
  Escape closes only the tooltip.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Tab` | Focusing the trigger with the keyboard opens the tooltip immediately. Moving focus away closes it. |
| `Escape` | Closes the tooltip. |
