# Overlay

Overlay handles layering, dismissal, focus and positioning. You supply the
role, the copy and the styles.

<Preview>
  <OverlayDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Button, H2, css } from '@reference-ui/react'
import { Overlay } from '@reference-ui/lib'

const backdrop = css({ bg: 'rgba(0,0,0,0.5)' })
const centred = css({
  position: 'fixed',
  top: '50%',
  left: '50%',
  transform: 'translate(-50%, -50%)',
})

export function DeleteDialog() {
  const [open, setOpen] = useState(false)
  return (
    <Overlay open={open} onOpenChange={setOpen}>
      <Overlay.Trigger>Delete project</Overlay.Trigger>
      <Overlay.Backdrop className={backdrop} />
      <Overlay.Content
        role="dialog"
        aria-modal="true"
        aria-labelledby="delete-title"
        className={centred}
      >
        <H2 id="delete-title">Delete project?</H2>
        <Button onClick={() => setOpen(false)}>Cancel</Button>
      </Overlay.Content>
    </Overlay>
  )
}
```

## Import

```tsx
import { Overlay } from '@reference-ui/lib'
```

## Anatomy

Every part except `Overlay.Content` is optional.

```tsx
<Overlay>
  <Overlay.Trigger />
  <Overlay.Portal container={element} />
  <Overlay.Backdrop />
  <Overlay.Content>
    <Overlay.Handle />
    <Overlay.Arrow />
  </Overlay.Content>
</Overlay>
```

`Overlay` renders no element. Backdrop and Content render into a portal at the
end of `document.body`. Each part may appear at most once.

## Geometry

Overlay picks where Content goes from the props you pass.

| You pass | Content is |
| --- | --- |
| Trigger, default `isolation` | Unbound. Overlay writes no position; place it with your own CSS. |
| Trigger and `isolation={false}` | Anchored to the Trigger. |
| `anchor` | Anchored to that reference. `anchor` wins over Trigger. |
| `edge` | Bound to that viewport edge. |

`edge` and `anchor` can't be combined: Content logs a warning and renders
nothing.

## Examples

### Sheet

Pass `edge` to bind Content to a side of the viewport. Add `Overlay.Handle` so
users can drag it to dismiss.

<Preview>
  <OverlaySheetDemo />
</Preview>

```tsx
<Overlay open={open} onOpenChange={setOpen} edge="bottom">
  <Overlay.Trigger>Open sheet</Overlay.Trigger>
  <Overlay.Backdrop className={backdrop} />
  <Overlay.Content role="dialog" aria-modal="true" aria-label="Share" offset={0}>
    <Overlay.Handle />
    <Button onClick={() => setOpen(false)}>Done</Button>
  </Overlay.Content>
</Overlay>
```

A drag dismisses once it covers 25% of the sheet, or on a fast flick.
Otherwise the sheet springs back.

### Anchored panel

Turn isolation off and Content positions itself against the Trigger. The
page stays interactive, and a press outside closes the panel.

<Preview>
  <OverlayAnchoredDemo />
</Preview>

```tsx
<Overlay open={open} onOpenChange={setOpen} isolation={false}>
  <Overlay.Trigger>Show details</Overlay.Trigger>
  <Overlay.Content placement="bottom-start">
    Anchored below the trigger.
  </Overlay.Content>
</Overlay>
```

For a ready-made anchored panel, use [Popover](/popover).

### Alert dialog

Call `preventDefault()` in `onEscape` or `onOutsidePress` to prevent closing
until the user chooses an action.

```tsx
<Overlay
  open={open}
  onOpenChange={setOpen}
  onEscape={event => event.preventDefault()}
  onOutsidePress={event => event.preventDefault()}
>
  <Overlay.Content role="alertdialog" aria-modal="true" aria-labelledby="title">
    …
  </Overlay.Content>
</Overlay>
```

### Isolation

`isolation` is three settings: `focus` keeps Tab inside Content, `inert`
makes the rest of the page unreachable, and `scroll` locks page scroll. All
three are on by default. Pass an object to turn one off:

```tsx
<Overlay isolation={{ scroll: false }}>…</Overlay>
```

### Animating

Closing does not unmount Backdrop and Content immediately. Both carry
`data-state="open"` or `data-state="closed"`, and stay in the DOM until a CSS
animation or transition on them finishes.

```tsx
const fade = css({
  transition: 'opacity 0.2s',
  '&[data-state="closed"]': { opacity: '0' },
})

<Overlay.Content className={fade}>…</Overlay.Content>
```

See [Presence](/presence) for what counts as an exit.

## API reference

### Overlay

Holds the open state and the settings every part reads.

<Reference name="OverlayProps" headingLevel={4} />

### Overlay.Trigger

A `button` that opens the layer when closed and closes it when open. Takes
every `button` prop and style prop. If your `onClick` calls
`preventDefault()`, the Trigger does nothing.

| Attribute | Values |
| --- | --- |
| `aria-expanded` | `true`, `false` |

### Overlay.Backdrop

A fixed, full-viewport `div` behind Content. A press on it closes the
layer. Takes every `div` prop and style prop.

| Attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |

### Overlay.Content

The layer itself. Takes every `div` prop and style prop, plus:

<Reference name="OverlayContentProps" headingLevel={4} />

`initialFocus` and `restoreFocus` apply while `isolation.focus` is on.
Placement props apply only when Content is anchored; `offset` also applies
with `edge`.

| Attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |
| `data-side` | `top`, `right`, `bottom`, `left` (anchored) |
| `data-align` | `start`, `center`, `end` (anchored) |
| `data-anchor-hidden` | Present when the anchor is clipped out of view. |
| `data-escaped` | Present when Content has left the anchor's clipping area. |
| `data-edge` | The bound edge (`edge`). |
| `data-dragging` | Present while the Handle is dragged. |

| CSS variable | Description |
| --- | --- |
| `--reference-overlay-available-width` | Width Content can use. |
| `--reference-overlay-available-height` | Height Content can use. |
| `--reference-overlay-anchor-width` | Width of the anchor. |
| `--reference-overlay-anchor-height` | Height of the anchor. |
| `--reference-overlay-transform-origin` | Origin facing the anchor, for scale animations. |
| `--reference-overlay-swipe-progress` | `0` to `1` while the Handle is dragged. |
| `--reference-overlay-index` | Position among open edge layers, `0` for the topmost. |
| `--reference-overlay-count` | Number of open edge layers. |

### Overlay.Arrow

A `div` that Overlay moves to point at the anchor. It renders a 2r square
with no shape; draw the arrow with your own styles. Takes every `div` prop
and style prop, plus:

<Reference name="OverlayArrowProps" headingLevel={4} />

### Overlay.Handle

A drag handle for edge layers. It only works with `edge`. Its default look
is a small grey pill; style props override it. Takes every `div` prop and
style prop.

### Overlay.Portal

Sets where Backdrop and Content render. It renders only its children.

<Reference name="OverlayPortalProps" headingLevel={4} />

## Accessibility

Overlay adds no role. Set `role="dialog"` (or `alertdialog`), `aria-modal`,
and a label on Content yourself. The Trigger gets `aria-expanded`.

While `isolation.inert` is on, everything outside the open layers gets the
`inert` attribute. Live regions, [Toast](/toast) and
[announce](/announce) stay reachable.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Space`, `Enter` | On the Trigger, opens or closes the layer. |
| `Tab` | With focus isolation, moves focus within Content and wraps. Without it, moves from the Trigger into Content; past the last item it closes the layer and moves on. |
| `Shift + Tab` | With focus isolation, moves back within Content. Without it, moves from the first item back to the Trigger. |
| `Esc` | Closes the topmost open layer. |

## Nesting

An Overlay inside another's Content is its child. Escape and outside presses
reach the topmost layer only, a press inside a child is not an outside press
for its parent, and closing a parent closes its children.
