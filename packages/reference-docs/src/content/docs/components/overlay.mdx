# Overlay

Overlay is a foundational primitive that manages layering, focus trapping,
dismissal, and positioning for modal and non-modal surfaces. You provide the
ARIA role, content, and styling.

<Preview>
  <OverlayDemo />
</Preview>

```tsx
import { useState } from 'react'
import { Button, H2, css } from '@reference-ui/react'
import { Overlay } from '@reference-ui/lib'

const backdrop = css({ bg: 'rgba(0,0,0,0.5)' })
const centred = css({
  position: 'fixed',
  top: '50%',
  left: '50%',
  transform: 'translate(-50%, -50%)',
})

export function DeleteDialog() {
  const [open, setOpen] = useState(false)
  return (
    <Overlay open={open} onOpenChange={setOpen}>
      <Overlay.Trigger>Delete project</Overlay.Trigger>
      <Overlay.Backdrop className={backdrop} />
      <Overlay.Content
        role="dialog"
        aria-modal="true"
        aria-labelledby="delete-title"
        className={centred}
      >
        <H2 id="delete-title">Delete project?</H2>
        <Button onClick={() => setOpen(false)}>Cancel</Button>
      </Overlay.Content>
    </Overlay>
  )
}
```

## Import

```tsx
import { Overlay } from '@reference-ui/lib'
```

## Anatomy

Every part except `Overlay.Content` is optional.

```tsx
<Overlay>
  <Overlay.Trigger />
  <Overlay.Portal container={element} />
  <Overlay.Backdrop />
  <Overlay.Content>
    <Overlay.Handle />
    <Overlay.Arrow />
  </Overlay.Content>
</Overlay>
```

`Overlay` renders no DOM element of its own. `Overlay.Backdrop` and
`Overlay.Content` render into a portal appended to `document.body`. Each
subcomponent may appear at most once.

## Geometry

`Overlay.Content` determines its positioning mode from the props on `Overlay`:

| Props | Positioning behavior |
| --- | --- |
| `Overlay.Trigger` with default `isolation` | Unbound. Overlay applies no positioning styles; position it with your own CSS. |
| `Overlay.Trigger` with `isolation={false}` | Anchored to `Overlay.Trigger`. |
| `anchor` | Anchored to the given element, ref, or coordinates (`anchor` takes precedence over `Overlay.Trigger`). |
| `edge` | Attached to the specified viewport edge. |

`edge` and `anchor` cannot be combined; if both are passed, `Overlay.Content`
logs a warning and renders nothing.

## Examples

### Sheet

Pass `edge` to bind `Overlay.Content` to a side of the viewport. Add
`Overlay.Handle` so users can drag it to dismiss.

<Preview>
  <OverlaySheetDemo />
</Preview>

```tsx
<Overlay open={open} onOpenChange={setOpen} edge="bottom">
  <Overlay.Trigger>Open sheet</Overlay.Trigger>
  <Overlay.Backdrop className={backdrop} />
  <Overlay.Content role="dialog" aria-modal="true" aria-label="Share" offset={0}>
    <Overlay.Handle />
    <Button onClick={() => setOpen(false)}>Done</Button>
  </Overlay.Content>
</Overlay>
```

Dragging past 25% of the sheet's size or flicking quickly dismisses the sheet;
otherwise, it snaps back into place.

### Anchored panel

Set `isolation={false}` to anchor `Overlay.Content` to `Overlay.Trigger`. The
rest of the page remains interactive, and clicking outside closes the panel.

<Preview>
  <OverlayAnchoredDemo />
</Preview>

```tsx
<Overlay open={open} onOpenChange={setOpen} isolation={false}>
  <Overlay.Trigger>Show details</Overlay.Trigger>
  <Overlay.Content placement="bottom-start">
    Anchored below the trigger.
  </Overlay.Content>
</Overlay>
```

For a ready-made anchored panel, use [Popover](/popover).

### Alert dialog

Call `preventDefault()` in `onEscape` or `onOutsidePress` to prevent closing
until the user chooses an action.

```tsx
<Overlay
  open={open}
  onOpenChange={setOpen}
  onEscape={event => event.preventDefault()}
  onOutsidePress={event => event.preventDefault()}
>
  <Overlay.Content role="alertdialog" aria-modal="true" aria-labelledby="title">
    …
  </Overlay.Content>
</Overlay>
```

### Isolation

`isolation` controls three modal behaviors: `focus` traps Tab navigation inside
`Overlay.Content`, `inert` marks the rest of the page inert, and `scroll` locks
document scrolling. All three are enabled by default. Pass an object to
configure them individually:

```tsx
<Overlay isolation={{ scroll: false }}>…</Overlay>
```

### Animating

`Overlay.Backdrop` and `Overlay.Content` expose `data-state="open"` and
`data-state="closed"`, remaining mounted when closing until any CSS animation or
transition completes.

```tsx
const fade = css({
  transition: 'opacity 0.2s',
  '&[data-state="closed"]': { opacity: '0' },
})

<Overlay.Content className={fade}>…</Overlay.Content>
```

See [Presence](/presence) for details on how exit animations are detected.

## API reference

### Overlay

Manages open state, positioning mode, and isolation settings for its child
parts. Renders no DOM element of its own.

<Reference name="OverlayProps" headingLevel={4} />

### Overlay.Trigger

A `button` that toggles the overlay. Accepts standard `button` props and style
props. Calling `preventDefault()` in `onClick` cancels the toggle.

| Attribute | Values |
| --- | --- |
| `aria-expanded` | `true`, `false` |

### Overlay.Backdrop

A fixed, full-viewport `div` rendered behind `Overlay.Content`. Clicking the
backdrop dismisses the overlay. Accepts standard `div` props and style props.

| Attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |

### Overlay.Content

The overlay surface. Renders a `div` and accepts standard `div` props, style
props, and positioning options:

<Reference name="OverlayContentProps" headingLevel={4} />

`initialFocus` and `restoreFocus` apply while `isolation.focus` is enabled.
Placement props apply only when `Overlay.Content` is anchored; `offset` also
applies with `edge`.

| Attribute | Values |
| --- | --- |
| `data-state` | `open`, `closed` |
| `data-side` | `top`, `right`, `bottom`, `left` (anchored) |
| `data-align` | `start`, `center`, `end` (anchored) |
| `data-anchor-hidden` | Present when the anchor is clipped out of view. |
| `data-escaped` | Present when Content has left the anchor's clipping area. |
| `data-edge` | The bound edge (`edge`). |
| `data-dragging` | Present while the Handle is dragged. |

| CSS variable | Description |
| --- | --- |
| `--reference-overlay-available-width` | Available viewport width for the content. |
| `--reference-overlay-available-height` | Available viewport height for the content. |
| `--reference-overlay-anchor-width` | Width of the anchor. |
| `--reference-overlay-anchor-height` | Height of the anchor. |
| `--reference-overlay-transform-origin` | Origin facing the anchor, for scale animations. |
| `--reference-overlay-swipe-progress` | `0` to `1` while the Handle is dragged. |
| `--reference-overlay-index` | Position among open edge layers, `0` for the topmost. |
| `--reference-overlay-count` | Number of open edge layers. |

### Overlay.Arrow

A `div` positioned along the edge of `Overlay.Content` to point toward the
anchor. Renders an unstyled `2r` square that you can shape with custom CSS.
Accepts standard `div` props, style props, and arrow options:

<Reference name="OverlayArrowProps" headingLevel={4} />

### Overlay.Handle

A draggable handle for edge-bound sheets (active only when `edge` is set).
Renders a `div` styled as a small pill by default, and accepts standard `div`
props and style props.

### Overlay.Portal

Configures the portal target for `Overlay.Backdrop` and `Overlay.Content`.
Renders no DOM element of its own.

<Reference name="OverlayPortalProps" headingLevel={4} />

## Accessibility

`Overlay.Content` does not set a default ARIA role. Add `role="dialog"` (or
`role="alertdialog"`), `aria-modal`, and `aria-label` or `aria-labelledby`
directly on `Overlay.Content`. `Overlay.Trigger` sets `aria-expanded`
automatically.

When `isolation.inert` is enabled, elements outside the active overlay receive
the `inert` attribute, while live regions, [Toast](/toast), and
[announce](/announce) remain accessible.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Space`, `Enter` | On the Trigger, opens or closes the layer. |
| `Tab` | When focus isolation is enabled, cycles focus within `Overlay.Content`. When disabled, moves focus from the trigger into `Overlay.Content`, and closes the overlay after tabbing past the last focusable element. |
| `Shift + Tab` | When focus isolation is enabled, cycles focus backward within `Overlay.Content`. When disabled, moves focus from the first focusable element back to the trigger. |
| `Esc` | Closes the topmost open layer. |

## Nesting

An `Overlay` rendered inside another `Overlay.Content` registers as a nested
child layer. `Escape` and outside clicks dismiss only the topmost open layer,
interactions inside a child overlay do not count as outside clicks on its
parent, and closing a parent overlay closes all of its nested children.
