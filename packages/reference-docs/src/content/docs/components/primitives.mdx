# Primitives

Primitives are typed React wrappers around real HTML tags. They keep the
semantics of native elements like `div`, `a`, and `p` while giving you
Reference UI style props and generated classes.

## Why primitives exist

Reference UI starts from the platform. Instead of a generic `Box` or an `as`
prop, each primitive maps directly to a real element.

- You keep native HTML semantics.
- You get typed props for the element you are rendering.
- You can use Reference UI style props directly in JSX.
- You can still reach for `css()` when you want reusable class composition.

## When to use primitives vs `css()`

- Use primitives when rendering a specific element and styling it inline.
- Use `css()` when composing styles once and applying them in several places.
- Use recipes when defining a reusable component with variants and a stronger contract.
