# Getting started

## Quick start

<Step n={1}>Install and initialize</Step>

Reference UI is both a library and a CLI. 

<Install packages="@reference-ui/lib react react-dom" devPackages="@reference-ui/core" />

`ref init` creates a `ui.config.ts` at the project root, next to `package.json`.
```bash
npx ref init
```



<Step n={2}>Run sync</Step>

Compile your styles and types from the project root.

```bash
npx ref sync --watch
```

Sync writes generated packages to `.reference-ui/`

<Step n={3}>Connect your agent</Step>

Add the Reference UI MCP server to your agent, so it works from your real
components and tokens. [MCP setup](/mcp-setup) has the config for Claude Code,
Cursor, VS Code and Codex.

<Step n={4}>Start building</Step>

Import the generated stylesheet once, before your app code.

```tsx
// src/main.tsx
import '@reference-ui/react/styles.css'
```

Primitives such as `Div` and `Button` come from `@reference-ui/react` and take
style props. 
Components and icons such as `SearchIcon` come from `@reference-ui/lib`.

```tsx {4-5,11-13}
// src/main.tsx
import '@reference-ui/react/styles.css'
import { createRoot } from 'react-dom/client'
import { Button, Div } from '@reference-ui/react'
import { SearchIcon } from '@reference-ui/lib'

function App() {
  return (
    <Div display="grid" justifyItems="start" gap="3r" padding="4r">
      Hello from Reference UI
      <Button display="flex" alignItems="center" gap="2r">
        <SearchIcon /> Search
      </Button>
    </Div>
  )
}

createRoot(document.getElementById('root')!).render(<App />)
```
