import { Button, Div } from '@reference-ui/react'

# Get Started

## Installation

```bash
pnpm add @reference-ui/lib react react-dom
```

## Try it

Reference UI compiles its CSS at build time, so this renders the real, shipped styles.

<Div display="flex" gap="3r" alignItems="center" marginBottom="4r">
  <Button variant="primary">Primary</Button>
  <Button variant="default">Default</Button>
  <Button variant="ghost">Ghost</Button>
</Div>
