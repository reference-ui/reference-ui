# Responsive

Responsive styles follow the width of a container, not the viewport. A card
that switches layout at `md` does so when the space it sits in reaches
768px, whether that is a page, a sidebar or a dialog.

## Mark a container

A responsive style matches only inside a container. Make an element one with
the `container` prop:

```tsx
import { Div } from '@reference-ui/react'

<Div container>
  {/* responsive styles in here follow this Div's width */}
</Div>
```

`container` sets `container-type: inline-size`. Pass a string to name the
container as well: `container="sidebar"`.

To make the whole page a container, set it on `body`:

```ts
import { globalCss } from '@reference-ui/system'

globalCss({
  body: { containerType: 'inline-size' },
})
```

`@reference-ui/lib` already does this, so projects that extend it have a page
container. Without any container, responsive styles never match, and
`ref sync` warns when your global CSS defines none.

## Breakpoints

| Name | Container width |
| --- | --- |
| `base` | Any width (no query) |
| `sm` | 640px and up |
| `md` | 768px and up |
| `lg` | 1024px and up |
| `xl` | 1280px and up |
| `2xl` | 1536px and up |

Wider breakpoints override narrower ones.

## Write a responsive value

**Arrays** list values from `base` up. Index 0 is `base`, index 1 is `sm`,
and so on. `null` skips a breakpoint:

```tsx
<Div width={['100%', null, '50%']} /> // 100%, then 50% from md
```

**Objects** name the breakpoints for one property:

```tsx
<Div padding={{ base: '2r', md: '4r', xl: '8r' }} />
```

**Breakpoint keys** group several properties:

```ts
import { css } from '@reference-ui/react'

css({
  display: 'grid',
  gridTemplateColumns: '1fr',
  md: { gridTemplateColumns: 'repeat(2, 1fr)' },
  lg: { gridTemplateColumns: 'repeat(3, 1fr)' },
})
```

Nested keys must all match: `sm: { md: { … } }` applies only when both do.

## Ranges

| Key | Matches | Example |
| --- | --- | --- |
| `<bp>Down` | Below `bp` | `mdDown`: `(max-width: 767.98px)` |
| `<bp>Only` | From `bp` to the next breakpoint | `mdOnly`: `(min-width: 768px) and (max-width: 1023.98px)` |
| `<from>To<to>` | From `from` up to `to` | `smToLg`: `(min-width: 640px) and (max-width: 1023.98px)` |

The upper bound stops 0.02px short, so adjacent ranges never overlap.

## Custom widths

The `r` prop takes pixel widths that are not on the scale:

```tsx
<Div width="100%" r={{ 300: { width: '50%' }, 900: { width: '33%' } }} />
```

Each key prints `@container (min-width: <key>px)`. `r` works on primitives
and in `css()`.

## Viewport and named containers

Write the at-rule as a key when you need the viewport or a named container:

```ts
css({
  padding: '2r',
  '@media (min-width: 800px)': { padding: '6r' },
  '@container sidebar (min-width: 400px)': { padding: '4r' },
})
```

In [Global CSS](/global-css), breakpoint keys print `@media` queries with the
same widths.
