# Style props

Style props are CSS properties written as props on a
[primitive](/primitives): `<Div padding="4r" color="brand">`.

The compiler turns each property and value into a class. The same keys and
values work in [`css()`](/css), the `css` prop, recipes and
[`globalCss()`](/global-css).

## Properties

Every standard CSS property is a style prop, in camelCase:
`backgroundColor`, `gridTemplateColumns`, `textDecorationLine`. Vendor
properties take either spelling, such as `WebkitLineClamp` or
`webkitLineClamp`.

### Shorthands

| Shorthand | Property |
| --- | --- |
| `p` | `padding` |
| `pt`, `pr`, `pb`, `pl` | `paddingTop`, `paddingRight`, `paddingBottom`, `paddingLeft` |
| `px`, `paddingX` | `paddingInline` |
| `py`, `paddingY` | `paddingBlock` |
| `m` | `margin` |
| `mt`, `mr`, `mb`, `ml` | `marginTop`, `marginRight`, `marginBottom`, `marginLeft` |
| `mx`, `marginX` | `marginInline` |
| `my`, `marginY` | `marginBlock` |
| `w`, `h` | `width`, `height` |
| `minW`, `maxW` | `minWidth`, `maxWidth` |
| `minH`, `maxH` | `minHeight`, `maxHeight` |
| `bg` | `background` |
| `flexDir` | `flexDirection` |

A shorthand and its full name are the same property. When both are set, the
one written last wins.

### Reference props

These props set more than one declaration:

| Prop | Example | Effect |
| --- | --- | --- |
| `size` | `size="10r"` | Sets `width` and `height`. |
| `font` | `font="display"` | Applies a family from `font()`. See [Fonts](/fonts). |
| `weight` | `weight="bold"` | A weight from the element's family. See [Fonts](/fonts#weights). |
| `container` | `container` | Makes the element a container. See [Responsive](/responsive). |
| `r` | `r={{ 480: { p: '6r' } }}` | Styles at custom container widths. See [Responsive](/responsive#custom-widths). |

## Values

A style prop accepts:

- a token name from the property's category, such as `color="brand"`, or the
  full path, `color="colors.brand"` (see [Tokens](/tokens));
- a colour with an opacity or tone, `bg="brand/40"` or `bg="brand/soft"`;
- rhythm units, `padding="4r"` (see [Spacing](/spacing));
- any CSS value, `width="calc(100% - 2rem)"`;
- a number: pixels on lengths (`width={42}`), bare otherwise
  (`opacity={0.5}`);
- a responsive array or object, `p={['2r', '4r']}` or
  `p={{ base: '2r', md: '4r' }}` (see [Responsive](/responsive));
- `null`, `false` or `undefined`, which set nothing.

The compiler must be able to read the value from your source. See
[What the compiler can read](/css#what-the-compiler-can-read).

## Conditions

A prop that starts with `_` takes a style object that applies only under
that condition:

```tsx
<Button
  bg="brand"
  _hover={{ bg: 'brand/80' }}
  _focusVisible={{ outline: '2px solid {colors.brand}' }}
  _disabled={{ opacity: 0.5 }}
/>
```

State conditions also match a data attribute, so a script can set the state:
`_hover` matches `:hover` and `[data-hover]`, and `_disabled` matches
`:disabled`, `[disabled]`, `[data-disabled]` and `[aria-disabled=true]`.
Conditions nest: `_hover={{ _dark: { … } }}` applies only when both match.

| Group | Conditions |
| --- | --- |
| Interaction | `_hover`, `_active`, `_focus`, `_focusVisible`, `_focusWithin`, `_visited`, `_target`, `_dragging`, `_grabbed`, `_loading` |
| Form state | `_disabled`, `_enabled`, `_checked`, `_indeterminate`, `_required`, `_optional`, `_readOnly`, `_readWrite`, `_valid`, `_invalid`, `_userValid`, `_userInvalid`, `_autofill`, `_placeholderShown`, `_default` |
| Disclosure and selection | `_open`, `_closed`, `_expanded`, `_selected`, `_current`, `_currentPage`, `_currentStep` |
| Structure | `_first`, `_last`, `_only`, `_even`, `_odd`, `_firstOfType`, `_lastOfType`, `_onlyOfType`, `_empty` |
| Pseudo-elements | `_before`, `_after`, `_placeholder`, `_selection`, `_marker`, `_file`, `_backdrop` |
| Group and peer | `_groupHover`, `_groupFocus`, `_groupFocusVisible`, `_groupActive`, `_groupChecked`, `_groupDisabled`, `_groupExpanded`, `_groupInvalid`, `_peerHover`, `_peerFocus`, `_peerFocusVisible`, `_peerActive`, `_peerChecked`, `_peerDisabled`, `_peerExpanded`, `_peerInvalid` |
| Colour mode | `_light`, `_dark` (an ancestor's `data-color-mode`), `_osLight`, `_osDark` (the operating system setting) |
| Media | `_motionReduce`, `_motionSafe`, `_print`, `_portrait`, `_landscape`, `_highContrast`, `_moreContrast`, `_lessContrast`, `_fullscreen` |
| Direction | `_ltr`, `_rtl` |

Group conditions match when an ancestor with the class `group` or the
attribute `data-group` is in that state. Peer conditions match a preceding
sibling with the class `peer` or the attribute `data-peer`.

An unknown condition, such as a misspelt `_hovr`, adds no CSS, and
`ref sync` warns.

For other selectors and at-rules, use the `css` prop with `&`, `@media` or
`@container` keys. See [CSS](/css#selectors-and-at-rules).
