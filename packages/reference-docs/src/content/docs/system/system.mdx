# Introduction

Reference UI is a styling system that compiles at build time. You write
styles in TypeScript, and `ref sync` turns them into one stylesheet and the
types that check your style values.

<SystemDiagram />

## What you write

- **Primitives and style props.** A primitive is a component for one HTML
  element, such as `Div` or `Button`. Style props are CSS properties written
  as props: `<Div padding="4r" color="brand">`. See
  [Primitives](/primitives) and [Style props](/style-props).
- **Tokens.** `tokens()` defines named design tokens that can be referenced
  across your styles. See [Tokens](/tokens), [Spacing](/spacing),
  [Fonts](/fonts) and [Animation](/animation).
- **CSS.** `css()` generates a class name from a style object, `recipe()`
  defines multi-variant component styles, and `globalCss()` declares
  document-wide rules. See [CSS](/css), [Recipes](/recipes),
  [Responsive](/responsive) and [Global CSS](/global-css).

Sync scans the files matched by `include` in `ui.config.ts`.

Core includes no default color palette, font stack, or spacing scale beyond the
rhythm unit (`r`). You can define your own theme or extend a prebuilt base
system such as `@reference-ui/lib`.

## What sync does

`ref sync` runs in two passes:

1. **Collect** runs each file that calls `tokens()`, `font()`, `keyframes()`
   or `globalCss()`, and merges the results into one description of your
   system.
2. **Compile** statically extracts every style prop, `css()`, and `recipe()`
   call in your source and compiles them against your system definition into
   CSS.

Because the compiler analyzes your source statically without executing it,
style values must be resolvable at build time. See [Compiler](/compiler) and
[Sync](/sync).

## What you get

Sync writes three things to `.reference-ui/`:

- **A stylesheet.** One `styles.css` with a rule for each style value you
  use, ordered in [cascade layers](/cascade-layers). Import it once:
  `import '@reference-ui/react/styles.css'`.
- **Types.** Declarations for your tokens and style props, so your editor
  completes `color="…"` with your color token names.
- **Packages.** Your primitives, `css()` and `recipe()` in
  `@reference-ui/react`, and a `baseSystem` other projects can extend in
  `@reference-ui/system`.

The Reference MCP server uses the same compiler to index your components,
tokens, and props for coding agents. See [MCP](/mcp).
