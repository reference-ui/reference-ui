# Introduction

Reference UI is a styling system that compiles at build time. You write
styles in TypeScript, and `ref sync` turns them into one stylesheet and the
types that check your style values.

<SystemDiagram />

## What you write

- **Primitives and style props.** A primitive is a component for one HTML
  element, such as `Div` or `Button`. Style props are CSS properties written
  as props: `<Div padding="4r" color="brand">`. See
  [Primitives](/primitives) and [Style props](/style-props).
- **Tokens.** `tokens()` names your design values once, so styles can use the
  name. See [Tokens](/tokens), [Spacing](/spacing), [Fonts](/fonts) and
  [Animation](/animation).
- **CSS.** `css()` returns a class name for any element, `recipe()` builds a
  component's variants, and `globalCss()` styles selectors you choose. See
  [CSS](/css), [Recipes](/recipes), [Responsive](/responsive) and
  [Global CSS](/global-css).

Sync reads the files that your `ui.config.ts` `include` globs match.

Reference UI ships no colours, fonts or spacing scale, only the rhythm unit.
Define your own, or extend a system that defines them, such as
`@reference-ui/lib`.

## What sync does

`ref sync` runs in two passes:

1. **Collect** runs each file that calls `tokens()`, `font()`, `keyframes()`
   or `globalCss()`, and merges the results into one description of your
   system.
2. **Compile** reads every style prop, `css()` and `recipe()` call in your
   source. A Rust engine compiles them, with that description, into CSS.

The engine reads your source without running it, so it compiles only the
style values it can see there. [Compiler](/compiler) lists
what it can read. [Sync](/sync) covers the command.

## What you get

Sync writes three things to `.reference-ui/`:

- **A stylesheet.** One `styles.css` with a rule for each style value you
  use, ordered in [cascade layers](/cascade-layers). Import it once:
  `import '@reference-ui/react/styles.css'`.
- **Types.** Declarations for your tokens and style props, so your editor
  completes `color="…"` with your colour names.
- **Packages.** Your primitives, `css()` and `recipe()` in
  `@reference-ui/react`, and a `baseSystem` other projects can extend in
  `@reference-ui/system`.

The Reference MCP server uses the same engine to map your components for
your agent. See [MCP](/mcp).
