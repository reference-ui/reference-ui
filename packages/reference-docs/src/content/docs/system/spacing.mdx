# Spacing

Spacing in Reference UI is measured in rhythm units. Write `4r` for four
units of padding, `0.5r` for half a unit, `-2r` for a negative margin. Every
rhythm value is a multiple of one CSS variable, so changing that variable
rescales the spacing of the whole interface at once. Named spacing tokens sit
beside the rhythm unit when you want words instead of numbers.

## The `r` unit

A number followed by `r` is a multiple of `--spacing-root`:

```tsx
import { Div } from '@reference-ui/react'

<Div padding="4r" gap="2r" marginTop="-1r" />
```

The compiler turns each value into a `calc()` against the root variable:

| You write | CSS |
| --- | --- |
| `1r` | `var(--spacing-root)` |
| `4r` | `calc(4 * var(--spacing-root))` |
| `0.5r`, `3.5r` | `calc(0.5 * var(--spacing-root))`, … |
| `1/2r`, `1/3r` | `calc(var(--spacing-root) / 2)`, … |
| `-4r` | `calc(-4 * var(--spacing-root))` |

There is no fixed scale: `137.5r` works as well as `4r`. Rhythm is not limited
to spacing properties either. It works in any length value, including
`width`, `fontSize` and `maxWidth`, and inside multi-part values such as
`border: '0.25r solid'`.

## Set the root

The engine defines `--spacing-root: 0.25rem` at the start of the stylesheet,
ranked below every rule you write. Override it with one `globalCss()` line to
rescale every rhythm value:

```ts
// src/theme/global.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  ':root': {
    '--spacing-root': '0.3rem',
  },
})
```

Because the root is a plain custom property, you can also set it on any
element to change the density of one subtree.

## Named spacing tokens

Define `spacing` tokens when a value deserves a name:

```ts
import { tokens } from '@reference-ui/system'

tokens({
  spacing: {
    gutter: { value: '1.5rem' },
    section: { value: '{spacing.gutter}' },
  },
})
```

```tsx
<Div paddingInline="gutter" marginBlock="-section" />
```

A leading `-` negates a named token as well: `-section` prints
`calc(-1 * var(--spacing-section))`. Spacing tokens apply to `margin*`,
`padding*`, `gap`, `rowGap`, `columnGap`, `inset`, `top`, `right`, `bottom`
and `left`; see [Tokens](/tokens#categories) for the full mapping.

## Numbers

A bare number on a length property is pixels: `width: 42` prints `42px`.
Unitless properties such as `opacity` and `zIndex` keep the
bare number. Use rhythm units for spacing so it follows the root.

## `getRhythm()`

When you need a rhythm value as a string in JavaScript, for example in an
inline `style`, call `getRhythm()`:

```ts
import { getRhythm } from '@reference-ui/system'

getRhythm(4)     // 'calc(4 * var(--spacing-root))'
getRhythm(1)     // 'var(--spacing-root)'
getRhythm(1, 3)  // 'calc(var(--spacing-root) / 3)'
```

```ts
function getRhythm(num: number, denom?: number): string
```

## The compiler only sees literal steps

A rhythm value gets a CSS rule only when the compiler can read it from your
source. `padding="4r"` works anywhere. A step built at runtime, such as
`` `${n}r` ``, has no rule unless the same step appears literally somewhere
else; in development the browser console names the prop and value that
missed. See [CSS](/css#what-the-compiler-can-read).
