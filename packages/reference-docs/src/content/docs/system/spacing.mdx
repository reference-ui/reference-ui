# Spacing

Spacing is measured in rhythm units: `4r` is four units, `0.5r` is half a
unit. Every unit is a multiple of one CSS variable, so changing it rescales
the whole interface.

## The `r` unit

A number followed by `r` is a multiple of `--spacing-root`:

```tsx
import { Div } from '@reference-ui/react'

<Div padding="4r" gap="2r" marginTop="-1r" />
```

| You write | CSS |
| --- | --- |
| `1r` | `var(--spacing-root)` |
| `4r` | `calc(4 * var(--spacing-root))` |
| `0.5r` | `calc(0.5 * var(--spacing-root))` |
| `1/2r` | `calc(var(--spacing-root) / 2)` |
| `-4r` | `calc(-4 * var(--spacing-root))` |

The multiplier can be any number. Rhythm units work in any length,
including `width`, `fontSize` and multi-part values such as
`border: '0.25r solid'`. They also work inside `calc()`, as in
`width: 'calc(100% - 4r)'`. Inside `var()`, `url()` and `env()` they stay as
written.

## Set the root

`--spacing-root` is `0.25rem` by default. Set it with `globalCss()` to rescale
every rhythm value:

```ts
// src/theme/global.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  ':root': {
    '--spacing-root': '0.3rem',
  },
})
```

The default sits in the lowest [cascade layer](/cascade-layers), so your
value always wins. When a system you extend sets the root, its value applies
until you set your own. Set the variable on any element to change the density
of that part of the page.

## Named spacing

Define `spacing` tokens for reusable lengths. A token value can be a CSS
length, a reference to another token, or a rhythm value:

```ts
import { tokens } from '@reference-ui/system'

tokens({
  spacing: {
    gutter: { value: '6r' },
    section: { value: '{spacing.gutter}' },
    rule: { value: '1px' },
  },
})
```

```tsx
<Div paddingInline="gutter" marginBlock="-section" />
```

A leading `-` negates a token: `-section` compiles to
`calc(-1 * var(--spacing-section))`. Each token is also a CSS variable, such
as `--spacing-gutter`, for use in your own CSS.

## Numbers

A bare number on a length property resolves to pixels: `width={42}` outputs
`42px`. Properties without a unit, such as `opacity` and `zIndex`, keep the
number. Use rhythm units for spacing so it scales with `--spacing-root`.

## `getRhythm()`

`getRhythm()` returns a rhythm value as a string, for places outside style
props, such as an inline `style`:

```ts
import { getRhythm } from '@reference-ui/system'

getRhythm(4)    // 'calc(4 * var(--spacing-root))'
getRhythm(1)    // 'var(--spacing-root)'
getRhythm(1, 3) // 'calc(var(--spacing-root) / 3)'
```

```ts
function getRhythm(num: number, denom?: number): string
```

## Write steps literally

Write rhythm steps as static strings like `padding="4r"` so the compiler can
extract them at build time. For a step calculated from a number at runtime,
pass `getRhythm(n)` to `style` (see [Dynamic styles](/dynamic-styles#dynamic-sizes)).
