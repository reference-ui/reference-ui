# Spacing

Spacing is measured in rhythm units: `4r` is four units, `0.5r` is half a
unit. Every unit is a multiple of one CSS variable, so changing it rescales
the whole interface.

## The `r` unit

A number followed by `r` is a multiple of `--spacing-root`:

```tsx
import { Div } from '@reference-ui/react'

<Div padding="4r" gap="2r" marginTop="-1r" />
```

| You write | CSS |
| --- | --- |
| `1r` | `var(--spacing-root)` |
| `4r` | `calc(4 * var(--spacing-root))` |
| `0.5r` | `calc(0.5 * var(--spacing-root))` |
| `1/2r` | `calc(var(--spacing-root) / 2)` |
| `-4r` | `calc(-4 * var(--spacing-root))` |

Any number works, not only steps on a scale. Rhythm units work in any length,
including `width`, `fontSize` and multi-part values such as
`border: '0.25r solid'`.

## Set the root

`--spacing-root` is `0.25rem` by default. Set it with `globalCss()` to rescale
every rhythm value:

```ts
// src/theme/global.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  ':root': {
    '--spacing-root': '0.3rem',
  },
})
```

The default sits in the lowest [cascade layer](/cascade-layers), so your
value always wins. Set the variable on any element to change the density of
that part of the page.

## Named spacing

Define `spacing` tokens when a value deserves a name:

```ts
import { tokens } from '@reference-ui/system'

tokens({
  spacing: {
    gutter: { value: '1.5rem' },
    section: { value: '{spacing.gutter}' },
  },
})
```

```tsx
<Div paddingInline="gutter" marginBlock="-section" />
```

A leading `-` negates a token: `-section` prints
`calc(-1 * var(--spacing-section))`.

## Numbers

A bare number on a length property is pixels: `width={42}` prints `42px`.
Properties without a unit, such as `opacity` and `zIndex`, keep the number.
Use rhythm units for spacing so it follows the root.

## `getRhythm()`

`getRhythm()` returns a rhythm value as a string, for places outside style
props, such as an inline `style`:

```ts
import { getRhythm } from '@reference-ui/system'

getRhythm(4)    // 'calc(4 * var(--spacing-root))'
getRhythm(1)    // 'var(--spacing-root)'
getRhythm(1, 3) // 'calc(var(--spacing-root) / 3)'
```

```ts
function getRhythm(num: number, denom?: number): string
```

## Write steps literally

A rhythm value gets CSS only when the compiler can read it from your source.
`padding="4r"` works anywhere. A step built at runtime, such as
`` `${n}r` ``, gets no CSS unless the same step appears literally somewhere
else. See [CSS](/css#what-the-compiler-can-read).
