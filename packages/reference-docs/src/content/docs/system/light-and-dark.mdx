# Light and dark

Light mode is active by default. Tokens that define a `dark` value
automatically switch to it inside any element with `colorMode="dark"`.

## Dark values

Give a token a `dark` value alongside `value` (which acts as the light
default):

```ts
// src/theme/tokens.ts
import { tokens } from '@reference-ui/system'

tokens({
  colors: {
    surface: { value: '#ffffff', dark: '#0b0b0f' },
    ink: { value: '#111827', dark: '#f3f4f6' },
  },
})
```

Token names remain the same across modes while their underlying CSS variables
update. Semantic tokens in `@reference-ui/lib`, such as `design.background` and
`design.text.base`, include both light and dark values by default. See
[Color](/color).

## Setting the mode

Set `colorMode` on any primitive to apply that mode to the element and its
descendants, including `@reference-ui/lib` components.

```tsx
<Div colorMode="dark" bg="surface" color="ink">
  <App />
</Div>
```

To switch the whole page, set `colorMode` on your root primitive.

## Toggling

Keep the mode in state and pass it to `colorMode`.

```tsx
import { useState } from 'react'
import { Button, Div } from '@reference-ui/react'

export function Root() {
  const [mode, setMode] = useState<'light' | 'dark'>('light')

  return (
    <Div colorMode={mode} bg="surface" color="ink">
      <Button onClick={() => setMode(mode === 'dark' ? 'light' : 'dark')}>
        Toggle mode
      </Button>
    </Div>
  )
}
```

## Reading the mode

`useColorMode()` returns the mode set by the nearest ancestor with `colorMode`,
or `undefined` when no ancestor sets one (defaulting to light mode).

```tsx
import { useColorMode } from '@reference-ui/react'

function ModeLabel() {
  const mode = useColorMode() ?? 'light'
  return <span>{mode}</span>
}
```

## System setting

Tokens do not automatically switch on `prefers-color-scheme`. To follow the
operating system preference, initialize your mode state from `matchMedia`:

```tsx
const [mode, setMode] = useState(() =>
  matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light',
)
```

`matchMedia` is only available in the browser. For server-side rendering, read
the user's preferred mode from the request instead. See
[Server-side rendering](/ssr).

## Per-mode styles

`_dark` and `_light` match when an ancestor sets `data-color-mode`, so they do
not match on the element that sets `colorMode` itself. Use them for one-off
values that are not backed by a token:

```tsx
<Div boxShadow="0 1px 3px rgb(0 0 0 / 0.2)" _dark={{ boxShadow: 'none' }} />
```

`_osDark` and `_osLight` follow the system setting instead of `colorMode`:

```tsx
<Div bg="white" _osDark={{ bg: 'black' }} />
```
