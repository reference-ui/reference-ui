# Style prop reference

Every standard CSS property is a style prop, in camelCase. This page lists
only the props that have a shorthand, read a token category or take a
special value, grouped by area. For how style props work, see
[Style props](/style-props).

In each table, **Tokens** is the category a bare token name is looked up in.
A full path, such as `colors.brand` or `spacing.gutter`, works on every
property.

## Values on any property

| Syntax | Example | Effect |
| --- | --- | --- |
| Token path | `bg="colors.brand"` | The token's variable, from any category. |
| `{path}` inside a value | `border="1px solid {colors.brand}"` | Each reference becomes the token's variable. |
| Rhythm units | `p="2r 4r"`, `gap="1/3r"` | Multiples of the spacing root. See [Spacing](/spacing). |
| Leading `-` | `mt="-gutter"` | Negates a token: `calc(-1 * var(--spacing-gutter))`. |
| Trailing `!` | `mt="2r!"` | Adds `!important`. ` !important` works too. |
| Number | `width={42}` | `42px` on a length. Bare on the unitless props marked below. |

On colour properties, a token also takes an opacity or a tone after a
slash: `bg="brand/40"`, `borderColor="brand/soft"`. See [Tones](/tones).

## Border and radius

| Prop | CSS property | Tokens | Notes |
| --- | --- | --- | --- |
| `borderRadius` | `border-radius` | `radii` | |
| `borderTopLeftRadius`, `borderTopRightRadius`, `borderBottomRightRadius`, `borderBottomLeftRadius` | Each corner | `radii` | |
| `borderStartStartRadius`, `borderStartEndRadius`, `borderEndStartRadius`, `borderEndEndRadius` | Each logical corner | `radii` | |
| `borderTopRadius`, `borderRightRadius`, `borderBottomRadius`, `borderLeftRadius` | The two corners on that side | `radii` | |
| `borderStartRadius`, `borderEndRadius` | The two corners on the inline start or end | `radii` | |
| `borderColor` and each side's colour | `border-color`, `border-top-color`, … | `colors` | |
| `border`, `borderTop`, `borderRight`, `borderBottom`, `borderLeft` | `border`, … | `colors` | See the shorthand rules below. |
| `borderBlockStart`, `borderBlockEnd`, `borderInlineStart`, `borderInlineEnd` | `border-block-start`, … | `colors` | |
| `outlineColor` | `outline-color` | `colors` | |
| `borderImageOutset`, `borderImageSlice`, `borderImageWidth` | `border-image-outset`, … | | Unitless. |

`border`, `borderTop`, `borderRight`, `borderBottom`, `borderLeft` and
`outline` print separate width, style and colour properties, so a later
`borderColor` still applies. The colour part takes a colour token:
`borderBottom="1px solid ink"`.

Three values print a fixed result:

| Value | CSS |
| --- | --- |
| `border` (`true`) | `border-width: 1px; border-style: solid` |
| `border={0}` | `border-width: 0px` |
| `outline="none"` | `outline: 2px solid transparent; outline-offset: 2px` |

## Vendor properties

Vendor properties take either spelling, such as `WebkitLineClamp` or
`webkitLineClamp`. Both are the same property.
