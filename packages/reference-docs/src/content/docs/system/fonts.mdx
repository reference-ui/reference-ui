# Fonts

One `font()` call defines a font family: its CSS stack, the files to load,
the weights it ships, and a few finishing declarations. From that call the
system generates the tokens, the `@font-face` rules, and the meaning of the
`font` and `weight` props, so you never write a `@font-face` block or repeat a
font stack by hand.

## Define a family

Call `font()` with a name and the family's options, in any file your
`ui.config.ts` `include` globs cover:

```ts
// src/theme/fonts.ts
import { font } from '@reference-ui/system'

font('display', {
  value: '"Playfair Display", Georgia, serif',
  fontFace: {
    src: 'url(/fonts/playfair-display.woff2) format("woff2")',
    fontWeight: '400 900',
    fontStyle: 'normal',
    fontDisplay: 'swap',
  },
  weights: {
    normal: '420',
    bold: '700',
  },
  css: {
    letterSpacing: '-0.02em',
  },
})
```

The next `ref sync` picks it up. From then on, `font="display"` works on every
primitive and in every `css()` call.

## Use a family

The `font` prop applies the whole family at once: the stack, the family's
default weight, and its `css` declarations.

```tsx
import { H1 } from '@reference-ui/react'

<H1 font="display">Set in Playfair Display</H1>
```

The default weight is the first of: `css.fontWeight`, `weights.normal`, then
`400`.

### `font` versus `fontFamily`

- `font="display"` sets the family stack, the default weight and the `css`
  extras.
- `fontFamily="display"` sets only the stack, through the `--fonts-display`
  token. Use it when something else already owns the weight and spacing.

Both choose the family that bare weight names resolve against (below).

## Weights belong to the family

`weights` maps weight names to the numbers this family really uses. The names
are `thin`, `light`, `normal`, `semibold`, `bold` and `black`. A weight name
next to a family resolves against that family's scale:

```tsx
import { P } from '@reference-ui/react'

<P font="display" weight="normal">420, from the display scale</P>
<P font="display" weight="bold">700, from the display scale</P>
<P weight="bold">700, the CSS keyword</P>
```

| You write | Resolves to |
| --- | --- |
| `weight="bold"` with `font` or `fontFamily` on the same element | the family's `bold` |
| `weight="bold"` with no family on the element | the CSS keyword value |
| `weight="display.bold"` | the display family's `bold`, with or without a family prop |
| `weight="display.black"` when display lists no `black` | the CSS keyword for `black` (900) |
| `weight="550"` | `550` as written |

The CSS keyword values are `thin` 100, `light` 300, `normal` 400, `semibold`
600, `bold` 700 and `black` 900. Use the scoped form, `display.bold`, when the
weight is set apart from the family, such as on a child element.

## Load the files

The engine prints one `@font-face` rule per `fontFace` entry, inside the
`global` layer. You choose where the files live:

- **Self-hosted.** Put the `.woff2` files in your app's public folder and
  point `src` at them, as in the example above.
- **Remote.** Point `src` at a font provider's URL. The shape is the same.

Pass an array to `fontFace` when a family needs several files, for example
one per style:

```ts
font('body', {
  value: '"Source Serif", Georgia, serif',
  fontFace: [
    { src: 'url(/fonts/source-serif.woff2) format("woff2")', fontStyle: 'normal' },
    { src: 'url(/fonts/source-serif-italic.woff2) format("woff2")', fontStyle: 'italic' },
  ],
  weights: { normal: '400', bold: '700' },
})
```

`sizeAdjust` and `descentOverride` scale a face's metrics so the fallback
font takes up nearly the same space while the web font loads. Add them if
you see text jump on first paint.

## What a family generates

For `font('display', …)` the stylesheet gains:

- `--fonts-display`, the stack, as a token in the `fonts` category;
- `--font-weights-display-normal`, `--font-weights-display-bold` and so on,
  one per listed weight;
- the `@font-face` rules in `@layer global`;
- the `display` scale that `font` and `weight` resolve against.

Remove the `font()` call and the next sync removes all of it.

## `font()` reference

```ts
function font(name: string, options: FontOptions): void
```

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `value` | `string` | yes | The `font-family` stack, written as it appears in CSS, quotes included. |
| `fontFace` | `FontFaceRule \| FontFaceRule[]` | yes | The files to load. |
| `weights` | `Partial<Record<FontWeightName, string>>` | yes | Weight name to numeric weight. Only listed names belong to the family. |
| `css` | `Record<string, string>` | no | Declarations applied with `font`, such as `letterSpacing`. A `fontWeight` here sets the default weight. |

`FontFaceRule`:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `src` | `string` | yes | The `src` descriptor, such as `url(…) format("woff2")`. |
| `fontWeight` | `string` | no | The weight or range the file covers, such as `'400 900'`. |
| `fontStyle` | `string` | no | `normal` or `italic`. |
| `fontDisplay` | `string` | no | Loading behaviour. `swap` keeps text visible while the file loads. |
| `sizeAdjust` | `string` | no | Scales the face's glyphs, such as `'105%'`. |
| `descentOverride` | `string` | no | Overrides the face's descent metric, such as `'20%'`. |

`FontWeightName` is `'thin' | 'light' | 'normal' | 'semibold' | 'bold' | 'black'`.
