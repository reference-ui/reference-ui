# Fonts

`font()` registers a font family along with its fallback stack, `@font-face`
sources, and named weights. `ref sync` compiles each definition into font
tokens, `@font-face` rules, and typed values for the `font` and `weight` props.
The default families included in `@reference-ui/lib` are covered in
[Typography](/typography).

## Define a family

Call `font()` in a file matched by your config's `include`:

```ts
// src/theme/fonts.ts
import { font } from '@reference-ui/system'

font('display', {
  value: '"Playfair Display", Georgia, serif',
  fontFace: {
    src: 'url(/fonts/playfair-display.woff2) format("woff2")',
    fontWeight: '400 900',
  },
  weights: {
    normal: '420',
    bold: '700',
  },
  css: {
    letterSpacing: '-0.02em',
  },
})
```

After the next `ref sync`, `font="display"` works on every primitive and in
every `css()` call.

## Use a family

The `font` prop applies the font stack, the family's default weight, and any
additional `css` declarations:

```tsx
import { H1 } from '@reference-ui/react'

<H1 font="display">Set in Playfair Display</H1>
```

The default weight resolves to `css.fontWeight` if defined, falling back to
`weights.normal` and then `400`.

Use `fontFamily="display"` when you only want to set `font-family` without
applying the family's default weight or `css` declarations.

## Weights

`weights` maps standard weight names (`thin`, `light`, `normal`, `semibold`,
`bold`, and `black`) to numeric weights for the family.

```tsx
import { P } from '@reference-ui/react'

<P font="display" weight="normal">420, from the display family</P>
<P font="display" weight="bold">700, from the display family</P>
<P weight="bold">700, the CSS value</P>
```

| You write | Resolves to |
| --- | --- |
| `weight="bold"` with `font` or `fontFamily` on the same element | The family's `bold` |
| `weight="bold"` with no family on the element | The CSS value, `700` |
| `weight="bold"` with two different families on the element | The CSS value, `700` |
| `weight="display.bold"` | The display family's `bold`, anywhere |
| `weight="display.black"` when display has no `black` | The CSS value, `900` |
| `weight="550"` | `550` |

Standard CSS fallback weights are `thin` (`100`), `light` (`300`), `normal`
(`400`), `semibold` (`600`), `bold` (`700`), and `black` (`900`). Use the
qualified `display.bold` syntax on child elements that inherit their font family
from an ancestor.

## Load the files

`ref sync` emits a `@font-face` rule for each `fontFace` entry. It uses the
first font name in `value` as the `font-family` and defaults `font-display` to
`swap` unless `fontDisplay` is specified. Point `src` to files in your public
directory or an external font URL.

Pass an array of `fontFace` objects when a family is split across multiple
files:

```ts
font('body', {
  value: '"Source Serif", Georgia, serif',
  fontFace: [
    { src: 'url(/fonts/source-serif.woff2) format("woff2")', fontStyle: 'normal' },
    { src: 'url(/fonts/source-serif-italic.woff2) format("woff2")', fontStyle: 'italic' },
  ],
  weights: { normal: '400', bold: '700' },
})
```

To reduce layout shift while the font loads, use `sizeAdjust` and
`descentOverride` to match the fallback font's metrics.

## What a family generates

For `font('display', …)`, `ref sync` generates:

- `--fonts-display`: the `font-family` stack, registered as a `fonts` token.
- `--font-weights-display-normal`, `--font-weights-display-bold`, etc.: a
  `fontWeights` token for each configured weight.
- `@font-face` rules in the `global` [cascade layer](/cascade-layers).

## Reference

```ts
function font(name: string, options: FontOptions): void
```

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `value` | `string` | Yes | The `font-family` stack, as written in CSS. |
| `fontFace` | `FontFaceRule \| FontFaceRule[]` | Yes | The files to load. |
| `weights` | `Partial<Record<FontWeightName, string>>` | Yes | Weight name to number. |
| `css` | `Record<string, string>` | No | Additional CSS declarations applied by the `font` prop, such as `letterSpacing`. Setting `fontWeight` here overrides the default weight. |

`FontFaceRule`:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `src` | `string` | Yes | The `src` descriptor, such as `url(…) format("woff2")`. |
| `fontWeight` | `string` | No | The weight or range the file covers, such as `'400 900'`. |
| `fontStyle` | `string` | No | `normal` or `italic`. |
| `fontDisplay` | `string` | No | The `font-display` descriptor while the font loads. Defaults to `swap`. |
| `sizeAdjust` | `string` | No | Scales the glyphs, such as `'105%'`. |
| `descentOverride` | `string` | No | Overrides the descent metric, such as `'20%'`. |

`FontWeightName` is `'thin' | 'light' | 'normal' | 'semibold' | 'bold' | 'black'`.
