# Fonts

`font()` defines a font family: its CSS stack, the files to load, and the
weights it ships. Sync turns it into tokens, `@font-face` rules and the
`font` and `weight` props.

## Define a family

```ts
// src/theme/fonts.ts
import { font } from '@reference-ui/system'

font('display', {
  value: '"Playfair Display", Georgia, serif',
  fontFace: {
    src: 'url(/fonts/playfair-display.woff2) format("woff2")',
    fontWeight: '400 900',
    fontDisplay: 'swap',
  },
  weights: {
    normal: '420',
    bold: '700',
  },
  css: {
    letterSpacing: '-0.02em',
  },
})
```

After the next `ref sync`, `font="display"` works on every primitive and in
every `css()` call.

## Use a family

The `font` prop applies the stack, the family's default weight and its `css`
declarations:

```tsx
import { H1 } from '@reference-ui/react'

<H1 font="display">Set in Playfair Display</H1>
```

The default weight is `css.fontWeight` if set, then `weights.normal`, then
`400`.

`fontFamily="display"` sets only the stack. Use it when something else sets
the weight and spacing.

## Weights

`weights` maps weight names to the numbers this family uses. The names are
`thin`, `light`, `normal`, `semibold`, `bold` and `black`.

```tsx
import { P } from '@reference-ui/react'

<P font="display" weight="normal">420, from the display family</P>
<P font="display" weight="bold">700, from the display family</P>
<P weight="bold">700, the CSS value</P>
```

| You write | Resolves to |
| --- | --- |
| `weight="bold"` with `font` or `fontFamily` on the same element | The family's `bold` |
| `weight="bold"` with no family on the element | The CSS value, `700` |
| `weight="display.bold"` | The display family's `bold`, anywhere |
| `weight="display.black"` when display has no `black` | The CSS value, `900` |
| `weight="550"` | `550` |

The CSS values are `thin` 100, `light` 300, `normal` 400, `semibold` 600,
`bold` 700 and `black` 900. Use the `display.bold` form on an element that
does not set the family itself, such as a child.

## Load the files

Sync writes one `@font-face` rule for each `fontFace` entry. Point `src` at
files in your app's public folder, or at a font provider's URL.

Pass an array when a family has several files:

```ts
font('body', {
  value: '"Source Serif", Georgia, serif',
  fontFace: [
    { src: 'url(/fonts/source-serif.woff2) format("woff2")', fontStyle: 'normal' },
    { src: 'url(/fonts/source-serif-italic.woff2) format("woff2")', fontStyle: 'italic' },
  ],
  weights: { normal: '400', bold: '700' },
})
```

If text jumps when the font loads, use `sizeAdjust` and `descentOverride` to
make the fallback font take up the same space.

## What a family generates

For `font('display', …)`, the stylesheet gets:

- `--fonts-display`, the stack, as a `fonts` token;
- `--font-weights-display-normal`, `--font-weights-display-bold` and so on,
  one for each weight;
- the `@font-face` rules, in the `global` [cascade layer](/cascade-layers).

## Reference

```ts
function font(name: string, options: FontOptions): void
```

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `value` | `string` | Yes | The `font-family` stack, as written in CSS. |
| `fontFace` | `FontFaceRule \| FontFaceRule[]` | Yes | The files to load. |
| `weights` | `Partial<Record<FontWeightName, string>>` | Yes | Weight name to number. |
| `css` | `Record<string, string>` | No | Declarations the `font` prop adds, such as `letterSpacing`. A `fontWeight` here is the default weight. |

`FontFaceRule`:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `src` | `string` | Yes | The `src` descriptor, such as `url(…) format("woff2")`. |
| `fontWeight` | `string` | No | The weight or range the file covers, such as `'400 900'`. |
| `fontStyle` | `string` | No | `normal` or `italic`. |
| `fontDisplay` | `string` | No | How text shows while the file loads, such as `swap`. |
| `sizeAdjust` | `string` | No | Scales the glyphs, such as `'105%'`. |
| `descentOverride` | `string` | No | Overrides the descent metric, such as `'20%'`. |

`FontWeightName` is `'thin' | 'light' | 'normal' | 'semibold' | 'bold' | 'black'`.
