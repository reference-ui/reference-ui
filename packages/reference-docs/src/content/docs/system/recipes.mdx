# Recipes

A recipe defines the variants of a component: base styles plus named
variants, such as `tone` and `size`. `recipe()` returns a function that gives
the class names for the variants you pick.

## Define a recipe

```tsx
import { recipe } from '@reference-ui/react'

const button = recipe({
  className: 'button',
  base: { paddingInline: '4r', borderRadius: 'card' },
  variants: {
    tone: {
      primary: { bg: 'brand', color: 'white' },
      quiet: { bg: 'transparent', color: 'brand' },
    },
    size: {
      sm: { height: '8r' },
      lg: { height: '12r' },
    },
  },
  defaultVariants: { tone: 'primary', size: 'sm' },
})

<button className={button({ tone: 'quiet' })}>Cancel</button>
```

Pass `recipe()` an object literal. A recipe the compiler cannot read fails
sync.

## Options

| Option | Type | Description |
| --- | --- | --- |
| `className` | `string` | Names the recipe. Two recipes with the same name in one system fail sync. |
| `base` | style object | Styles every choice gets. |
| `variants` | `Record<string, Record<string, StyleObject>>` | One style object per value of each variant. Use `true` and `false` keys for a boolean variant. |
| `defaultVariants` | `Record<string, string>` | The value used when a call leaves a variant out. |
| `compoundVariants` | `Array<{ [variant]: value, css: StyleObject }>` | Styles that apply only when every listed variant matches. |

## Compound variants

`compoundVariants` adds styles that apply only when every listed variant
matches:

```tsx
const button = recipe({
  // …
  compoundVariants: [{ tone: 'quiet', size: 'lg', css: { fontWeight: '600' } }],
})
```

## Responsive variants

A variant value can be responsive: `button({ size: { base: 'sm', md: 'lg' } })`.

## Helpers

The returned function also has:

- `raw(props)`, which returns the merged style object instead of class names;
- `variantKeys` and `variantMap`, which list the variants and their values;
- `splitVariantProps(props)`, which splits variant props from the rest.

## Types

`RecipeVariantProps` gives the props type of a recipe:

```ts
import type { RecipeVariantProps } from '@reference-ui/react'

type ButtonVariants = RecipeVariantProps<typeof button>
// { tone?: 'primary' | 'quiet'; size?: 'sm' | 'lg' }
```

## Cascade layer

Recipe classes live in the `recipes` [cascade layer](/cascade-layers),
below utilities. A style prop or `css()` class on the same element always
wins over the recipe.
