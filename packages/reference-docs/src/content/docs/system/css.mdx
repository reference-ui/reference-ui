# CSS

`css()` turns a style object into a class name for any element. It is
compiled ahead of time: the compiler reads the calls from your source and
writes their rules into the stylesheet. For a component with variants, use a
[recipe](/recipes).

## `css()`

```tsx
import { css } from '@reference-ui/react'

const card = css({
  padding: '4r',
  bg: 'surface',
  borderRadius: 'card',
  _hover: { bg: 'surface/80' },
})

<article className={card}>…</article>
```

A style object takes the same keys and values as
[style props](/style-props).

### Combine styles

`css()` takes any number of style objects, or arrays of them. For the same
property, the later object wins. `null`, `false` and `undefined` are skipped:

```ts
const button = css(
  { padding: '2r', color: 'text' },
  isActive && { color: 'brand' },
  size === 'lg' ? { padding: '4r' } : null,
)
```

A `null`, `false` or `undefined` value inside an object is skipped too, so
`{ color: undefined }` never overrides an earlier `color`.

```ts
function css(...styles: Array<CssStyles | CssStyles[]>): string

type CssStyles = SystemStyleObject | undefined | null | false
```

## Values

| Value | Example | Result |
| --- | --- | --- |
| Token name | `color: 'brand'` | `var(--colors-brand)`. See [Tokens](/tokens). |
| Token reference | `border: '1px solid {colors.line}'` | Expands inside any string. |
| Opacity or tone | `bg: 'brand/40'`, `bg: 'brand/soft'` | A `color-mix()` of the colour. |
| Rhythm | `gap: '3r'` | `calc(3 * var(--spacing-root))`. See [Spacing](/spacing). |
| Number | `width: 42`, `opacity: 0.5` | `42px` on lengths, bare otherwise. |
| Any CSS | `bg: 'linear-gradient(…)'` | Printed as written. |
| Important | `color: 'brand !important'` or `'brand!'` | Marks the declaration `!important`. |
| Custom property | `'--card-gap': '2r'` | Keeps its casing. |

## Selectors and at-rules

Keys that start with `_` are [named conditions](/style-props#conditions).
Keys that start with `&` are selectors relative to the element. Keys that
start with `@media`, `@container` or `@supports` are at-rules:

```ts
css({
  color: 'text',
  _hover: { color: 'brand' },
  '& > svg': { flexShrink: 0 },
  '&:not(:first-child)': { marginTop: '2r' },
  '@supports (backdrop-filter: blur(4px))': { backdropFilter: 'blur(4px)' },
})
```

Breakpoint keys such as `md` are covered in [Responsive](/responsive).
Conditions nest, and a nested rule applies only when every condition around
it matches.

## What the compiler can read

The compiler reads `css()` calls only when `css` is imported from
`@reference-ui/react` or `@reference-ui/styled`. A renamed import, such as
`import { css as style }`, still counts, and so does a file of yours that
re-exports `css` from either package. A local function named `css`, or a
`css` from another package, is not read. The same rule applies to
[`recipe()`](/recipes).

The compiler reads your source without running it. It can read:

- literal objects and values in a `css()` call or a style prop;
- `const` objects and values, in the same file or imported from another;
- both branches of a ternary, such as `active ? 'brand' : 'text'`;
- spreads of objects it can read, including `...(flag && extra)`.

A value it cannot read, such as the result of a function call, gets no CSS.
`ref sync` warns at the call site, and in development the browser console
names the property and value that missed.

### Values chosen at runtime

When the choice is made at runtime, write each option as its own `css()`
call and pick between the class names:

```tsx
const toneClass = {
  info: css({ color: 'blue' }),
  danger: css({ color: 'red' }),
}

<p className={toneClass[kind]}>…</p>
```

When the value itself comes from runtime data, read it from a custom property
and set that property in `style`:

```tsx
<div
  className={css({ bg: 'var(--swatch)' })}
  style={{ '--swatch': user.color }}
>
  …
</div>
```

### Generate values ahead of time

For values that appear nowhere in your source, list them under `staticCss`
in `ui.config.ts`. Each key is a property, optionally with a condition
prefix. Each value lists token names, or `'*'` for the whole category:

```ts
// ui.config.ts
export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  staticCss: {
    color: ['*'],
    '_hover:bg': ['brand', 'surface'],
  },
})
```

Sync fails if an entry names a token that does not exist.
