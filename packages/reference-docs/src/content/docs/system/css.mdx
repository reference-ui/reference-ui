# CSS

`css()` takes a style object and returns a class name string. Calls are
extracted statically at build time and compiled into the stylesheet. For
components with multiple variants, use a [recipe](/recipes).

## `css()`

Pass a style object to `css()` and apply the returned class string to any
element:

```tsx
import { css } from '@reference-ui/react'

const card = css({
  padding: '4r',
  bg: 'surface',
  borderRadius: 'card',
  _hover: { bg: 'surface/80' },
})

<article className={card}>…</article>
```

A style object accepts the same keys and values as
[style props](/style-props).

### Combine styles

`css()` accepts multiple style objects or nested arrays of style objects. When
the same property appears more than once, the later value takes precedence.
`null`, `false`, and `undefined` arguments are ignored:

```ts
const button = css(
  { padding: '2r', color: 'text' },
  isActive && { color: 'brand' },
  size === 'lg' ? { padding: '4r' } : null,
)
```

`null`, `false`, and `undefined` property values are also ignored, so
`{ color: undefined }` does not override an earlier `color`.

```ts
function css(...styles: Array<CssStyles | CssStyles[]>): string

type CssStyles = SystemStyleObject | undefined | null | false
```

## Values

| Value | Example | Result |
| --- | --- | --- |
| Token name | `color: 'brand'` | `var(--colors-brand)`. See [Tokens](/tokens). |
| Token reference | `border: '1px solid {colors.line}'` | Expands inside any string. |
| Opacity or tone | `bg: 'brand/40'`, `bg: 'brand/soft'` | Mixes the colour with transparency via `color-mix()`. |
| Rhythm | `gap: '3r'` | `calc(3 * var(--spacing-root))`. See [Spacing](/spacing). |
| Number | `width: 42`, `opacity: 0.5` | `42px` for length properties; unitless otherwise. |
| Any CSS | `bg: 'linear-gradient(…)'` | Passed through as written. |
| Important | `color: 'brand !important'` or `'brand!'` | Marks the declaration `!important`. |
| Custom property | `'--card-gap': '2r'` | Preserves the custom property name. |

## Selectors and at-rules

Keys that start with `_` are [named conditions](/style-props#conditions).
Keys that start with `&` are selectors relative to the element. Keys that
start with `@media`, `@container` or `@supports` are at-rules:

```ts
css({
  color: 'text',
  _hover: { color: 'brand' },
  '& > svg': { flexShrink: 0 },
  '&:not(:first-child)': { marginTop: '2r' },
  '@supports (backdrop-filter: blur(4px))': { backdropFilter: 'blur(4px)' },
})
```

Breakpoint keys such as `md` are covered in [Responsive](/responsive).
Conditions can be nested, and a nested rule applies only when all enclosing
conditions match.
