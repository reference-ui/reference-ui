# CLI

The `ref` CLI is provided by `@reference-ui/core`.

| Command | Description |
| --- | --- |
| `ref init` | Writes a default `ui.config.ts`. |
| `ref sync` | Compiles your stylesheet and types into `.reference-ui/`. |
| `ref clean` | Removes `.reference-ui/` and the `node_modules/@reference-ui/` symlinks. |

Every command takes an optional project directory, `[dir]`, which defaults to
the current directory.

## init

```bash
npx ref init [dir]
```

Creates a `ui.config.ts` file in the project directory. It sets `name` from
`package.json` (defaulting to `'my-app'`), sets `include` to
`['src/**/*.{ts,tsx}']`, and extends `@reference-ui/lib/baseSystem`.

If `ui.config.ts`, `ui.config.js`, or `ui.config.mjs` already exists,
`ref init` exits with code 1 without modifying the file.

## sync

```bash
npx ref sync [dir]
npx ref sync --watch [dir]
```

Compiles your config and source files, writes the generated packages to
`.reference-ui/`, and links them into `node_modules/@reference-ui/`. See
[Sync](/sync).

| Option | Description |
| --- | --- |
| `--watch` | Watch matched files and the config for changes and resync automatically. |
| `--verbose` | List every warning with its location and a fix hint. |
| `--quiet` | Suppress output on success; only print errors. |
| `--json` | Write diagnostics as a JSON array to stdout and send all other output to stderr. |
| `--break-lock` | Force-acquire the sync lock from another process. |
| `--debug` | Log file-watcher events in watch mode. |

Only one sync runs per project at a time. If a watch session is already
running, a one-off `ref sync` triggers a resync in that session and exits with
code 0, while a second `ref sync --watch` attaches to the active session until
it stops.

With `--watch --json`, each resync writes a JSON diagnostics array to stdout,
including failed runs.

## clean

```bash
npx ref clean [dir]
```

Stops any running `ref sync` process for the project, then removes
`.reference-ui/` and the symlinks in `node_modules/@reference-ui/`. Run
`ref sync` to regenerate them.
