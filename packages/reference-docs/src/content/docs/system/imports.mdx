# Imports and packages

You install `@reference-ui/core`, `@reference-ui/lib` and
`@reference-ui/icons`. `ref sync` generates the rest into `.reference-ui/` and
links them into `node_modules/@reference-ui/`, so run sync once before you
typecheck or build. Don't edit the generated packages: each sync rewrites
them. See [Sync](/sync).

## `@reference-ui/core`

Install it as a dev dependency. It also provides the `ref` CLI.

### `defineConfig`

Returns your config as given, typed as `ReferenceUIConfig`. See [Config](/config).

### `extendSystem(base, { tokens })`

Returns a copy of a base system with your token values. See
[Base systems](/base-systems#extendsystem).

### Types

`ReferenceUIConfig`, `BaseSystem`, and the input types for each theme call:
`TokenConfig`, `FontOptions`, `KeyframesConfig`, `GlobalCssConfig` and
`RecipeConfig`.

## `@reference-ui/system`

Generated by sync. Sync runs every file in your `include` that imports from
here and collects its calls.

### `tokens(config)`

Adds tokens. See [Tokens](/tokens).

### `font(name, options)`

Adds a font family. See [Fonts](/fonts).

### `keyframes(config)`

Adds keyframes. See [Animation](/animation).

### `globalCss(config)`

Adds global styles. See [Global CSS](/global-css).

### `recipe(config)`

Adds a recipe to the system, so sync emits its CSS. See [Recipes](/recipes).

### `getRhythm(num, denom?)`

Returns a rhythm value as a CSS string. See [Spacing](/spacing).

### `baseSystem`

Your system, ready for another app's `extends` or `layers`. Also exported on
its own from `@reference-ui/system/baseSystem`. See
[Export a base system](/export-base-system).

## `@reference-ui/react`

Generated by sync, and bound to your system.

### Primitives

One component per HTML element: `Div`, `Span`, `Button`, `Input` and the
rest. See [Primitives](/primitives).

### `css(...styles)`

Returns a class name for one or more style objects. See [css()](/css).

### `recipe(config)`

Returns a function that picks classes from variants. See [Recipes](/recipes).

### `useColorMode()`

Returns `'light'`, `'dark'` or `undefined` from the nearest `colorMode`. See
[Light and dark](/light-and-dark).

### Types

`SystemStyleObject`, `StyleProps`, `<Tag>Props`, `RecipeVariantProps` and the
token unions. See [Types](/types).

### `@reference-ui/react/styles.css`

The compiled stylesheet. Import it once in your app's entry file.

## `@reference-ui/types`

Generated by sync from the files in your `include`.

### `Reference`

Renders the API of any interface or type alias in those files. See
[Reference](/reference).

## `@reference-ui/lib`

The component library. Install it as a dependency.

### Components

`Overlay`, `Tabs`, `Field` and the rest. See [Components](/components).

### `@reference-ui/lib/baseSystem`

The library's system for your `extends`, icons included. Import it from this
entry in `ui.config.ts`: the root entry slows config loading.

### `@reference-ui/lib/theme`

The theme values as plain objects: `colors`, `fonts`, `radii`, `tones` and
the rest. See [Foundations](/foundations).

## `@reference-ui/icons`

Material Symbols icons as components. Install it as a dependency.

### Icons

`SearchIcon` and the rest. See [Icons](/icons).

### `@reference-ui/icons/baseSystem`

The icons' system, for `layers` when you don't extend the library.
