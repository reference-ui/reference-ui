# Imports and packages

`@reference-ui/core`, `@reference-ui/lib`, and `@reference-ui/icons` are
installed from npm. The remaining `@reference-ui/*` packages are generated by
`ref sync` into `.reference-ui/` and linked into `node_modules/@reference-ui/`.
Run `ref sync` before typechecking or building, and do not edit the generated
files directly. See [Sync](/sync).

## `@reference-ui/core`

Install it as a dev dependency. It also provides the `ref` CLI.

### `defineConfig`

Returns your config as given, typed as `ReferenceUIConfig`. See [Config](/config).

### `extendSystem(base, { tokens })`

Returns a copy of a base system with your token values. See
[Base systems](/base-systems#extendsystem).

### Types

`ReferenceUIConfig`, `BaseSystem`, and the input types for each theme call:
`TokenConfig`, `FontOptions`, `KeyframesConfig`, `GlobalCssConfig` and
`RecipeConfig`.

## `@reference-ui/system`

Generated by `ref sync`. Files matched by `include` that import from
`@reference-ui/system` are evaluated during sync to collect theme and global
style definitions.

### `tokens(config)`

Registers design tokens. See [Tokens](/tokens).

### `font(name, options)`

Registers a font family and its `@font-face` rules. See [Fonts](/fonts).

### `keyframes(config)`

Registers CSS `@keyframes` rules. See [Animation](/animation).

### `globalCss(config)`

Registers global CSS rules. See [Global CSS](/global-css).

### `recipe(config)`

Registers a component recipe and compiles its variant classes. See [Recipes](/recipes).

### `getRhythm(num, denom?)`

Returns a rhythm value as a CSS string. See [Spacing](/spacing).

### `baseSystem`

Your compiled base system artifact for use in another project's `extends` or
`layers`. Also exported from the standalone `@reference-ui/system/baseSystem`
entry point. See [Export a base system](/export-base-system).

## `@reference-ui/react`

Generated by `ref sync` and scoped to your system.

### Primitives

JSX primitives for standard HTML elements (`Div`, `Span`, `Button`, `Input`,
and others) that accept style props. See [Primitives](/primitives).

### `css(...styles)`

Returns a class name for one or more style objects. See [css()](/css).

### `recipe(config)`

Defines a multi-variant style recipe and returns its runtime class selector
function. See [Recipes](/recipes).

### `useColorMode()`

Returns `'light'`, `'dark'`, or `undefined` from the nearest ancestor
`colorMode` boundary. See [Light and dark](/light-and-dark).

### Types

`SystemStyleObject`, `StyleProps`, `<Tag>Props`, `RecipeVariantProps` and the
token unions. See [Types](/types).

### `@reference-ui/react/styles.css`

The compiled stylesheet. Import it once in your app's entry file.

## `@reference-ui/types`

Generated by sync from the files in your `include`.

### `Reference`

Renders the API of any interface or type alias in those files. See
[Reference](/reference).

## `@reference-ui/lib`

The component library. Install it as a dependency.

### Components

UI components such as `Overlay`, `Tabs`, and `Field`. See [Components](/components).

### `@reference-ui/lib/baseSystem`

The library's precompiled base system (including `@reference-ui/icons`) for
`extends` or `layers`. Always import from this subpath in `ui.config.ts`
rather than the package root.

### `@reference-ui/lib/theme`

The default theme definitions exported as plain TypeScript objects (`colors`,
`fonts`, `radii`, `tones`, and others). See [Foundations](/foundations).

## `@reference-ui/icons`

Material Symbols icons as components. Install it as a dependency.

### Icons

Material Symbols icon components such as `SearchIcon`. See [Icons](/icons).

### `@reference-ui/icons/baseSystem`

The icon package's base system, for use in `layers` when your project does not
already extend `@reference-ui/lib/baseSystem`.
