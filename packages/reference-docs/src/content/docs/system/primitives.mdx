# Primitives

Each primitive component renders a corresponding HTML element and accepts
[style props](/style-props): `Div` renders a `<div>`, `Button` renders a
`<button>`, and `H2` renders an `<h2>`.

<Preview>
  <PrimitiveCard />
</Preview>

```tsx
import { A, Div, H3, P } from '@reference-ui/react'

export function Card() {
  return (
    <Div display="grid" gap="2r" padding="5r" borderRadius="md" bg="surface" _hover={{ bg: 'raised' }}>
      <H3 margin="0">A card</H3>
      <P margin="0" color="muted">A Div, an H3, a P and an A.</P>
      <A href="/props" color="brand">Read the props</A>
    </Div>
  )
}
```

`ref sync` generates primitives in `@reference-ui/react` with TypeScript types
for your configured tokens.

## One component per element

Each HTML element has its own component typed for that tag: `A` takes `href`,
`Input` takes `value`, and `ref` gives you the underlying `HTMLAnchorElement`
or `HTMLInputElement`.

## Props

| Prop | Description |
| --- | --- |
| Element props | Standard HTML attributes for the underlying tag (`id`, `className`, `aria-*`, `data-*`, event handlers, `children`, `ref`), forwarded to the DOM element. |
| Style props | CSS properties and conditions such as `_hover`. Compiled to class names and stripped before rendering to the DOM. See [Style props](/style-props). |
| `css` | A style object or array of style objects, compiled like [`css()`](/css). Overrides style props on the same element. |
| `colorMode` | `'light'` or `'dark'`. Sets `data-color-mode` on the element and scopes colour mode tokens for its descendants. |
| `variant` | Sets `data-variant` on the element for targeting in `globalCss()`. |

Any `className` you pass is appended to the generated utility classes. Every
primitive also includes a tag class such as `ref-div` or `ref-button` that can
be targeted in `globalCss()`.

```tsx
<Div
  id="summary"
  aria-live="polite"
  onClick={handleClick}
  padding="4r"
  css={{ _hover: { bg: 'raised' } }}
/>
```

## Colour mode

`colorMode` sets the active mode for an element and its subtree, overriding the
page mode. Modes can be nested, and tokens with
[light and dark values](/tokens#light-and-dark-values) resolve against the
nearest ancestor mode. See [Light and dark](/light-and-dark).

Read the current mode with `useColorMode()`. It returns the nearest
primitive's mode, or the `data-color-mode` of `html` or `body`:

```tsx
import { useColorMode } from '@reference-ui/react'

function ModeLabel() {
  const mode = useColorMode() // 'light', 'dark' or undefined
  return <span>{mode ?? 'page default'}</span>
}
```

## `data-layer`

Primitives set `data-layer` to your system's [`name`](/config#name) so the
stylesheet can scope colour mode tokens per system. Inside a colour mode
boundary, descendants from the same system omit `data-layer` to avoid redundant
DOM attributes, while primitives that set `colorMode` or belong to another
system always include it. See [Cascade layers](/cascade-layers).

## Your own components

When a custom component forwards its props to a primitive, the compiler traces
style props passed from parent to child automatically. For example,
`<Card padding="4r" />` is extracted at build time when `Card` spreads its props
onto a `<Div {...props} />`. The compiler traces props across component
boundaries, spreads, higher-order components, re-exports, and barrel files
without manual registration. Class components are not traced and trigger a
warning during `ref sync` if passed style props.

Props consumed by the component itself (such as a `size` prop mapped to
`data-size`) are treated as regular component props rather than style props.

Components imported from an external package (such as `@reference-ui/lib`)
accept style props when that package is listed in `extends` or `layers` in
`ui.config.ts`. Otherwise, `ref sync` logs a warning naming the package.

## Types

Each primitive exports its props type: `DivProps`, `ButtonProps`, and so on.
`PrimitiveProps<'div'>` is the same type by tag name, and `StyleProps` is the
style props alone:

```ts
import type { PrimitiveProps, StyleProps } from '@reference-ui/react'

type PanelProps = PrimitiveProps<'section'> & { title: string }
```
