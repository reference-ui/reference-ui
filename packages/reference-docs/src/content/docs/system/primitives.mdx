# Primitives

A primitive renders one HTML element and takes [style props](/style-props):
`Div` renders a `div`, `Button` a `button`, `H2` an `h2`.

<Preview>
  <PrimitiveCard />
</Preview>

```tsx
import { A, Div, H3, P } from '@reference-ui/react'

export function Card() {
  return (
    <Div display="grid" gap="2r" padding="5r" borderRadius="md" bg="surface" _hover={{ bg: 'raised' }}>
      <H3 margin="0">A card</H3>
      <P margin="0" color="muted">A Div, an H3, a P and an A.</P>
      <A href="/props" color="brand">Read the props</A>
    </Div>
  )
}
```

`ref sync` generates the primitives into `@reference-ui/react`, typed against
your tokens.

## One component per element

Each HTML element has its own component. You choose the element by
choosing the component, so each one is typed for its element: `A` takes
`href`, `Input` takes `value`, and `ref` gives you the real
`HTMLAnchorElement` or `HTMLInputElement`.

## Props

| Prop | Description |
| --- | --- |
| Element props | Everything the element accepts: `id`, `className`, `aria-*`, `data-*`, event handlers, `children`, `ref`. They reach the DOM unchanged. |
| Style props | CSS properties and conditions such as `_hover` as props. See [Style props](/style-props). They never reach the DOM. |
| `css` | A style object, or an array of them, applied like [`css()`](/css). It wins over a style prop for the same property. |
| `colorMode` | `'light'` or `'dark'`. Sets `data-color-mode` on the element and the primitives inside it. |
| `variant` | Sets `data-variant` on the element, for `globalCss()` rules that select on it. |

Your `className` is added to the classes the primitive generates. Every
primitive also carries a class named after its tag, such as `ref-div` or
`ref-button`, which `globalCss()` rules can select.

```tsx
<Div
  id="summary"
  aria-live="polite"
  onClick={handleClick}
  padding="4r"
  css={{ _hover: { bg: 'raised' } }}
/>
```

## Colour mode

`colorMode` sets the mode for an element and everything inside it, whatever
the page uses. Modes nest. Tokens with [light and dark values](/tokens#light-and-dark-values)
resolve in the nearest mode. [Light and dark](/light-and-dark) shows how to
toggle it.

Read the current mode with `useColorMode()`. It returns the nearest
primitive's mode, or the `data-color-mode` of `html` or `body`:

```tsx
import { useColorMode } from '@reference-ui/react'

function ModeLabel() {
  const mode = useColorMode() // 'light', 'dark' or undefined
  return <span>{mode ?? 'page default'}</span>
}
```

## `data-layer`

A primitive sets `data-layer` to your system's [`name`](/config#name).
Inside a colour mode, a primitive skips it when its nearest primitive
ancestor is from the same system. A primitive with `colorMode`, or one from
another system, always sets it. The stylesheet uses the attribute to keep
two systems on one page apart. See [Cascade layers](/cascade-layers).

## Your own components

A component that passes style props on to a primitive takes style props
too. `<Card padding="4r" />` compiles when `Card` spreads its props onto a
`Div`. The compiler follows props through spreads, other components,
higher-order components, re-exports and barrel files, so there is nothing to
register. Class components are not followed: `ref sync` warns
`STT-W-CLASS-COMPONENT` for one that takes style props.

A prop the component keeps for itself, such as a `size` it turns into
`data-size`, stays the component's own prop.

Components from a package, such as those in `@reference-ui/lib`, take style
props when that package's system is in `extends` or `layers`. Otherwise
`ref sync` warns `ATM-W-EXTERNAL-UNBACKED` and names the package.

## Types

Each primitive exports its props type: `DivProps`, `ButtonProps`, and so on.
`PrimitiveProps<'div'>` is the same type by tag name, and `StyleProps` is the
style props alone:

```ts
import type { PrimitiveProps, StyleProps } from '@reference-ui/react'

type PanelProps = PrimitiveProps<'section'> & { title: string }
```
