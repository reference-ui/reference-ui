# Config

`ui.config.ts` tells `ref sync` what your system is called, which files to
read, and which systems it builds on.

```ts
// ui.config.ts
import { defineConfig } from '@reference-ui/core'
import { baseSystem } from '@reference-ui/lib/baseSystem'

export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  extends: [baseSystem],
})
```

`ref init` writes this file for you. `defineConfig` returns its argument
unchanged; it only adds type checking.

Sync looks for `ui.config.ts`, `ui.config.js` or `ui.config.mjs`, in that
order, in the directory it runs in. It does not search parent directories.
In watch mode, sync reloads the config when it or a file it imports changes.

Import only data modules into the config. Import a base system from its
`baseSystem` subpath, not from the package root: when the config takes more
than 750 ms to load, sync warns `BSS-W-SLOW-CONFIG` and names the slow import.

## Required

### name

**Type**: `string`

The name of your system. It names your system's cascade layer, and primitives
write it to the DOM as `data-layer`. It must not be empty or contain double
quotes, backslashes or newlines.

### include

**Type**: `string[]`

Glob patterns for the files sync reads, relative to the config's directory.
Sync finds style props and `css()` calls in `.ts`, `.tsx`, `.js` and `.jsx`
files, and runs the files that call `tokens()`, `font()`, `keyframes()` or
`globalCss()`. A style value in a file outside `include` gets no CSS.

```ts
include: ['src/**/*.{ts,tsx}', 'content/**/*.mdx', '!src/**/*.test.tsx']
```

An `.mdx` file can hold token, font and global CSS definitions. A pattern that
starts with `!` excludes files. Sync never reads `node_modules`, `dist`,
`build`, `.git` or `.reference-ui`.

A pattern that matches no files is a warning, not an error.

## Composing systems

`extends` and `layers` both take the `baseSystem` export of another synced
package. A system can appear in only one of them, and neither can list your
own `name`. See [Share a design system](/share-a-design-system) for when to
use each.

### extends

**Type**: `BaseSystem[]`

**Default**: `[]`

Systems to build on. Their tokens, fonts and styles become part of yours, and
you can use their token names. Later entries win over earlier ones, and your
own definitions win over all of them.

### layers

**Type**: `BaseSystem[]`

**Default**: `[]`

Systems whose components you render without adopting their tokens. Their CSS
joins your stylesheet, and their components keep their own token values. Their
token names are not part of your types.

`layers` does not name or order cascade layers. Sync names one cascade layer
per system and orders them itself: `extends` systems, then `layers` systems,
then yours. See [Cascade layers](/cascade-layers).

## Output

### strict

**Type**: `('colors' | 'radii' | 'spacing')[]`

**Default**: `[]`

Token categories that accept only your tokens. A raw value such as
`color="#ff0000"` in a strict category is a type error. Strict colours still
accept tones and the keywords `white`, `black`, `inherit`, `currentColor` and
`transparent`. See [Tokens](/tokens#restrict-values-to-tokens).

### staticCss

**Type**: `Record<string, string[]>`

**Default**: `{}`

Style values to generate even though no source file uses them. Each key is a
property, optionally with a condition prefix. Each value lists token names,
or `'*'` for every token in the property's category.

```ts
staticCss: {
  color: ['*'],
  '_hover:bg': ['brand', 'surface'],
}
```

Sync fails if an entry names a token that does not exist. `'*'` on a property
with no token category is a warning. See
[CSS](/css#generate-values-ahead-of-time).

### normalizeCss

**Type**: `boolean`

**Default**: `true`

Adds the CSS reset to the stylesheet. See
[Global CSS](/global-css#the-reset).

### jsxElements

**Type**: `string[]`

**Default**: `[]`

Component names to treat as style prop hosts. You rarely need it: sync finds
every component that passes style props on to a primitive. A name here
applies only to your own components, never to one imported from a package.
See [Primitives](/primitives#your-own-components).

## Diagnostics

### logs

**Type**: `'compiler'[]`

**Default**: `[]`

Adds the compiler's own diagnostics to sync's output: values it could not
read, spreads it could not follow, and similar. They count toward the warning
total, and `ref sync --verbose` lists them.

## MCP

Sync ignores these options. The Reference MCP server reads them when it
builds its model. See [MCP configuration](/mcp-configuration).

### mcp

**Type**: `{ include?: string[]; exclude?: string[] }`

**Default**: none

Packages, components and files the server scans beside your own source, and
the ones it leaves out.

### useReferenceLibrary

**Type**: `boolean`

**Default**: `true`

Shows `@reference-ui/lib` components to your agent. `use_reference_library`
is the same flag.

### useReferenceIcons

**Type**: `boolean`

**Default**: `true`

Lets your agent search `@reference-ui/icons` with `list_icons`.
`use_reference_icons` is the same flag.
