# Global CSS

`globalCss()` writes rules for selectors you choose, such as `body`, `:root`
or a class of your own.

```ts
// src/theme/global.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  ':root': {
    '--spacing-root': '0.3rem',
  },
  body: {
    fontFamily: 'body',
    color: 'text',
    backgroundColor: 'surface',
  },
  'a:focus-visible': {
    outline: '2px solid {colors.brand}',
    outlineOffset: '2px',
  },
})
```

Each key is a selector, written as in CSS. Comma lists, `:has()`, `:is()` and
vendor pseudo-elements such as `::-webkit-scrollbar` pass through unchanged.
Call `globalCss()` in any file your `include` globs match, as often as you
like.

## Values

Values work as they do in [`css()`](/css#values): token names, `{colors.brand}`
references, rhythm units such as `4r`, and plain CSS. A key set to
`undefined` is dropped, which helps when you spread a shared object.

A custom property value prints as written. Only a value that is a whole
reference, such as `'{colors.brand}'`, becomes the token's `var()`. The
`--spacing-root` rule above rescales every rhythm unit. See
[Spacing](/spacing).

An unknown property name is dropped with a warning.

## Nesting and conditions

Inside a rule, `&` stands for the rule's selector. Named conditions such as
`_hover` work as they do on [style props](/style-props#conditions):

```ts
globalCss({
  '.field': {
    borderColor: 'line',
    '& > [data-slot="icon"]': { color: 'muted' },
    _hover: { borderColor: 'brand' },
    _disabled: { opacity: 0.5 },
    _placeholder: { color: 'muted' },
  },
})
```

## Media and container queries

`@media` and `@container` keys wrap the rule:

```ts
globalCss({
  '.sidebar': {
    display: 'none',
    '@media (min-width: 900px)': { display: 'block' },
  },
})
```

An at-rule key at the top level wraps every selector inside it:

```ts
globalCss({
  '@media print': {
    nav: { display: 'none' },
    body: { color: 'black' },
  },
})
```

## Breakpoints

Breakpoint keys, range keys such as `mdDown` or `smToLg`, and responsive
objects and arrays work as they do on style props. In global CSS they print
`@media` queries on the viewport, where style props and `css()` print
`@container` queries. See [Responsive](/responsive).

```ts
globalCss({
  body: {
    fontSize: { base: '14px', lg: '16px' },
    padding: ['2r', null, '4r'],
    mdDown: { lineHeight: 1.4 },
  },
})
```

The `lg` value prints `font-size: 16px` inside `@media (min-width: 1024px)`.

## Where global rules sit

Global rules live in the `global` layer, below recipes and utilities. A style
prop or `css()` class on the same element always wins, with no `!important`.
See [Cascade layers](/cascade-layers).

## The reset

When `normalizeCss` is on, which is the default, the stylesheet starts with a
small reset in the `reset` layer. It:

- sets `box-sizing: border-box` on every element and pseudo-element;
- removes the default margin from `body`, `h1` to `h4`, `p`, `figure`,
  `blockquote`, `dl` and `dd`;
- removes list markers from `ul` and `ol` with `role="list"`;
- gives `body` a `min-height` of `100vh`, a `line-height` of `1.5` and
  `text-rendering: optimizeSpeed`;
- sets `text-decoration-skip-ink: auto` on links without a class;
- makes `img` and `picture` block elements with `max-width: 100%`;
- makes `input`, `button`, `textarea` and `select` inherit the font;
- turns on smooth scrolling when focus is inside the page;
- cuts animations, transitions and smooth scrolling to almost nothing when
  the user prefers reduced motion.

The reduced-motion rules use `!important`, so they win over your own
animations. Turn the reset off in `ui.config.ts`:

```ts
// ui.config.ts
export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  normalizeCss: false,
})
```

## Reference

```ts
function globalCss(rules: GlobalCssConfig): void
```

`GlobalCssConfig` maps selectors, or top-level at-rules, to rules. A rule
holds CSS properties in camelCase, custom properties (`--name`), nested `&`
selectors, named conditions, breakpoint and range keys, responsive values,
and `@media` or `@container` keys.
