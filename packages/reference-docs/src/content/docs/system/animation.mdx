# Animation

`keyframes()` defines the steps of an animation. An `animations` token gives
it a name, a duration and an easing, so an element runs it with one prop.

## Define keyframes

Call `keyframes()` with one entry per animation. Each entry maps steps
(`from`, `to` or percentages) to declarations:

```ts
// src/theme/motion.ts
import { keyframes } from '@reference-ui/system'

keyframes({
  fadeIn: {
    from: { opacity: '0', transform: 'translateY(4px)' },
    to: { opacity: '1', transform: 'translateY(0)' },
  },
  pulse: {
    '0%, 100%': { opacity: '1' },
    '50%': { opacity: '0.5' },
  },
})
```

Each entry becomes one `@keyframes` rule in the `global`
[cascade layer](/cascade-layers). Token names, `{colors.brand}` references and
rhythm units work inside the steps.

## Name an animation

Add an `animations` token whose value is a CSS `animation` shorthand:

```ts
import { tokens } from '@reference-ui/system'

tokens({
  animations: {
    fade: {
      in: { value: 'fadeIn 0.2s ease-out both' },
    },
    pulse: {
      slow: { value: 'pulse 2s ease-in-out infinite' },
    },
  },
})
```

## Run an animation

`animation` looks up names in the `animations` category:

```tsx
import { Div, css } from '@reference-ui/react'

<Div animation="fade.in" />

const loading = css({ animation: 'pulse.slow' })
```

The class uses the token's variable, so changing the token's duration or
easing changes every element that uses it.

You can also write the shorthand directly: `animation="fadeIn 0.2s ease-out"`.

## Reduced motion

`_motionReduce` applies when the user asks for less motion, and
`_motionSafe` when they do not:

```tsx
<Div animation="pulse.slow" _motionReduce={{ animation: 'none' }} />
```

With the [reset](/global-css#the-reset) on, animations and transitions
already shrink to almost nothing for these users.

## Reference

```ts
function keyframes(config: KeyframesConfig): void

type KeyframesConfig = Record<
  string,                                         // animation name
  Record<string, Record<string, string | number>> // step: declarations
>
```

| Token category | Value | Used by |
| --- | --- | --- |
| `animations` | A CSS `animation` shorthand | `animation`, `animationName` |
| `durations` | A time, such as `150ms` | `transitionDuration` |
| `easings` | A timing function | `transitionTimingFunction` |
