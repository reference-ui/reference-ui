# Animation

`keyframes()` defines the steps of an animation. An `animations` token gives
it a duration and an easing, so an element runs it with one prop.

</Preview>

## Define keyframes

Call `keyframes()` with one entry per animation. Each entry maps steps
(`from`, `to` or percentages) to declarations:

```ts
// src/theme/motion.ts
import { keyframes } from '@reference-ui/system'

keyframes({
  rise: {
    from: { opacity: '0', transform: 'translateY(4px)' },
    to: { opacity: '1', transform: 'translateY(0)' },
  },
  breathe: {
    '0%, 100%': { opacity: '1' },
    '50%': { opacity: '0.5' },
  },
})
```

Each entry becomes one `@keyframes` rule in the `global`
[cascade layer](/cascade-layers). Values in the steps resolve tokens and
rhythm units the same way style props do.

## Name an animation

Add an `animations` token whose value is a CSS `animation` shorthand. Its
first word is the keyframes name:

```ts
import { tokens } from '@reference-ui/system'

tokens({
  animations: {
    rise: {
      quick: { value: 'rise 0.2s ease-out both' },
    },
    breathe: {
      slow: { value: 'breathe 2s ease-in-out infinite' },
    },
  },
})
```

Lib already ships [presets](/motion) such as `fadeIn.quick` and `spin.slow`.

## Run an animation

`animation` takes a token path from the `animations` category:

```tsx
import { Div, css } from '@reference-ui/react'

<Div animation="rise.quick" />

const loading = css({ animation: 'breathe.slow' })
```

The class uses the token's variable, so changing the token's duration or
easing changes every element that uses it.

`animation` also takes a raw shorthand, and `animationName` takes a keyframes
name for use with the longhands:

```tsx
<Div animation="rise 0.2s ease-out" />

<Div animationName="rise" animationDuration="0.6s" animationTimingFunction="ease-out" />
```

## Reduced motion

`_motionReduce` applies when the user asks for less motion, and
`_motionSafe` when they do not:

```tsx
<Div animation="breathe.slow" _motionReduce={{ animation: 'none' }} />
```

The [reset](/global-css#the-reset) is on by default. For these users it cuts
animation and transition durations to `0.01ms` and runs each animation once.

## Reference

```ts
function keyframes(config: KeyframesConfig): void

type KeyframesConfig = Record<
  string,                                         // keyframes name
  Record<string, Record<string, string | number>> // step: declarations
>
```

| Token category | Value | Used by |
| --- | --- | --- |
| `animations` | A CSS `animation` shorthand | `animation` |
| `durations` | A time, such as `150ms` | `transitionDuration` |
| `easings` | A timing function | `transitionTimingFunction` |
