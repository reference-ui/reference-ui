# Animation

`keyframes()` defines CSS `@keyframes` rules, and `animations` tokens pair them
with a duration and easing so you can apply them with a single prop.

</Preview>

## Define keyframes

Call `keyframes()` with one entry per animation. Each entry maps steps
(`from`, `to` or percentages) to declarations:

```ts
// src/theme/motion.ts
import { keyframes } from '@reference-ui/system'

keyframes({
  rise: {
    from: { opacity: '0', transform: 'translateY(4px)' },
    to: { opacity: '1', transform: 'translateY(0)' },
  },
  breathe: {
    '0%, 100%': { opacity: '1' },
    '50%': { opacity: '0.5' },
  },
})
```

Each entry compiles to a `@keyframes` rule in the `global`
[cascade layer](/cascade-layers). Step values resolve tokens and
rhythm units the same way style props do.

## Name an animation

Define an `animations` token using the CSS `animation` shorthand, starting with
the keyframes name:

```ts
import { tokens } from '@reference-ui/system'

tokens({
  animations: {
    rise: {
      quick: { value: 'rise 0.2s ease-out both' },
    },
    breathe: {
      slow: { value: 'breathe 2s ease-in-out infinite' },
    },
  },
})
```

`@reference-ui/lib` includes [presets](/motion) such as `fadeIn.quick` and `spin.slow`.

## Run an animation

`animation` takes a token path from the `animations` category:

```tsx
import { Div, css } from '@reference-ui/react'

<Div animation="rise.quick" />

const loading = css({ animation: 'breathe.slow' })
```

The generated class references the token's CSS variable, so updating the
token's duration or easing updates every element that uses it.

`animation` also accepts a raw CSS shorthand, and `animationName` accepts a
keyframes name when using individual animation properties:

```tsx
<Div animation="rise 0.2s ease-out" />

<Div animationName="rise" animationDuration="0.6s" animationTimingFunction="ease-out" />
```

## Reduced motion

`_motionReduce` applies when `prefers-reduced-motion: reduce` is active, and
`_motionSafe` applies when it is not:

```tsx
<Div animation="breathe.slow" _motionReduce={{ animation: 'none' }} />
```

The default [CSS reset](/global-css#the-reset) already reduces animation and
transition durations to `0.01ms` and limits animations to a single iteration
when reduced motion is enabled.

## Reference

```ts
function keyframes(config: KeyframesConfig): void

type KeyframesConfig = Record<
  string,                                         // keyframes name
  Record<string, Record<string, string | number>> // step: declarations
>
```

| Token category | Value | Used by |
| --- | --- | --- |
| `animations` | A CSS `animation` shorthand | `animation` |
| `durations` | A time, such as `150ms` | `transitionDuration` |
| `easings` | A timing function | `transitionTimingFunction` |
