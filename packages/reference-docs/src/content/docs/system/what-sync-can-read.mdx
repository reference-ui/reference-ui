# What sync can read

`ref sync` reads your source without running it and writes CSS for every style
value it finds. A value it can read gets CSS. A value known only at runtime
paints only when that value already has CSS.

## Where sync looks

In every file your `include` globs match, sync reads:

- style props on primitives, and on components that pass style props on;
- `css()` and [`recipe()`](/recipes) calls imported from `@reference-ui/react`
  or `@reference-ui/styled`.

It also reads `staticCss` in `ui.config.ts`.

### Which calls count

The import decides. Each of these is read:

```tsx
import { css } from '@reference-ui/react'
import { css as style } from '@reference-ui/react'
import * as ui from '@reference-ui/react' // ui.css({ … })
import { css } from './styles' // your file that re-exports css
```

A local function or parameter named `css`, or a `css` from another package,
is not read. `recipe()` follows the same rule.

## Values

Sync can read:

- literals in a `css()` call, a `css` prop or a style prop;
- `const` values, objects, arrays and enums, in the same file or imported, and
  their members, such as `space.lg` or `sizes['lg']`;
- both branches of a ternary, and both sides of `&&`, `||` and `??`;
- template strings whose parts it can read, such as `` `${gap}px` ``;
- spreads of objects it can read.

```tsx
import { css } from '@reference-ui/react'
import { focusRing } from './styles'

const gap = 4

const field = (active: boolean) =>
  css({
    ...focusRing,
    padding: `${gap}px`,
    color: active ? 'brand' : 'text',
  })
```

Sync cannot read the result of a function call, a prop or state value, a
variable reassigned before the style reads it, or a computed key such as
`[key]: '10px'`. That value gets CSS only when the same property and value
already have CSS, from another call sync reads or from `staticCss`.

Sync warns `ATM-W-MISSING-STYLE-PLAN` for a style it can prove gets no class.
Set `logs: ['compiler']` to list every value it could not read. In
development, the browser console warns `css(): no compiled class for` the
property and value, with where it was called. See
[Diagnostics](/diagnostics#compiler-diagnostics).

## Generate values with `staticCss`

`staticCss` lists values to generate with no call site. A value chosen at
runtime then paints:

```ts
// ui.config.ts
export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  staticCss: {
    color: ['brand', 'danger'],
  },
})
```

```tsx
import { Span } from '@reference-ui/react'

function Badge({ tone }: { tone: 'brand' | 'danger' }) {
  return <Span color={tone}>New</Span>
}
```

See [Config](/config#staticcss) for keys, conditions and `'*'`.

## Style props on components

A component that passes style props on to a primitive takes style props too.
Sync follows them through spreads, other components, higher-order components,
re-exports and barrel files. Class components are not followed: sync warns
`STT-W-CLASS-COMPONENT`. List any other component sync does not follow under
[`jsxElements`](/config#jsxelements). See
[Primitives](/primitives#your-own-components).

Components from a package built on Reference UI, such as
`@reference-ui/lib`, take style props when that package's system is in
`extends` or `layers`. Otherwise sync warns `ATM-W-EXTERNAL-UNBACKED` and
names the package. A workspace package that your `include` globs reach counts
as your own code, unless it publishes a system of its own.

## Keep styles static

Write every option where sync can read it, and choose between them at runtime:

- Write each option as its own `css()` call and pick between the class names.
  See [`css()`](/css#values-chosen-at-runtime).
- Use a recipe variant. Every variant value gets a class. See
  [Recipes](/recipes#values-picked-at-runtime).
- List the values under `staticCss`.
- For a value from runtime data, such as a colour a user picks, set a custom
  property in `style` and read it with `var()` in `css()`. See
  [`css()`](/css#values-chosen-at-runtime).

If styles are still missing, see
[Troubleshooting](/troubleshooting#one-property-is-missing).
