# Types

`ref sync` writes TypeScript types for your system into `.reference-ui/`.
Use them to type shared styles, wrapper components and recipe props.

The token unions come from your config and fragments, so they change when
your tokens change. The shapes stay the same.

| Import from | Types |
| --- | --- |
| `@reference-ui/react` | Styles, tokens, primitive props and recipes. Generated by sync. |
| `@reference-ui/core` | Config and fragment inputs. Ships with the package. |

## Styles

### `SystemStyleObject`

A style object: style props, conditions, breakpoints and nested `&`
selectors. It is what `css()` and the `css` prop take.

```ts
import { css, type SystemStyleObject } from '@reference-ui/react'

const focusRing: SystemStyleObject = {
  outline: '2px solid',
  outlineColor: 'brand',
  _hover: { outlineColor: 'ink' },
  md: { outlineOffset: '2px' },
  '& > svg': { color: 'brand' },
}

const className = css(focusRing)
```

### `CssStyles`

One argument to `css()`: a `SystemStyleObject`, or `undefined`, `null` or
`false`, which `css()` skips.

```ts
type CssStyles = SystemStyleObject | undefined | null | false

function css(...styles: Array<CssStyles | CssStyles[]>): string
```

### `StyleProps`

The style props a primitive accepts, without its HTML props. A prop with
tokens lists your token names and still takes any CSS value, unless its
category is in [`strict`](/config#strict).

```ts
import type { StyleProps } from '@reference-ui/react'

type IconProps = {
  color?: StyleProps['color']
  size?: StyleProps['width']
}
```

### `StylePropValue<T>`

The value shape of one style prop: a plain value, `null`, `false`,
`undefined`, an array, or an object keyed by conditions and breakpoints.

```ts
import type { StylePropValue } from '@reference-ui/react'

type Gap = StylePropValue<'2r' | '4r'>
// '2r' | '4r' | { base?: ..., md?: ..., _hover?: ... } | ...
```

### `StyleConditionKey` and `BreakpointKey`

`StyleConditionKey` is the union of condition keys, such as `_hover` and
`_dark`. `BreakpointKey` is the union of breakpoint keys, such as `base`,
`md` and `mdDown`. See [Responsive](/responsive).

## Tokens

`Tokens` maps each category to its union of token names. Each category also
has its own type.

| Type | Holds |
| --- | --- |
| `ColorToken` | Color token names, such as `'brand'` or `'blue.500'` |
| `SpacingToken` | Spacing token names |
| `RadiusToken` | Radius token names |
| `FontWeightToken` | Weight tokens per font, such as `'sans.bold'` |
| `AnimationToken` | Animation token names |

A category with no tokens is `never`.

```ts
import type { ColorToken } from '@reference-ui/react'

const accents: ColorToken[] = ['brand', 'blue.500']
```

## Primitive props

Each primitive exports its props type: `DivProps`, `ButtonProps`, and so on.
It holds the element's HTML props, the style props and the `css` prop.

```tsx
import { Div, type DivProps } from '@reference-ui/react'

type PanelProps = DivProps & { title: string }

function Panel({ title, children, ...props }: PanelProps) {
  return (
    <Div padding="4r" {...props}>
      <h2>{title}</h2>
      {children}
    </Div>
  )
}
```

| Type | What it is |
| --- | --- |
| `PrimitiveProps<T>` | The props type by tag name: `PrimitiveProps<'div'>` equals `DivProps`. |
| `PrimitiveTag` | Every tag a primitive covers. |
| `PrimitiveElement<T>` | The DOM element type a primitive renders for tag `T`. |
| `PrimitiveCssProp` | The type of the `css` prop. |

## Recipes

### `RecipeVariantProps<T>`

The variant props of a recipe, each one optional. Pass `typeof` your recipe.

```tsx
import { Div, recipe, type DivProps, type RecipeVariantProps } from '@reference-ui/react'

const card = recipe({
  className: 'card',
  base: { padding: '4r' },
  variants: {
    tone: {
      quiet: { bg: 'transparent' },
      loud: { bg: 'brand' },
    },
  },
})

type CardProps = DivProps & RecipeVariantProps<typeof card>
// tone?: 'quiet' | 'loud'

function Card({ tone, className, ...props }: CardProps) {
  return <Div className={`${card({ tone })} ${className ?? ''}`} {...props} />
}
```

### `RecipeConfig` and `RecipeRuntimeFn`

`RecipeConfig` is the object `recipe()` takes: `className`, `base`,
`variants`, `defaultVariants` and `compoundVariants`. `RecipeRuntimeFn` is
the function it returns, with `raw`, `variantKeys`, `variantMap` and
`splitVariantProps`. See [Recipes](/recipes).

## Config and fragments

These come from `@reference-ui/core`. Import them with `import type`.

| Type | What it types |
| --- | --- |
| `ReferenceUIConfig` | The object `defineConfig()` takes. See [Config](/config). |
| `BaseSystem` | A system you list in `extends` or `layers`. |
| `ReferenceTokenConfig` | A token tree for `tokens()`. |
| `ReferenceTokenLeaf` | One token: `value`, `light`, `dark` and `description`. |
| `KeyframesConfig` | The object `keyframes()` takes. |
| `FontOptions` | The options `font()` takes. |
| `FontFaceRule` | One `@font-face` entry in `fontFace`. |
| `GlobalCssConfig` | The object `globalCss()` takes. |

```ts
// src/theme/colors.ts
import type { ReferenceTokenConfig } from '@reference-ui/core'
import { tokens } from '@reference-ui/system'

const colors: ReferenceTokenConfig = {
  colors: {
    brand: { value: '#0055ff', dark: '#5c8dff' },
  },
}

tokens(colors)
```
