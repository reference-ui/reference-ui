# Typography

Lib ships three font families, five named weights for each, and a type scale
for its text primitives. Body text is `sans` at 16px.

Pick a family with the `font` prop and a weight with the `weight` prop:

```tsx
import { P } from '@reference-ui/react'

<P font="serif" weight="semibold">Set in Literata at its semibold weight.</P>
```

## Font families

| Name | Typeface | Stack | Letter spacing |
| --- | --- | --- | --- |
| `sans` | Inter | `"Inter", ui-sans-serif, sans-serif` | `-0.01em` |
| `serif` | Literata | `"Literata", ui-serif, serif` | `normal` |
| `mono` | JetBrains Mono | `"JetBrains Mono", ui-monospace, monospace` | `-0.04em` |

<FontFamilies />

Each family loads one variable `woff2` file from Google Fonts with
`font-display: swap`. Text shows in the fallback font until the file arrives.

`font="mono"` sets the family, its default weight and its letter spacing.
`fontFamily="mono"` sets only the stack. See [Fonts](/fonts) for the
difference.

## Weights

Every family has the same five weight names. Each name maps to a different
number per family, so the families look equally heavy side by side.

| Weight | `sans` | `serif` | `mono` |
| --- | --- | --- | --- |
| `thin` | 200 | 200 | 100 |
| `light` | 285 | 300 | 300 |
| `normal` | 385 | 373 | 393 |
| `semibold` | 550 | 550 | 590 |
| `bold` | 650 | 633 | 700 |

## Type scale

Lib's text primitives use these sizes. Sizes are in `r`, the
[spacing unit](/spacing): `1r` is `0.25rem`, 4px at the browser's default font
size.

| Element | Size | Line height | Weight |
| --- | --- | --- | --- |
| `H1` | `9r` (36px) | `15r` (60px) | `semibold` |
| `H2` | `6r` (24px) | `10r` (40px) | `semibold` |
| `H3` | `5r` (20px) | `10r` (40px) | `semibold` |
| `H4` | `4.5r` (18px) | `8r` (32px) | `semibold` |
| `H5` | `4.5r` (18px) | `8r` (32px) | `semibold` |
| `H6` | `3.5r` (14px), uppercase | `8r` (32px) | `semibold` |
| `P` | `4r` (16px) | `1.6` | inherited |
| `Blockquote` | `4.5r` (18px), italic | `1.6` | inherited |
| `Small` | `small` | `1.4` | inherited |

<TypeScale />

All of them use `sans` and the `design.text.base` colour, except `Small`,
`Blockquote` and `Cite`, which use `design.text.light`. Override any value with
a style prop:

```tsx
<H2 fontSize="8r">A larger section heading</H2>
```

## Inline text and code

`Code`, `Kbd`, `Samp` and `Pre` use `mono`. `Code` is `0.9em` and `Kbd` is
`0.85em` of the surrounding text, so they fit a line at any size.

<InlineSamples />

```tsx
import { Code, Kbd, P } from '@reference-ui/react'

<P>
  Declare it with <Code>const</Code>, or press <Kbd>Cmd</Kbd> + <Kbd>S</Kbd> to save.
</P>
```
