# Radius

`@reference-ui/lib` provides four border radius tokens:

<RadiusScale />

| Token | Value |
| --- | --- |
| `sm` | `0.27rem` |
| `md` | `0.4rem` |
| `lg` | `0.6rem` |
| `full` | `9999px` |

## Usage

Pass a radius token name to `borderRadius` or any corner-specific radius prop:

```tsx
import { Div, css } from '@reference-ui/react'

<Div borderRadius="md" padding="4r" bg="design.bg.muted" />

const avatar = css({ borderRadius: 'full' })
```

To override a value or define additional radius tokens, add a `radii` group in
`tokens()` (see [Theming](/theming)).
