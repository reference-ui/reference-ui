# Introduction

Foundations are the default design tokens and global styles provided by
`@reference-ui/lib`: color, typography, border radius, motion, and control
sizing. Library components use these tokens internally, and your own styles can
reference them by name.

## Included foundations

`@reference-ui/core` provides the token and styling APIs (`tokens()`, `font()`,
`keyframes()`, and `globalCss()`) without a built-in theme. `@reference-ui/lib`
uses those APIs to define the default design system:

| Foundation | Tokens | Page |
| --- | --- | --- |
| Colour | A 19-family palette (`blue.500`), four tones (`blue.500/medium`), semantic tokens with light and dark values (`design.text.base`) | [Color](/color) |
| Typography | `sans`, `serif` and `mono`, each with five named weights | [Typography](/typography) |
| Radius | `sm`, `md`, `lg` and `full` | [Radius](/radius) |
| Motion | Animation presets such as `fadeIn.quick`, and the keyframes behind them | [Motion](/motion) |

`@reference-ui/lib` also sets the base rhythm unit (`1r` = `0.25rem`, or 16px at
`4r`; see [Spacing](/spacing)). It does not define default shadow, z-index, or
breakpoint tokens; you can define your own with `tokens()` (see
[Theming](/theming)).

## Using library tokens

The configuration generated by `ref init` extends `@reference-ui/lib/baseSystem`
by default:

```ts
// ui.config.ts
import { defineConfig } from '@reference-ui/core'
import { baseSystem } from '@reference-ui/lib/baseSystem'

export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  extends: [baseSystem],
})
```

After running `ref sync`, all style props accept and type-check `@reference-ui/lib`'s
token names:

```tsx
import { Div, P } from '@reference-ui/react'

<Div bg="design.background" borderRadius="md" padding="4r">
  <P font="serif" color="design.text.light">Lib's tokens, by name.</P>
</Div>
```

## Overriding tokens

Tokens defined in your project merge on top of `@reference-ui/lib`'s defaults.
Defining a token at the same path overrides it across both your own styles and
library components. See [Theming](/theming).
