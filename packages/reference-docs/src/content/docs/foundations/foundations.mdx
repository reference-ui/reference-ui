# Introduction

Foundations are the design values `@reference-ui/lib` ships: colour, type,
radius and motion. Lib's components are built from them, and your own styles
can use them by name.

## What lib ships

`@reference-ui/core` provides the APIs, such as `tokens()` and `font()`, and
ships no values of its own. Lib calls those APIs to define one complete look.

| Foundation | Tokens | Page |
| --- | --- | --- |
| Colour | A 19-family palette (`blue.500`), four tones (`blue.500/medium`), semantic tokens with light and dark values (`design.text.base`) | [Color](/color) |
| Typography | `sans`, `serif` and `mono`, each with five named weights | [Typography](/typography) |
| Radius | `sm`, `md`, `lg` and `full` | [Radius](/radius) |
| Motion | Animation presets such as `fadeIn.quick`, and the keyframes behind them | [Motion](/motion) |

Lib also sets the spacing unit: `1r` is `0.25rem`, so `4r` is 16px at the
browser's default font size. See [Spacing](/spacing).

Lib defines no shadow, z-index or breakpoint tokens. Add your own with
`tokens()`, as [Theming](/theming) shows.

## Use lib's tokens

The config that `ref init` writes already extends lib's `baseSystem`:

```ts
// ui.config.ts
import { defineConfig } from '@reference-ui/core'
import { baseSystem } from '@reference-ui/lib/baseSystem'

export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  extends: [baseSystem],
})
```

After `ref sync`, every style prop accepts lib's token names and type-checks
them. Write a token's name as the value:

```tsx
import { Div, P } from '@reference-ui/react'

<Div bg="design.background" borderRadius="md" padding="4r">
  <P font="serif" color="design.text.light">Lib's tokens, by name.</P>
</Div>
```

## Override a value

Your tokens extend lib's. Define a token at the same path and yours wins, in
your styles and in lib's components. See [Theming](/theming).
