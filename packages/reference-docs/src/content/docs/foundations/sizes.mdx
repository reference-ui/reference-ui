# Sizes

`@reference-ui/lib` exports a shared control height and three icon sizes so
buttons, inputs, and menu triggers align consistently when placed side by side.

Sizes are expressed in `r`, the [rhythm unit](/spacing) (`1r` = `--spacing-root`,
which defaults to `0.25rem` or 4px). `8.5r` compiles to
`calc(8.5 * var(--spacing-root))` (34px at the default root size).

## Import

```ts
import {
  controlHeight,
  controlHeightPx,
  controlSize,
  defaultIconSize,
  iconSizes,
} from '@reference-ui/lib'
```

## Control height

| Export | Value | Computed |
| --- | --- | --- |
| `controlHeight` | `'8.5r'` | 34px |
| `controlHeightPx` | `'34px'` | 34px |
| `controlSize` | `{ height: '8.5r', paddingBlock: '0.75r' }` | 34px tall, 3px of padding above and below |

These elements are `controlHeight` tall:

- `Button`
- `Input` (text types) and `Select`
- [Field](/field)
- [Menu](/menu) triggers and items, as a minimum height
- [Listbox](/listbox) options, as a minimum height

To match them, give your own control the same height:

```tsx
import { Div } from '@reference-ui/react'

<Div height="8.5r" paddingBlock="0.75r" />
```

Use `controlHeightPx` when an inline `style` or third-party prop requires a
pixel string:

```tsx
import { controlHeightPx } from '@reference-ui/lib'

<div style={{ minHeight: controlHeightPx }} />
```

## Icon sizes

| Key | Value | Computed |
| --- | --- | --- |
| `small`, `sm` | `'4r'` | 16px |
| `base`, `md` | `'5r'` | 20px |
| `large`, `lg` | `'6r'` | 24px |

`iconSizes` includes both the short (`sm`, `md`, `lg`) and full (`small`,
`base`, `large`) keys, matching the `size` prop on [icons](/icons).
`defaultIconSize` is `'5r'` (20px, `md`), which fits inside a `controlHeight`
control.
