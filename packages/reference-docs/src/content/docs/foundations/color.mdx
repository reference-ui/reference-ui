# Color

`@reference-ui/lib` provides a color palette, four opacity tones, and semantic
tokens for light and dark mode. All three work in any color prop, such as
`bg="blue.500"`, `bg="blue.500/medium"`, or `color="design.text.base"`.

## Palette

The palette contains 19 color families, each with 11 shades from `50`
(lightest) through `950` (darkest) in `oklch()`. Palette shades have fixed
values across light and dark mode.

```tsx
import { Div, P } from '@reference-ui/react'

<Div bg="blue.100" borderColor="blue.300">
  <P color="blue.900">A light blue surface with a deep blue label.</P>
</Div>
```

### Neutrals

`slate` and `gray` provide neutral scales. Most default surfaces, borders, and
text tokens use `gray`.

### Hues

`red`, `orange`, `amber`, `yellow`, `lime`, `green`, `emerald`, `teal`,
`cyan`, `sky`, `blue`, `indigo`, `violet`, `purple`, `magenta`, `pink` and
`rose`.

## Tones

A tone applies a named opacity preset to a palette shade using `shade/tone`
syntax, allowing the color to blend with the underlying surface in both light
and dark mode.

<ShadesAndTones />

```tsx
import { Div } from '@reference-ui/react'

// A shade: the solid step.
<Div bg="blue.500" />

// A tone: the same shade at medium strength.
<Div bg="blue.500/medium" />
```

Each tone defines two opacity levels: a lower surface opacity for backgrounds
and fills, and a higher line opacity so borders and text remain legible.

| Tone | Surface | Line |
| --- | --- | --- |
| `ghost` | 4% | 22% |
| `medium` | 10% | 34% |
| `firm` | 14% | 46% |
| `strong` | 18% | 58% |

<IntensityGrid />

The CSS property determines which opacity level is used. `border*` and
`outline*` props, `color`, text decoration, strokes, and shadows use the line
opacity; all other color props, including `bg` and `fill`, use the surface
opacity.

<RoleSpecimens />

Use `medium` as a default, `firm` or `strong` for stronger contrast, and `ghost`
for subtle fills. For body text, use a solid shade such as `blue.700` rather
than a translucent tone.

## Semantic tokens

Semantic tokens map UI roles such as backgrounds, text, borders, and accents to
palette shades with dedicated light and dark mode values. Both library
components and your own styles can reference them.

| Token | Light | Dark |
| --- | --- | --- |
| `design.background` | `oklch(100% 0 0)` | `gray.950` |
| `design.foreground` | `gray.950` | `gray.50` |
| `design.primary.background` | `gray.950` | `gray.100` |
| `design.primary.foreground` | `gray.50` | `gray.950` |
| `design.primary.hover.background` | `gray.900` | `gray.50` |
| `design.accent.foreground` | `blue.600` | `blue.300` |
| `design.accent.background` | `gray.100` | `gray.950` |
| `design.accent.hover` | `blue.800` | `blue.300` |
| `design.accent.border` | `gray.300` | `blue.950` |
| `design.text.base` | `gray.950` | `gray.50` |
| `design.text.light` | `gray.700` | `gray.300` |
| `design.text.lighter` | `gray.600` | `gray.400` |
| `design.mark.background` | `blue.200` | `blue.950` |
| `design.mark.foreground` | `blue.950` | `blue.200` |
| `design.positive.text` | `green.600` | `green.400` |
| `design.bg.muted` | `gray.100` | `gray.900` |

```tsx
import { Div, P } from '@reference-ui/react'

<Div bg="design.background" color="design.text.base">
  <P color="design.text.light">Secondary copy that follows the colour mode.</P>
</Div>
```

`@reference-ui/lib` also defines component-scoped `ui.*` tokens (such as
`ui.link.default`, `ui.button.hover`, and `ui.focus.ring`) for styling built-in
primitives and components, as well as legacy `text.*` aliases (`text.primary`,
`text.secondary`). Prefer `design.*` and `design.text.*` in application styles.

## Light and dark mode

Light mode is active by default, and dark mode applies inside any element with
`data-color-mode="dark"`. Token values are controlled by `data-color-mode`
rather than a `prefers-color-scheme` media query, so your application controls
when dark mode is active.

Pass the `colorMode` prop to any primitive to scope a color mode to that
subtree:

<ColorModeDemo />

```tsx
import { Div, P } from '@reference-ui/react'

<Div colorMode="dark" bg="design.background" color="design.text.base">
  <P color="design.text.light">Copy that resolves to its dark values.</P>
</Div>
```

To switch the whole page, set `colorMode` on your root primitive.
[Light and dark](/light-and-dark) covers following the system setting and adding a
toggle, and [Server-side rendering](/ssr) covers setting the mode from the request.

Only semantic tokens switch values between light and dark mode; palette shades
remain fixed, and tones blend with the background behind them.
