# Style HTML you don't control

Rendered Markdown, CMS content, and `dangerouslySetInnerHTML` output produce
raw HTML elements without style props or generated classes. You can style them
by scoping `globalCss()` rules under a wrapper element.

<Step n={1}>Wrap the content</Step>

Give the element that holds the content a class or a data attribute:

```tsx
import { Article } from '@reference-ui/react'

export function Post({ html }: { html: string }) {
  return (
    <Article
      className="prose"
      maxWidth="70ch"
      dangerouslySetInnerHTML={{ __html: html }}
    />
  )
}
```

The inner elements do not need class names. You can also target a data attribute
such as `'[data-prose]'` instead of `'.prose'`.

<Step n={2}>Scope rules under the wrapper</Step>

Write one rule for the wrapper and nest the elements inside it with `&`:

```ts
// src/theme/prose.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  '.prose': {
    color: 'design.text.base',
    fontSize: '4r',
    lineHeight: 1.6,
    '& > *': { marginBlock: 0 },
    '& > * + *': { marginTop: '4r' },
    '& h2': { fontSize: '6r', fontWeight: 600, marginTop: '10r' },
    '& h3': { fontSize: '5r', fontWeight: 600, marginTop: '8r' },
    '& ul, & ol': { paddingLeft: '5r' },
    '& a': {
      color: 'design.accent.foreground',
      _hover: { color: 'design.accent.hover' },
    },
    '& blockquote': {
      color: 'design.text.light',
      borderLeft: '4px solid {colors.design.accent.border}',
      paddingLeft: '4r',
    },
  },
})
```

`'& h2'` compiles to `.prose h2`, scoping the rule to elements inside the
wrapper. Property values support the same syntax as `css()`: token names, `{…}`
token references in compound values, and rhythm units such as `4r`. The
[semantic tokens](/color#semantic-tokens) used above automatically adapt to
light and dark mode.

<Step n={3}>Adjust scale and density</Step>

Because every `r` value is a multiple of `--spacing-root`, overriding
`--spacing-root` on the wrapper proportionally scales all rhythm-based font
sizes and spacing inside it:

```ts
globalCss({
  '.prose': { '--spacing-root': '0.28rem' },
})
```

## Respond to the container

Use a nested `@container` rule to adjust styles based on the nearest container's
width:

```ts
globalCss({
  '.prose': {
    '& h2': {
      fontSize: '5r',
      '@container (min-width: 768px)': { fontSize: '6r' },
    },
  },
})
```

Breakpoint keys such as `md` also work in `globalCss()`, where they compile to
viewport `@media` queries. See [Global CSS](/global-css#breakpoints).

## Cascade layer precedence

`globalCss()` rules are placed in the `global` layer, below recipes and
utilities. Style props on the wrapper (such as `maxWidth="70ch"` above) take
precedence over `globalCss()` rules without `!important`. See
[Cascade layers](/cascade-layers).

Because `@reference-ui/lib`'s [element styles](/element-styles) target `ref-*`
primitive classes rather than bare HTML tags, injected HTML only inherits the
[CSS reset](/global-css#the-reset) and your scoped rules (with the exception of
inline `code`, which targets all `<code>` elements).
