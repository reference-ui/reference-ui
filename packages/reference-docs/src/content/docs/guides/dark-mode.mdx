# Dark mode

Tokens with a dark value switch when their element is in dark mode. Your app
decides the mode and sets it on the root element.

<Step n={1}>Give your tokens a dark value</Step>

`value` is the light value, and `dark` replaces it in dark mode.

```ts
// src/theme/tokens.ts
import { tokens } from '@reference-ui/system'

tokens({
  colors: {
    surface: { value: '#ffffff', dark: '#0b0b0f' },
    ink: { value: '#111827', dark: '#f3f4f6' },
  },
})
```

The library's semantic tokens, such as `design.background` and
`design.text.base`, already have both values. See [Color](/color).

<Step n={2}>Set the mode on your root</Step>

`colorMode` on any primitive sets the mode for it and everything inside it,
library components included.

```tsx
<Div colorMode="dark" bg="surface" color="ink">
  <App />
</Div>
```

<Step n={3}>Add a toggle</Step>

Keep the mode in state and pass it to `colorMode`. This root starts from the
system setting and remembers the user's choice:

```tsx
// src/Root.tsx
import { useEffect, useState, type ReactNode } from 'react'
import { Button, Div } from '@reference-ui/react'

type Mode = 'light' | 'dark'

function initialMode(): Mode {
  if (typeof window === 'undefined') return 'light'
  const stored = localStorage.getItem('color-mode')
  if (stored === 'light' || stored === 'dark') return stored
  return matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
}

export function Root({ children }: { children: ReactNode }) {
  const [mode, setMode] = useState<Mode>(initialMode)

  useEffect(() => {
    localStorage.setItem('color-mode', mode)
    document.documentElement.style.colorScheme = mode
  }, [mode])

  return (
    <Div colorMode={mode} bg="surface" color="ink" minHeight="100dvh">
      <Button onClick={() => setMode(mode === 'dark' ? 'light' : 'dark')}>
        {mode === 'dark' ? 'Light mode' : 'Dark mode'}
      </Button>
      {children}
    </Div>
  )
}
```

Setting `color-scheme` on `<html>` switches the browser's own form controls
and scrollbars to match.

`initialMode` can't read storage on the server, so a server render starts in
light mode and won't match the browser. If you render on the server, save the
choice in a cookie instead and pass the mode read from the request in as the
starting state. See [Server-side rendering](/ssr).

## Style one property per mode

`_dark` applies styles when an ancestor is in dark mode, so it doesn't apply
on the element that sets `colorMode`. Use it for the odd value that has no
token:

```tsx
<Div boxShadow="raised" _dark={{ boxShadow: 'none' }} />
```
