# Build a component

Reference UI compiles your styles at build time, and you can still build your
own components the way you would with CSS-in-JS.

The compiler follows your component's props down to the primitives it
renders. When a style prop reaches a primitive, your component takes style
props too, so `<Card padding="6r">` compiles just like `<Div padding="6r">`.
A component that renders a plain `<div>` gets no style props.

<Step n={1}>Define its style</Step>

`css()` takes a style object and returns a class name.

```tsx
// src/components/Card.tsx
import { css } from '@reference-ui/react'

const card = css({
  padding: '4r',
  borderRadius: 'md',
  bg: 'violet.500/firm',
})
```

<Step n={2}>Build the component</Step>

Give the class to a primitive and pass every other prop through. Join the
caller's `className` with yours, so both reach the element:

```tsx
// src/components/Card.tsx
import { Div, type DivProps } from '@reference-ui/react'

export function Card({ className, ...props }: DivProps) {
  return <Div className={`${card} ${className ?? ''}`} {...props} />
}
```

<Step n={3}>Add variants</Step>

A recipe adds named variants to your component. Swap `css()` for
`recipe()`: it takes a `className`, base styles and variants, and returns a
function that gives you the class names for the variants you pick.

```tsx
// src/components/Card.tsx
import { recipe } from '@reference-ui/react'

const card = recipe({
  className: 'card',
  base: {
    padding: '4r',
    borderRadius: 'md',
  },
  variants: {
    tone: {
      violet: { bg: 'violet.500/firm', color: 'violet.700', _dark: { color: 'violet.200' } },
      blue: { bg: 'blue.500/firm', color: 'blue.700', _dark: { color: 'blue.200' } },
      green: { bg: 'green.500/firm', color: 'green.700', _dark: { color: 'green.200' } },
    },
  },
  defaultVariants: { tone: 'violet' },
})
```

Call the recipe with the variant props to get the class names.
`RecipeVariantProps` infers their types, so `tone` is typed to
`'violet' | 'blue' | 'green'`:

```tsx
// src/components/Card.tsx
import { Div, type DivProps, type RecipeVariantProps } from '@reference-ui/react'

type CardProps = DivProps & RecipeVariantProps<typeof card>

export function Card({ tone, className, ...props }: CardProps) {
  return <Div className={`${card({ tone })} ${className ?? ''}`} {...props} />
}
```

See [Recipes](/recipes) for compound and responsive variants.

<Step n={4}>Usage</Step>

Import your card like any other component. Reference UI knows that `Card`
renders one of its primitives, and that `Card` passes its props on to it. So
your card takes its own `tone`, and every one of the
**[style props](/style-props)** too:

```tsx
import { Card } from './components/Card'

<Card tone="violet">Violet</Card>
<Card tone="blue">Blue</Card>
<Card tone="green" padding="6r">Green, with more padding</Card>
```
