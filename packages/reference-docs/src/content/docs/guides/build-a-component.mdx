# Build a component

Reference UI compiles your styles at build time, and you can still build your
own components the way you would with CSS-in-JS.

The compiler follows your component's props down to the primitives it
renders. When a style prop reaches a primitive, your component takes style
props too, so `<Card padding="6r">` compiles just like `<Div padding="6r">`.

<Step n={1}>Define its style</Step>

`css()` takes a style object and returns a class name.

```tsx
// src/components/Card.tsx
import { css } from '@reference-ui/react'

const card = css({
  padding: '4r',
  borderRadius: 'md',
  bg: 'slate.500/strong',
})
```

<Step n={2}>Build the component</Step>

Give the class to a primitive and pass every other prop through:

```tsx
// src/components/Card.tsx
import { Div, type DivProps } from '@reference-ui/react'

export function Card(props: DivProps) {
  return <Div {...props} className={card} />
}
```

<Step n={3}>Add variants</Step>

A recipe defines different variants for your component. Swap `css()` for
`recipe()`: it takes base styles and named variants, and returns a function
that gives you the class names for the variants you pick.

```tsx
// src/components/Card.tsx
import { recipe } from '@reference-ui/react'

const card = recipe({
  className: 'card',
  base: {
    padding: '4r',
    borderRadius: 'md',
  },
  variants: {
    tone: {
      slate: { bg: 'slate.500/strong' },
      violet: { bg: 'violet.500/strong' },
      rose: { bg: 'rose.500/strong' },
    },
  },
  defaultVariants: { tone: 'slate' },
})
```

Call the recipe with the variant props to get the class names.
`RecipeVariantProps` infers their types, so `tone` is typed to
`'slate' | 'violet' | 'rose'`:

```tsx
// src/components/Card.tsx
import { Div, type DivProps, type RecipeVariantProps } from '@reference-ui/react'

type CardProps = DivProps & RecipeVariantProps<typeof card>

export function Card({ tone, ...props }: CardProps) {
  return <Div {...props} className={card({ tone })} />
}
```

See [Recipes](/recipes) for the full reference.

## Usage

```tsx
<Card>Slate</Card>
<Card tone="violet">Violet</Card>
<Card tone="rose">Rose</Card>
<Card tone="violet" padding="6r">More padding</Card>
```

</Preview>

Style props override the recipe, because recipe rules sit in an earlier
cascade layer. Here `padding="6r"` replaces the recipe's `4r`.
