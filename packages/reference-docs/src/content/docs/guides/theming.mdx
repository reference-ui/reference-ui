# Theming

Reference UI gives you a set of tools for theming. What you define reaches every style prop, `css()` call
and library component.

## Design tokens

Tokens name your design values, grouped by category.

```ts
// src/theme/tokens.ts
import { tokens } from '@reference-ui/system'

tokens({
  colors: {
    surface: { value: '#ffffff' },
  },
  radii: {
    card: { value: '0.5rem' },
  },
  shadows: {
    raised: { value: '0 1px 3px rgb(0 0 0 / 0.2)' },
  },
})
```

### Usage

#### Primitive

```tsx
<Div bg="surface" borderRadius="card" boxShadow="raised" />
```

#### css()

```tsx
const card = css({
  bg: 'surface',
  borderRadius: 'card',
  boxShadow: 'raised',
})
```

## Fonts

`font()` defines a family: its stack, files and weights.

```ts
// src/theme/fonts.ts
import { font } from '@reference-ui/system'

font('display', {
  value: '"Playfair Display", Georgia, serif',
  fontFace: {
    src: 'url(/fonts/playfair-display.woff2) format("woff2")',
    fontWeight: '400 900',
  },
  weights: { normal: '420', bold: '700' },
})
```

### Usage

`font` applies the family; `weight` picks from its weights.

#### Primitive

```tsx
<H1 font="display" weight="bold">Set in Playfair Display</H1>
```

#### css()

```tsx
const heading = css({
  font: 'display',
  weight: 'bold',
})
```

## Animations

`keyframes()` defines the motion; an `animations` token names it with a
duration and easing.

```ts
// src/theme/motion.ts
import { keyframes, tokens } from '@reference-ui/system'

keyframes({
  fadeIn: {
    from: { opacity: '0' },
    to: { opacity: '1' },
  },
})

tokens({
  animations: {
    fade: { in: { value: 'fadeIn 0.2s ease-out both' } },
  },
})
```

### Usage

#### Primitive

```tsx
<Div animation="fade.in" />
```

#### css()

```tsx
const panel = css({ animation: 'fade.in' })
```

## Global CSS

`globalCss()` styles any selector with your tokens.

```ts
// src/theme/global.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  '.card': {
    backgroundColor: 'surface',
    borderRadius: 'card',
    boxShadow: 'raised',
  },
})
```

## Strict

A strict category accepts only your tokens, so a raw value such as
`color="#ff0000"` fails to type-check. Colors, radii and spacing can be strict.

```ts
// ui.config.ts
export default defineConfig({
  name: 'my-app',
  include: ['src/**/*.{ts,tsx}'],
  strict: ['colors', 'spacing'],
})
```
