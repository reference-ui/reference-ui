# Responsive layouts

Responsive styles in Reference UI follow the width of the nearest container.
A layout built this way adapts the same in a full page, a sidebar or a dialog.

<Step n={1}>Check the page is a container</Step>

The library makes `body` a container, so with `@reference-ui/lib` in
`extends` there is nothing to do. Without it, add one rule:

```ts
// src/theme/global.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  body: { containerType: 'inline-size' },
})
```

Without a container, responsive styles never match. `ref sync` warns when
your global CSS defines none.

<Step n={2}>Change values at breakpoints</Step>

Pass an object with a value per breakpoint. `base` applies at every width,
and each breakpoint applies from its width up:

```tsx
<Div
  display="grid"
  gap={{ base: '3r', md: '6r' }}
  gridTemplateColumns={{ base: '1fr', md: 'repeat(2, 1fr)', xl: 'repeat(4, 1fr)' }}
>
  <Card />
  <Card />
  <Card />
  <Card />
</Div>
```

One column in narrow space, two from `md` (768px), four from `xl`
(1280px). The full scale is on [Responsive](/responsive).

Write the narrow layout as `base` first, then add the breakpoints where it
needs to change. `sm` means 640px and up, so it never targets the narrowest
space.

<Step n={3}>Show and hide by width</Step>

Switch `display` between `none` and a layout value at a breakpoint:

```tsx
<Nav display={{ base: 'none', md: 'flex' }}>…</Nav>
<Button display={{ md: 'none' }}>Menu</Button>
```

To limit a style to one band of widths, use a range key such as `mdOnly` or
`smToLg`. [Responsive](/responsive#target-a-range) lists them.

## Respond to a panel

Mark any element with `container`, and responsive styles inside it follow
that element's width instead of the page:

```tsx
<Div display="grid" gridTemplateColumns="16rem 1fr">
  <Aside container>
    <ProfileCard />
  </Aside>
  <Main container>
    <ProfileCard />
  </Main>
</Div>
```

`ProfileCard` takes its narrow layout in the sidebar and its wide layout in
the main column, from the same code.

To skip past nearer containers, name one and target it in `r`:

```tsx
<Main container="content">
  {/* … */}
  <Div r={{ 'content/md': { padding: '8r' } }} />
</Main>
```

`'content/md'` matches when the container named `content` is at least
768px wide.

## Switch a recipe variant

A recipe variant takes the same breakpoint object:

```tsx
<button className={button({ size: { base: 'sm', md: 'lg' } })}>Save</button>
```

The button is `sm` until its container reaches `md`, then `lg`.
[Recipes](/recipes#responsive-variants) covers how compound variants treat
these values.
