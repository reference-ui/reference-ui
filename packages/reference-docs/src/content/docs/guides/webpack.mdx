# webpack

`ref sync` generates the stylesheet and runtime packages in `.reference-ui/`
before webpack starts, so webpack resolves them as standard packages without a
custom webpack plugin.

These steps start from a project where you have installed Reference UI and run
`ref init`, as in [Getting started](/initialize).

<Step n={1}>Add the scripts</Step>

Use `concurrently` (or any process runner) to run `ref sync --watch` alongside
`webpack-dev-server`:

<Install packages="concurrently webpack-dev-server" dev />

Then add the scripts:

```json
{
  "scripts": {
    "dev": "ref sync && concurrently --kill-others \"ref sync --watch\" \"webpack serve\"",
    "build": "ref sync && webpack"
  }
}
```

Running `ref sync` first ensures the generated packages exist on disk before
webpack starts.

<Step n={2}>Configure CSS loaders</Step>

Ensure webpack is configured to handle `.css` imports with `style-loader` and
`css-loader`:

<Install packages="style-loader css-loader" dev />

Then add a rule that uses them:

```js {6-9}
// webpack.config.cjs
module.exports = {
  entry: './src/main.tsx',
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader'],
      },
    ],
  },
}
```

Keep your existing rules for TypeScript and HTML. No additional Reference UI
loaders or plugins are needed.

<Step n={3}>Import the stylesheet</Step>

Import it once, in your entry file, before your app code.

```tsx
// src/main.tsx
import '@reference-ui/react/styles.css'
```

## Verify the setup

1. Run `npm run dev`. `ref sync` outputs the initial build summary, and webpack
   starts the dev server.
2. Render `<Div padding="6r">` from `@reference-ui/react`. `ref sync --watch`
   recompiles the stylesheet and webpack reloads the change.
3. Run `npm run build` to run `ref sync` followed by `webpack`.

[Sync](/sync) covers watch mode and its output in more detail.
