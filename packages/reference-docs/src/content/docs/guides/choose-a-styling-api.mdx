# Choose a styling API

Reference UI provides five styling APIs: style props, `css()`, `recipe()`,
`globalCss()`, and tokens. Because they all accept the same properties and
values, you can start with inline style props and extract shared styles into
classes, recipes, or tokens as your components grow.

| You are styling | Use |
| --- | --- |
| One element | [Style props](#style-props) |
| Multiple elements with shared styles, or a non-primitive element | [`css()`](#css) |
| A component with variants | [`recipe()`](#recipe) |
| A component with multiple parts | [`recipe()` with `slots`](/recipes#slots) |
| Document-level elements or third-party HTML | [`globalCss()`](#globalcss) |
| Shared design values across styles | [Tokens](#tokens) |

## Style props

Pass style props directly to a [primitive](/primitives), alongside condition
props such as `_hover`:

```tsx
import { Div, H3 } from '@reference-ui/react'

<Div padding="4r" bg="surface" borderRadius="card" _hover={{ bg: 'surface/80' }}>
  <H3 color="brand">Plan</H3>
</Div>
```

See [Style props](/style-props) for every prop and value.

## css()

Use `css()` when several elements share the same styles, or when styling a
non-primitive element (such as a native tag or a component from another
library). It returns a class name string:

```tsx
import { css } from '@reference-ui/react'

const card = css({ padding: '4r', bg: 'surface', borderRadius: 'card' })

<article className={card}>…</article>
```

See [CSS](/css) and [Dynamic styles](/dynamic-styles).

## recipe()

When a component has named variants like `tone` or `size`, use `recipe()`. It
takes base styles and variant maps, and returns a function that produces the
class names for a given selection:

```tsx
import { recipe } from '@reference-ui/react'

const card = recipe({
  className: 'card',
  base: { padding: '4r', borderRadius: 'card' },
  variants: {
    tone: {
      plain: { bg: 'surface' },
      brand: { bg: 'brand', color: 'white' },
    },
  },
  defaultVariants: { tone: 'plain' },
})

<article className={card({ tone: 'brand' })}>…</article>
```

See [Build a component](/build-a-component) and [Recipes](/recipes).

## globalCss()

Use `globalCss()` to style elements outside your component tree, such as `body`,
`:root`, rendered Markdown or CMS HTML, or all primitives of a given type via
their `ref-*` class:

```ts
// src/theme/global.ts
import { globalCss } from '@reference-ui/system'

globalCss({
  body: { color: 'text', backgroundColor: 'surface' },
  '.prose a': { color: 'brand' },
})
```

See [Global CSS](/global-css) for selectors, nesting and the reset.

## Tokens

Define repeated values as design tokens so they can be referenced by name across
style props, `css()`, recipes, and global rules. Updating a token updates every
style that references it:

```ts
// src/theme/tokens.ts
import { tokens } from '@reference-ui/system'

tokens({
  colors: {
    brand: { value: '#4f46e5' },
  },
})
```

See [Theming](/theming) for fonts, animations and dark mode, and
[Tokens](/tokens) for the full reference.

## Style precedence

Each API outputs CSS to a dedicated [cascade layer](/cascade-layers). Global
rules have the lowest precedence, followed by recipes, and then utilities (style
props and `css()`). When multiple APIs target the same element, more specific
layers override broader ones without `!important`. Here, the `padding` prop
overrides the recipe's `4r` padding:

```tsx
<Div className={card()} padding="6r">…</Div>
```
