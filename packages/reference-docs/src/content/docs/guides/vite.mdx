# Vite

`ref sync` generates the stylesheet and runtime packages in `.reference-ui/`
before Vite starts, so Vite resolves them as standard packages without a custom
Vite plugin.

These steps start from a project where you have installed Reference UI and run
`ref init`, as in [Getting started](/initialize).

<Step n={1}>Add the scripts</Step>

Use `concurrently` (or any process runner) to run `ref sync --watch` alongside
the Vite dev server:

<Install packages="concurrently" dev />

Then add the scripts:

```json
{
  "scripts": {
    "dev": "ref sync && concurrently --kill-others \"ref sync --watch\" \"vite\"",
    "build": "ref sync && vite build"
  }
}
```

Running `ref sync` first ensures the generated packages exist on disk before
Vite starts.

<Step n={2}>Import the stylesheet</Step>

Import it once, in your entry file, before your app code.

```tsx
// src/main.tsx
import '@reference-ui/react/styles.css'
```

No changes to `vite.config.ts` are required.

## Verify the setup

1. Run `npm run dev`. `ref sync` outputs the initial build summary, and Vite
   starts the dev server.
2. Render `<Div padding="6r">` from `@reference-ui/react`. `ref sync --watch`
   recompiles the stylesheet and Vite hot-reloads the change.
3. Run `npm run build` to run `ref sync` followed by `vite build`.

[Sync](/sync) covers watch mode and its output in more detail.
