# Server-side rendering

Reference UI works with server-side rendering (SSR) and static site generation
(SSG) without any framework-specific style plugins, because all CSS is compiled
ahead of time.

## How it works

`ref sync` compiles a static stylesheet at build time, while primitives and
`css()` only return class name strings at runtime. Because no CSS is generated
or injected in the browser, SSR requires:

- no server-side style registry or extraction pass,
- no streamed `<style>` tags during hydration, and
- no flash of unstyled content (FOUC).

The server and client produce identical class names against the same stylesheet,
so the HTML hydrates without mismatches.

## Load the stylesheet

Import the stylesheet once, in the module that renders your app's root, so
the server HTML links it:

```tsx
import '@reference-ui/react/styles.css'
```

## Set the colour mode

The server can't read the browser's settings or storage. Save the user's
choice in a cookie, read it from the request, and pass it to `colorMode` on
your root primitive:

```tsx
<Div colorMode={mode}>
  <App />
</Div>
```

Both server and client then render the same mode without a theme flash during
hydration. See [Light and dark](/light-and-dark) for persisting and toggling the
mode.

Avoid setting `data-color-mode` directly on `<html>` or `<body>`. In the
browser, primitives without an ancestor `colorMode` prop fall back to reading
that attribute from `document`, which is unavailable on the server and causes a
hydration mismatch.

## Library components

- Overlay content that mounts only when open (such as Tooltip and Popover
  content) is omitted from the server HTML and mounts in the browser when
  opened, while triggers render normally on the server.
- [Portal](/portal) renders its children in the browser after hydration.
- [ReferenceLibrary](/reference-library) renders its children on the server and
  mounts the toast viewport and live region in the browser after hydration.
- Components create their ids with React's `useId`, so the ids in `aria-*`
  attributes match between the server and the browser.
