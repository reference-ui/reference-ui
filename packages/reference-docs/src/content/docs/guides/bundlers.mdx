# Bundlers

`ref sync` writes your stylesheet and packages to `.reference-ui/` before
the bundler runs. The bundler reads them like any other package.

Each setup below needs the same three things: sync before the build, watch
mode beside the dev server, and one stylesheet import.

## Vite

<Step n={1}>Add the Vite scripts</Step>

```json
{
  "scripts": {
    "dev": "ref sync && concurrently --kill-others \"ref sync --watch\" \"vite\"",
    "build": "ref sync && vite build"
  }
}
```

The first `ref sync` makes sure the generated packages exist before Vite
starts. `concurrently` is a separate package; any tool that runs two commands
side by side works.

<Step n={2}>Import the stylesheet with Vite</Step>

Import it once, in your entry file, before your app code.

```tsx
// src/main.tsx
import '@reference-ui/react/styles.css'
```

Your `vite.config.ts` needs no Reference UI settings.

## webpack

<Step n={1}>Add the webpack scripts</Step>

```json
{
  "scripts": {
    "dev": "ref sync && concurrently --kill-others \"ref sync --watch\" \"webpack serve\"",
    "build": "ref sync && webpack"
  }
}
```

<Step n={2}>Handle CSS files</Step>

webpack needs a rule for `.css` imports. This one uses `style-loader` and
`css-loader`:

```js {6-9}
// webpack.config.cjs
module.exports = {
  entry: './src/main.tsx',
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader'],
      },
    ],
  },
}
```

Keep your existing rules for TypeScript and HTML. Reference UI adds none.

<Step n={3}>Import the stylesheet with webpack</Step>

Import it once, in your entry file, before your app code.

```tsx
// src/main.tsx
import '@reference-ui/react/styles.css'
```

## Verify the setup

1. Run `npm run dev`. The terminal shows the sync summary, then your dev
   server.
2. Add `padding="6r"` to a `Div`. A resync line appears and the page picks
   up the padding.
3. Run `npm run build`. Sync runs first, then the bundler.

[Sync](/sync) covers watch mode and its output in more detail.
