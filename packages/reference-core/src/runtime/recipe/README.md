# The recipe() runtime

Native recipe resolution over compiled tables. Authored configs become closed-class resolvers composing base plus variant and compound classes, per-axis responsive objects append one derived per-breakpoint class each, and the lowering wrapper keeps rhythm sugar on the container-query shape the compiler extracted. Class derivation is pure over tables that ship derivation inputs only.

A config with `slots` resolves as one plain resolver per slot over that slot's projection, named `${className}__${slot}` like its compiled table, and returns one class string (or raw style object) per slot.
