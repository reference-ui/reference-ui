# Reference tasty options

The reference-flavored tasty API both runtimes build through. Caller-supplied options gain preferred external libraries plus the member projection onto system properties; the Node bridge and the browser runtime share these getters so their symbol graphs agree. The display-result read, the budget warning and the type-parameter hook's `displayMembersOf` are typed by the vendored tasty declarations, so `api.ts` declares no view types of its own.
