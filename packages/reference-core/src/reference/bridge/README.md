# Reference build bridge

The serial-phase surface sync wires for the reference tasty build. The scheduler runs the cold-start build on the next loop iteration while sync completes unwatched; the runner answers structured results with warnings riding the unified reporter and throws becoming failed results, never rejections. One-shot CLIs drain the cold build before exit: a build still pending drains as its promise, and one that already settled drains as its parked result. Each result drains exactly once; a parked result is not a cache, since the drain removes it and the next scheduled build clears a stale one. A failed build is reported once as an error, with its `TST-E-*` code, at the moment it settles (the runner's logger, or the scheduler for a build that rejects); the one-shot CLI names it in its summary and still exits 0, since a tasty failure is metadata and never fails a sync.
