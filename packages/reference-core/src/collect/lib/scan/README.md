# Fragment discovery scan

Finds the source files that may carry fragments. Glob roots plus import-or-call signals select absolute paths; a fused suffix walk classifies matchable and retainable flags without allocating per candidate, MDX gets a pure sync selection pass that fences off frontmatter and code blocks, and the native single-read scan shares needle regexes with the TS side so match order never drifts. Differential batteries and committed goldens pin the boundary byte-for-byte.

The project listing (`project-files.ts`) is the one enumeration both scanners and the watch matcher share. It walks the root in the Rust walk's sorted order, enters each real directory under its own path, and enters a symlinked directory only when it admits a file of its target that no earlier admitted link admitted (`project-admission.ts`), never back into an ancestor, so a loop of links ends at the link that closes it. A file reached through two paths is listed once: under its real path when one exists, otherwise under the first link alias. Include globs that leave the root (`../shared/**`, absolute globs) walk their own base the same way.
