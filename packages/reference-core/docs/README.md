# Standing documents

The three files agents reach for beyond the code. The domain doc names
the load-bearing vocabulary (cases, worlds, specs, fragments, the cut);
the testing doc is the `agentcore` contract (commands, exit codes, the
last-run log, snapshot policy); the reference-browser doc traces how
tasty type data becomes rendered API-table rows. Each is a living doc:
when the code it describes moves, the doc moves in the same pass.
