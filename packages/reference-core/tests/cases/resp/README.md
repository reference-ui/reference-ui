# CORE-RESP — container breakpoints and responsive arrays

Proves Reference's responsive dialect paints by container width, not viewport width: named breakpoints, range conditions, numeric `r` keys, and array values with `null` holes all lower to `@container` queries, and the browser proof flips a container element's width and reads computed style. The group spec carries the responsive contract; the cases below are the ledger.
