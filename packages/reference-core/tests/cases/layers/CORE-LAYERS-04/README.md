# CORE-LAYERS-04 — container root and upstream qualifiers reach the consumer through layers, as through extends

The consumer authors one container query and carries a local `globalCss` block, so the container-root check has something to judge. The upstream is a real published base system, synced for real by the spec, whose global CSS roots the page with `:root { container-type: inline-size }`. The consumer also renders the upstream package's own `Span` with a literal colour (`src/probe.tsx`): a tag imported from an installed package renders through that package's runtime, so the engine keeps the style prop as an external want and backs it in the consumer's foreign group for the upstream. The upstream carries a `package.json` naming it `core-layers4-up`, and the spec links it into `world/node_modules` for the run, so the import resolves to the upstream's directory and its published system.

The spec runs three legs over the same consumer, re-syncing between them:

1. Standalone (canonical config, no upstream). The sync warns `ATM-W-MISSING-CONTAINER-ROOT` once, with the text "no container root (container-type) is defined in globalCss". The compile request carries neither `upstreamContainerRoot` nor `upstreamSystems`, the sheet has no foreign group, the container probe stays at its 50px base and the foreign probe takes the body ink.
2. Layers (`layers: [up]`). The sync is silent. The request carries `upstreamContainerRoot: true` and `upstreamSystems: ["core-layers4-up"]`. The sheet states `@layer core-layers4-up, core-layers4;`, the upstream root rides the upstream block, and the consumer's foreign group `/* foreign core-layers4-up */` prints `.core-layers4-up__c_\#15803d`. The html element is an `inline-size` container, the probe paints 60px, and the foreign probe paints the literal green.
3. Extends (`extends: [up]`, the control). The same verdicts as layers, so the layer changes nothing the extends bucket does not already do.

The published entry is asserted too. The consumer's own `system/baseSystem.mjs` carries no foreign group, while the served sheet keeps it. That publish-time strip is what keeps a foreign rule from reaching a downstream compose.

Observables found, with evidence:

- Container root verdict. `src/sync/index.ts:179` reads the root verdict across extends and layers together. `src/system/base/container-root.ts:8-41` detects a `:root`, `html` or `body` block declaring a container property in the published global text. `src/native/request.ts:50` puts the key on the request. `packages/reference-rs/modules/atomic/src/assembly.rs:97-102` hands it to the check. `packages/reference-rs/modules/atomic/src/resolve/conditions/mod.rs:65-96` warns only when `@container` atoms exist, no upstream roots the page, and the local `globalCss` is non-empty. The code is `packages/reference-rs/modules/atomic/src/diagnostics/codes.rs:193`, the text is `packages/reference-rs/modules/atomic/src/diagnostics/policy/resolve.rs:127`.
- Qualifiers. `src/sync/index.ts:135-143` builds `upstreamSystems` from extends then layers, self excluded. `src/native/request.ts:53` serializes it. `packages/reference-rs/modules/atomic/src/assembly.rs:65-74` (`qualifiers_for`) makes the list own-first and deduped; it orders the groups but no longer decides what is emitted. `packages/reference-rs/modules/atomic/src/stylesheet/cascade/mod.rs:121-150` (`write_utilities_grouped`) writes one `/* foreign <q> */` group per system the foreign atoms name, composed systems first in qualifier order. `packages/reference-rs/modules/atomic/src/stylesheet/emitter/mod.rs:146-159` prints the utilities layer when it has an own rule or a foreign group. `packages/reference-rs/modules/atomic/src/runtime/plan_pool.rs:36-52` (`first_seen`) gives a declaration whose backing names no system no plan.
- What makes a want external. Import provenance: a tag whose import ends at a package that published a system is external whatever its name, and backs under that package's systems the consumer composes (`packages/reference-rs/modules/atomic/src/extract/provenance.rs`, `extract/package_system.rs` reads the package's published system). The probe was first a same-file `Probe` that turned `color` into `data-probe-color`; since `edae6aa85` a same-file component's consumed prop is its own, so that probe minted no want and the layers leg failed on `public-release` too. The real consumer describes the same mechanism in `packages/reference-lib/ui.config.ts`, for `layers: [iconsBaseSystem]`.
- Foreign stripping. `src/system/base/streams.ts:78-103` (`stripForeignSections`) drops a foreign section from an entry. `packages/reference-core/src/system/base/streams.ts:158-170` (`toPublishedEntry`) applies that to the own entry before it publishes, and this case asserts that leg. `packages/reference-core/src/system/base/streams.ts:105-115` (`printUpstreamBlock`) applies it to upstream blocks at merge time. A real upstream never reaches that merge strip, because the publish strip has already removed every foreign group, so this case does not exercise it.
