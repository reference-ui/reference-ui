# CORE-CHAIN shared upstream helper

Syncs a real upstream or consumer for real and reads back what it published: the base system and the evaluated spec. Rewrites a canonical config to import published base systems and compose them in order, installs a world package the way a package manager leaves it, restores the canonical spelling with a resync, and reads a probe's computed paint from the served page. Each case states its own wiring and its own claims.
