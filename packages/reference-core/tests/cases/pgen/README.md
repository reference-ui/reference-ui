Proves the RS-emitted primitive shelf Core vendors through the native seam: the E1 element vocabulary as data, the E2 raw roster as a live module, and the E4 raw types as declarations. Two parity cases gate freshness at test time, six type cases prove the E4 surface assigns and rejects exactly where it must, and the PRIM re-anchors tie the old census to the new shelf. `shared/` holds the temp-project tsc harness and the set-parity helpers the specs share. `SPEC.md` carries the shelf contract; `TESTS.md` is the case ledger.
