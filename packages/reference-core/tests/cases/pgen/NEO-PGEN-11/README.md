# NEO-PGEN-11 — the special-cased roster renders, override refs land, and no pattern pack ships

The world renders the special-family members no other render case owns:
Obj, Var, and Map with native wiring, the void Br, Hr, and Wbr, plus a
Caption in its table and a Menu, both carrying ref callbacks that record
which host interface they receive. Every probe paints `color="brand"`. The
spec asserts each probe's element name, marker, layer stamp, brand paint,
and styling-key absence, proves the caption and menu refs receive their
override host interfaces at runtime, and pins the bound bundle's export
set to exactly the 101 roster names plus the 6 value helpers plus css and
recipe — with the known pattern names absent and the types bundle
pattern-free. Related: NEO-PGEN-02 (the single-letter specials),
NEO-PGEN-19 (the type-level override precedent), NEO-PRIM-10 (the
surface census this export pin refines).
