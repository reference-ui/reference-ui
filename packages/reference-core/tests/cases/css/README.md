# CORE-CSS — value grammar and the css() runtime

Proves the `css()` value grammar leaf by leaf: one property, one value, one class, painted through the runtime over compiled plans. Token paths and rhythm, arbitrary functions and values, unit policies, shorthand expansions, important spellings, and nullish leaves that emit nothing; responsive lowering matches build time and the harvest floor paints written shades while unwritten ones miss loud. Conditions, breakpoints, merging, and recipes belong to their own groups. The group spec carries the value contract; the cases below are the ledger.
