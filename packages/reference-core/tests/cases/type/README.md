# CORE-TYPE — generated declarations

Proves that after `sync()` the generated declarations type real consumer code: a world importing primitives, `css`/`recipe`, and named types from `@reference-ui/react` compiles clean, token unions and recipe variants reject bad literals, and the system authoring surface typechecks in fragment files. Owns the types publish assembly and the tsconfig `paths`. The group spec carries the declarations contract; the cases below are the ledger.
