# CORE-TYPE — generated declarations

Proves that after `sync()` the generated declarations type real consumer code: a world importing primitives, `css`/`recipe`, and named types from `@reference-ui/react` compiles clean, token unions and recipe variants reject bad literals, and the system authoring surface typechecks in fragment files. Owns `src/packager/assembly.ts` (types publish only) and `tsconfig.json` `paths`. `SPEC.md` carries the declarations contract; `TESTS.md` is the case ledger.
