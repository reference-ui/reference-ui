# NEO-LAYERS-04 — container root and upstream qualifiers reach the consumer through layers, as through extends

The consumer authors one container query and carries a local `globalCss` block, so the container-root check has something to judge. The upstream is a real published base system, synced for real by the spec, whose global CSS roots the page with `:root { container-type: inline-size }`. The consumer also carries one capitalized JSX tag with a literal colour, which the engine keeps as an external want and prints under one foreign group per composed system.

The spec runs three legs over the same consumer, re-syncing between them:

1. Standalone (canonical config, no upstream). The sync warns `ATM-W-MISSING-CONTAINER-ROOT` once, with the text "no container root (container-type) is defined in globalCss". The compile request carries neither `upstreamContainerRoot` nor `upstreamSystems`, the sheet has no foreign group, the container probe stays at its 50px base and the foreign probe takes the body ink.
2. Layers (`layers: [up]`). The sync is silent. The request carries `upstreamContainerRoot: true` and `upstreamSystems: ["neo-layers4-up"]`. The sheet states `@layer neo-layers4-up, neo-layers4;`, the upstream root rides the upstream block, and the consumer's foreign group `/* foreign neo-layers4-up */` prints `.neo-layers4-up__c_\#15803d`. The html element is an `inline-size` container, the probe paints 60px, and the foreign probe paints the literal green.
3. Extends (`extends: [up]`, the control). The same verdicts as layers, so the layer changes nothing the extends bucket does not already do.

The published entry is asserted too. The consumer's own `system/baseSystem.mjs` carries no foreign group, while the served sheet keeps it. That publish-time strip is what keeps a foreign rule from reaching a downstream compose.

Observables found, with evidence:

- Container root verdict. `src/sync/index.ts:179` reads the root verdict across extends and layers together. `src/system/base/container-root.ts:8-41` detects a `:root`, `html` or `body` block declaring a container property in the published global text. `src/native/request.ts:50` puts the key on the request. `packages/reference-rs/modules/atomic/src/assembly.rs:97-102` hands it to the check. `packages/reference-rs/modules/atomic/src/resolve/conditions/mod.rs:65-96` warns only when `@container` atoms exist, no upstream roots the page, and the local `globalCss` is non-empty. The code is `packages/reference-rs/modules/atomic/src/diagnostics/codes.rs:193`, the text is `packages/reference-rs/modules/atomic/src/diagnostics/policy/resolve.rs:127`.
- Qualifiers. `src/sync/index.ts:135-143` builds `upstreamSystems` from extends then layers, self excluded. `src/native/request.ts:53` serializes it. `packages/reference-rs/modules/atomic/src/assembly.rs:54-63` (`qualifiers_for`) makes the list own-first and deduped. `packages/reference-rs/modules/atomic/src/stylesheet/cascade/mod.rs:133-151` writes one `/* foreign <q> */` group per qualifier. `packages/reference-rs/modules/atomic/src/stylesheet/emitter/mod.rs:130` prints a foreign set only when there is more than one qualifier. `packages/reference-rs/modules/atomic/src/runtime/plan_pool.rs:44` gives an external declaration no plan without a foreign qualifier.
- What makes a want external. `packages/reference-rs/modules/atomic/src/atom/want.rs:19-23` marks wants authored on a capitalized, non-host JSX tag, and `packages/reference-rs/modules/atomic/src/extract/jsx/names.rs:71-74` is the lexical rule. The real consumer describes the same mechanism at `packages/reference-lib/ui.config.ts:27-35`, for `layers: [iconsBaseSystem]`.
- Foreign stripping. `src/system/base/streams.ts:78-103` (`stripForeignSections`) drops a foreign section from an entry. `packages/reference-neo/src/system/base/streams.ts:158-170` (`toPublishedEntry`) applies that to the own entry before it publishes, and this case asserts that leg. `packages/reference-neo/src/system/base/streams.ts:105-115` (`printUpstreamBlock`) applies it to upstream blocks at merge time. A real upstream never reaches that merge strip, because the publish strip has already removed every foreign group, so this case does not exercise it.
