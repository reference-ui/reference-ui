## 3. Harness inventory + `case.json` contract

### `tests/shared/*.ts` (one line each)

| File | Job |
|------|-----|
| `cli.ts` | `agentneo` argv: `list` / `search` / `run` / `q`; snapshot `--confirm` gate; package typecheck then sequential `runCase`. |
| `runner.ts` | Per-case pipeline: world build → optional `sync(worldDir)` → HTTP serve + preflight → headless Playwright specs → artifacts. |
| `server.ts` | Isolated static HTTP server on `127.0.0.1` + ephemeral port for one world (never `file://`). |
| `page.ts` | Local structural types for the Playwright page/locator surface specs import. |
| `snapshots.ts` | `snap(page, name)` pixelmatch vs `__snapshots__/`; write baselines only when update mode is armed. |
| `cases.ts` | Discover any folder with `case.json`; records `{ id, name, folder, dir, worldDir, specsDir, description }`. |
| `lastRun.ts` | Gitignored `tests/.artifacts/last-run.json` for `--failed` and fail-first ordering. |
| `build.ts` | Transpile `world/src/**/*.ts(x)` with esbuild into gitignored `world/dist/` (no-op if no `src/`). |
| `typecheck.ts` | Package `tsc --noEmit -p packages/reference-neo`; red types refuse the whole run. |

### `case.json` contract

Parsed in two places:

- `cases.ts` **requires** string `id` and `name`. Duplicate ids fail loud. README first line is description only.
- `runner.ts` `caseOptsIntoSync`: `"sync": true` opts the world into `src/sync/index.ts` `sync(cwd)` before serve. Any other value or missing flag = static serve (legacy). Unreadable JSON = skip sync.

**No `build` flag.** If `world/src/` exists, build always runs; if absent (SMOKE / SNAP-A / PLAY-B / SYNC-01 tokens live under `theme/`), build is a silent no-op.

**No per-case `typecheck` flag.** `cli.ts` `cmdRun` always `checkTypes()` once, then cases.

Optional CLI on `run`: `--failed`, `--update-snapshots` (refused unless `--confirm`).

### `run` sequence

1. Parse flags; snapshot gate (`--update-snapshots` without `--confirm` → exit 1).
2. Select cases (one id, all, or last-run failures); fail-first reorder.
3. **Typecheck** the package (`tsc --noEmit`). Fail → refuse, no browser.
4. For each case (`prepareWorld` → `serveWorld` → Playwright):
   1. **Build** `world/src` → `dist/` (esbuild transpile-only).
   2. **Sync** if `"sync": true` (clean `.reference-ui/`, fragments, native `compile()`, publish).
   3. **Serve** world over HTTP; preflight GET `/` must be 200.
   4. Launch Chromium **headless** (`chromium.launch()` with no `head: true`).
   5. For each `specs/*.spec.ts`, `page.goto` + default-export `run({ page, url, case, snap })`.
   6. Artifacts: screenshot + a11y yaml always; trace on failure.
5. Merge `last-run.json`. Exit 1 if any fail, 2 if Playwright degraded.

### Snapshot gating

- Specs call `snap(page, name)` from the runner.
- Baselines: `tests/cases/<id>/__snapshots__/<name>.png`.
- Compare: pixelmatch threshold 0.1, max diff ratio 0.001; pass still logs drift.
- Updates **only** via `pnpm agentneo run --update-snapshots --confirm`. Without `--confirm`, CLI throws and writes nothing.
- Committed baselines today: `NEO-SMOKE-01/dot.png`, `NEO-SNAP-A-01/probe.png`, `NEO-PLAY-B-01/probes.png`.
