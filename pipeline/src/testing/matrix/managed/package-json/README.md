# Managed Matrix Package JSON

Every package.json shape generated by the matrix pipeline: managed fixture manifests inside the monorepo `matrix/*` folders, and synthetic consumer manifests generated inside Dagger with scripts stripped, `workspace:` deps rewritten to staged tarballs, and active bundler dev dependencies injected.

One source of truth for managed versions, pipeline-routed scripts, and workspace-protocol rewriting, instead of spreading package.json rules across sync code and runner orchestration.
