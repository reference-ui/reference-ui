# Stored collection specs

Index specs for the memex collections: the case families (cases, lib-cases, rs-cases), the component unit contracts (components) and the vendored design-system docs (docs-corpus). Each names how a doc is read (a marker folder, or entries of a JSON array), the id and title fields, and the ranking weights. Specs list no roots where they can: a folder joins a collection when its `README.md` carries `memex: <collection>` frontmatter, so a new case folder anywhere needs only that README. docs-corpus is the exception: its root, `vendor/docs/_normalized`, is gitignored generated output with no README to commit, so its spec lists that root explicitly; on a checkout without the corpus the collection is empty.
