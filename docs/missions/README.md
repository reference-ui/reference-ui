# Mission Log

Active missions live here, one file each. Finished missions move to
[`completed/`](completed/). Ideas are missions too — they just haven't
shipped yet. Status line at the top of each file says where it stands:
`idea`, `ready` (plan signed, line 1 reads `OPERATION: READY`, awaiting
the READY-phase asks before GO), `active`, or `done` (done ones live in
`completed/`).
