## Brief (from `.agents/missions/playtest/packaging.md` H-6)

The dev-mode miss probe (`reportMissCandidates` → `sheetsComplete`) only
defers for external LINKED sheets; Vite-dev-injected `<style>` tags arrive
AFTER first render, so early `css()` calls warn for values whose rules EXIST
in the sheet (false-positive race; production link tags unaffected).

## Root cause (confirmed in code)

- Probe lives at `packages/reference-rs/modules/atomic/js/namer/miss.ts`
  (agent-rs territory — NOT touching): `reportMissCandidates` runs its check
  in a microtask; `sheetsComplete()` skips every sheet with `href === null`
  (inline `<style>`), so with zero linked sheets it returns true while the
  document is still loading and late `<style>` tags have not arrived yet.
- Neo's `css()` (`packages/reference-neo/src/runtime/css/css.ts`
  `reportStyleMisses`) hands every constructed class to the probe
  immediately, so in dev the first-render flush scans an empty sheet list
  and warns for present rules.

## Fix plan (neo-side, no rs changes)

- In neo `css.ts`: hold miss candidates until the document settles — hand
  to the probe immediately when there is no document (Node silence) or
  `readyState === 'complete'`; otherwise queue and flush once on window
  `load`, when every dev-injected `<style>` from the initial graph is in.
- True misses still warn (their class never appears); present rules scan
  clean. Production path unchanged (early return already).

## Flags for HQ

1. The rs-side probe (`packages/reference-rs/modules/atomic/js/namer/miss.ts`
   `sheetsComplete`) still treats "no linked sheets pending" as complete
   while the document loads — agent-rs may want to gate on `readyState`
   there too, so non-neo callers of `reportMissCandidates` get the same
   protection. Neo no longer depends on that path pre-load.
2. Post-load HMR-injected styles can still race post-load `css()` calls
   (a MutationObserver in the probe would be the deeper fix) — out of
   scope for this first-render race.
3. Dev miss diagnostics now flush at `load` instead of in a microtask;
   on pages where `load` hangs, dev warnings wait with it. Accepted
   trade-off for zero false positives.
