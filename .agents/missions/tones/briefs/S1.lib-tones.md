Goal: ship the default TONES in the base system (`@reference-ui/lib`'s theme) and carry them through the frozen Rust fixtures, so every system that extends lib gets `--tones-*` custom properties.

## Background

Tones are a new token category: a colour at a named opacity, used as
`bg="blue.500/medium"`. The atomic compiler already resolves them (role
`surface` for areas, `line` for edges/text) against tokens keyed
`tones.<name>.<role>`. This job only declares the defaults and re-freezes the
fixtures that mirror lib's tokens.

## Work

1. New file `packages/reference-lib/src/core/theme/tones.ts`, in the style of
   `packages/reference-lib/src/core/theme/radii.ts`, with a short `/** */`
   header (what tones are; surface = areas, line = borders/outlines/text; values
   are percentages of the colour mixed with transparent; projects override or
   add tones with their own `tokens({ tones })`):
   ```ts
   export const tones = {
     ghost:  { surface: { value: '4%' },  line: { value: '22%' } },
     medium: { surface: { value: '10%' }, line: { value: '34%' } },
     firm:   { surface: { value: '14%' }, line: { value: '46%' } },
     strong: { surface: { value: '18%' }, line: { value: '58%' } },
   } as const
   tokens({ tones })
   ```
