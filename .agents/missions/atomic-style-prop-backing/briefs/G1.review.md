### Correction C-T16 — real fan-out defect (RULE + fix required before W3)

**Symptom.** T16 test 6 fails: the page's icons rules arrive **twice**.
`duplicates = [".reference-icons__w_30r", ".reference-icons__w_55r"]`,
`total = 609` vs `expected = 7`.

**Mechanism (verified from bodies + a fresh `ref sync`).**
1. `packages/reference-lib/ui.config.ts` `include` covers `src/**` **and `book/**`**; it declares `layers: [iconsBaseSystem]`.
2. The §D gate externalizes lib's **own** non-host capital tags — Book compound tags (`<Popover.Trigger w="30r">`, `<IconComp …>`), test fixtures (`<HandoffFixture …>`) — because they are capitalized and not hosts.
3. `assembly.rs:54 qualifiers_for` gives lib `["reference-ui","reference-icons"]` (icons is lib's layer upstream).
4. External wants are emitted **once per foreign qualifier** via `write_utilities_grouped` → `emitter/mod.rs:122 append_utilities_layer` → `emitter/streams.rs:156 utilities_layer` — and **G0 §H / T04 put the foreign groups in the ONE shared `utilities` stream**.
5. lib's published `baseSystem.mjs` stream `"reference-ui"` = 2167 own `.reference-ui__*` + **602 `.reference-icons__*` foreign** rules (2780 lines).
6. The consumer copies that stream verbatim → page = 7 canonical icons + 602 foreign = **609**, `w_30r`/`w_55r` duplicated *inside* the foreign group.
7. **515 of 590** distinct foreign classes also appear in lib's own group → lib's own call-sites are qualified twice.

**This is a fan-out design defect, not infra.** It reproduces natively with a fresh engine; the package-prep/cargo staging change is cleared.

**Fix options (rule which, or propose better):**
- **(a) A published base system's `streams.utilities` is OWN-ONLY.** Keep foreign-qualifier groups in the rendered `stylesheet`/`portable_stylesheet` (the page this compile produces) but **out of the `streams` object** a downstream compose copies verbatim (`stylesheet/emitter/streams.rs` + the portable path). A consumer derives foreign rules from its **own** external tags, never from an upstream's stream.
- **(b) Stop externalizing a self-compiling package's own capital tags** not owned by a declared upstream system — the 515/590 own↔foreign overlap shows lib's own call-sites are the source; plus exclude `book/**`/tests from lib's `include`.

The **T16-frozen contract is authority**: "icons rules arrive exactly once (no duplicated layer copy)".

**Also required (test-infra gap).** The **native** `pnpm agent playwright` path must run `ref sync` (or matrix packages must not ship a committed `.reference-ui`) — otherwise native can never be gate evidence (the false pass). The T16-hermetic crew already landed a pipeline improvement that surfaces matrix Playwright failure detail in the stage log.

**Ask.** Rule the fix (a / b / other) and the exact change surface; confirm the corrected engine still lands foreign rules **on the consuming page** (the fan-out's purpose); and say how T17's structured-icons accounting must reflect it.
