## 4. 10-line handoff note

1. §H landed: `write_utilities_grouped(out, own, external, qualifiers)` — own group
   via the shared sorter, then external ranked **once** and replayed under
   `SelectorPrefix::for_system(q)` for every `qualifiers[1..]`.
2. One shared sort+group writer: `rank_atoms` + `write_ranked` back both
   `write_utilities` and the grouped own/foreign passes, so the own group is
   **structurally** the flat bytes (not a copy that happens to match).
3. Short-circuit `if external.is_empty() { return write_utilities(out, own, &qualifiers[0]); }`
   — the default path takes the untouched flat writer.
4. Two sets, N groups: `append_utilities_layer` + `streams::utilities_layer` take
   `(own, external, qualifiers)`; the single `utilities` stream carries all groups,
   so `stylesheet` **and** `portable_stylesheet` ride foreign rules — no new stream
   key, no portable split.
5. Buffer sized `own + external×n_foreign` (`n_foreign = qualifiers.len()−1`).
6. No empty blocks: the layer is skipped when nothing would print (own empty and
   no foreign group) — proven by `test_no_empty_utilities_block_without_foreign_qualifier`.
7. `debug_assert!` follows §H: there is no `own system` parameter, since `own`'s
   system **is** `qualifiers[0]`; the assert pins the non-empty own-first invariant.
8. `finish` now threads the own set, the external set, and `qualifiers`.
9. **T05 assumes:** emission is keyed by `plan.system` (`class_name_with_system`);
   T04 emits exactly one rule per foreign qualifier per external class, so the S4
   join must expand external expectations over `qualifiers[1..]` to match.
10. **G1 assumes:** default-path bytes are frozen — any golden diff on a
    non-external station is a line-stop; the empty-external oracle pins it.

## 5. Byte-identity evidence (G0 §K / T04)

- **Empty-external short-circuit === existing bytes.** Unit oracle
  `grouped_empty_external_is_byte_identical_to_flat_write_utilities` builds one
  mixed atom set, runs the flat `write_utilities(&set, "@reference-ui/lib")` and
  `write_utilities_grouped(&set, &AtomSet::new(), &["@reference-ui/lib"])`, and
  asserts `assert_eq!(grouped, flat)`.
- **Structural, not coincidental.** `write_utilities` and the grouped own pass
  both call `write_ranked`/`rank_atoms`, so the own group is the same code path.
- **Portable agrees.** `test_grouped_foreign_rules_ride_both_sheets` asserts the
  foreign rule (`.alpha__p_2r`) is present in **both** `sheet` and `portable`, that
  the own group precedes the foreign group inside the single `streams.utilities`,
  and that `portable == build_portable_stylesheet_with(own, external, qualifiers, …)`
  (the grouped single-build). The 10-key stream serialization is unchanged
  (`test_streams_serialize_to_ten_wire_keys` green: `utilities` is still one key).
- **Zero golden drift.** `pnpm agentrs v atomic` green with no `output/*` change;
  the 314 seam goldens are byte-unchanged. The 11 T02 external-want stations carry
  `qualifiers = [own]` (standalone), so a non-empty external set yields **zero**
  foreign groups and prints the same own-only bytes as T03.
- **`external` stays additive on the wire.** `Want`/`AuthoredDeclaration`
  skip-when-false; the emitted-sheet wire (`stylesheet`/`portableStylesheet`/
  `streams`) is byte-identical whenever no foreign qualifier exists.
