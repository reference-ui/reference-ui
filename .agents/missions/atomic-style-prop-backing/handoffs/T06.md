1. **`src/native/contract.ts`** — `ScopedCompileRequest` gains
   `upstreamSystems?: string[]` (structural carry like `include`, doc-commented:
   drops when undefined so a no-upstream compile gains no key).
2. **`src/native/request.ts`** — `CompileRequestInput` gains
   `upstreamSystems?: string[]`; `buildCompileRequest` emits
   `upstreamSystems: input.upstreamSystems?.length ? [...input.upstreamSystems] : undefined`
   — **length-gated, NOT `|| undefined`** (arrays are truthy; `||` would keep the
   key present-empty and break the SYNC-04 byte-diff).
3. **`src/sync/index.ts`** (`evaluateAndCompile`) — module-local
   `deduped(names)` (first-occurrence `[...new Set(names)]`, request order
   preserved) and the derivation:
   `deduped([...(config.extends ?? []), ...(config.layers ?? [])].map(s => s.name).filter(n => n !== spec.name))`,
   passed as `upstreamSystems`.

**`native/compile.ts`: no change needed.** `compileNative(request)` forwards the
whole `ScopedCompileRequest` object; the extra structural field rides because
`ScopedCompileRequest extends NativeCompileRequest` is assignable and the object
is passed by reference. Wiring only on the builder path is sufficient.
