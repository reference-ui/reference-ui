## 4. 10-line handoff note

1. **§I landed.** `WalkCtx::expect` materializes one `ExactLookupExpected`
   per applicable system; own→`[own]`, external→`qualifiers[1..]`, via the
   one `diagnostics::target_systems` helper. `dynamic()` untouched (shapeless).
2. **Finder.** `analysis/jsx` admits capital non-host tags as external through
   the shared `crate::extract::jsx::is_external_tag`, guarded by the resolved
   host graph (mirrors the extract gate; no phantom expectations on an empty
   graph). The `css()` surface is permanently `external=false`.
3. **R1 plumbing.** `assembly::qualifiers_for` is called at each
   analysis-input site (serial `lib.rs`, parallel `phase_walk.rs`) and again in
   `finish()` — same pure helper, no prebuilt value. `AnalysisInput`/
   `AnalysisCtx` carry `qualifiers`.
4. **Reject path.** `WantContext.external` → `ResolveReport.external` → the
   `ResolveOutcome` fact; proof re-targets the own-system resolver key across
   the foreign qualifiers before joining, so an external rejection cannot
   double-warn.
5. **Sink path.** `HarvestReport.external = sink.external`; `Sinks` coverage
   checks the foreign-qualified emitted keys for external sinks.
6. **Emitted side unchanged.** `emitted_keys` serializes `plan.system`
   through `serialize_lookup_key`; it already works on both the full-plan
   (`render_session`) and carried-key (`render_session_with_keys`) paths —
   verified, no new code there.
7. **One key authority.** No second canonicalizer: `target_systems` only
   chooses the system; `OwnedLookupKey::lookup_key()` (analysis/proof) and
   `emitted_keys` (plan→owned→`lookup_key`) both route through
   `runtime/serializer.rs::serialize_lookup_key`.
8. **Tests.** covered-external silent (render + full pipeline); missing
   external warns once (causeless render + reject-join full pipeline);
   diet ≡ proof (carried keys vs re-serialized plans) pinned.
9. **Warns once.** The full-pipeline `missing_external_key_warns_once`
   asserts exactly one miss (the reason-carrying condition line), proving the
   reject re-target joined rather than adding a causeless duplicate.
10. **T06/T04 assume:** analysis keys are foreign-qualified exactly when
    `qualifiers[1..]` is non-empty; emission already prints one rule per
    foreign qualifier (T04 `class_name_with_system`), so the join matches.

## 6. Enumerated key-materialization sites (G0 §I "enumerate them")

1. **Expect path — `WalkCtx::expect` (`analysis/object.rs`).** Expands per
   applicable system via `target_systems`. This is the only analysis site that
   materializes `OwnedLookupKey` for a block.
2. **Reject path — `Proof::collect_reject` (`proof/render.rs`).** The
   resolver's key is own-system; for an external `ResolveOutcome` it is
   re-targeted across `qualifiers[1..]` before `proof/rejects::collect`, so the
   reject joins the foreign expectation.
3. **Sink path — `Sinks::sink_covered` (`proof/sinks.rs`).** Harvest offered
   values are materialized per applicable system for external sinks.

`expect` also stamps `external` on its facts; `ResolveOutcome`/`HarvestOutcome`
carry it from the want/sink. `emitted_keys` needs no expansion (already
per-plan).
