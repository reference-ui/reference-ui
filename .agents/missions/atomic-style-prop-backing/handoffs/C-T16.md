### (c1) engine sentinel — `cascade/mod.rs`

`write_utilities_grouped` now replays each foreign qualifier's ranked set through
a new `write_foreign_group`, which brackets it with `/* foreign <q> */` /
`/* end foreign <q> */` marker lines (`push_foreign_marker`). The markers are
emitted **only** on the non-empty-external path; the empty-external short-circuit
(`return write_utilities(out, own, &qualifiers[0]);`) is byte-for-byte unchanged.

```rust
    if external.is_empty() {
        return write_utilities(out, own, &qualifiers[0]);
    }
    write_ranked(out, own, &name::SelectorPrefix::for_system(&qualifiers[0]));
    let ranked = rank_atoms(external);
    for qualifier in qualifiers.iter().skip(1) {
        write_foreign_group(out, &ranked, qualifier);
    }
...
fn write_foreign_group(out: &mut String, ranked: &[(&Atom, CascadeKey<'_>)], qualifier: &str) {
    push_foreign_marker(out, "foreign", qualifier);
    write_groups(out, ranked, &name::SelectorPrefix::for_system(qualifier));
    push_foreign_marker(out, "end foreign", qualifier);
}

fn push_foreign_marker(out: &mut String, label: &str, qualifier: &str) {
    out.push_str("  /* "); out.push_str(label); out.push(' ');
    out.push_str(qualifier); out.push_str(" */\n");
}
```
